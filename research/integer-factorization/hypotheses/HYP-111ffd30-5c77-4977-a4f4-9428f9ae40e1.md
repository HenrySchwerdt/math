# Ultimate research goal — classical integer factorization

Discover and rigorously establish a uniform deterministic classical algorithm
that returns the complete prime factorization, including multiplicities, of every
positive integer N ≥ 2 in worst-case O(n log n) bit operations, n = ⌈log₂ N⌉.
This is an aspirational open research goal, not a known achievable bound.

No special integer classes, randomized success guarantees, quantum oracles or
quantum hardware satisfy this target. Account for arithmetic and memory in an
explicit computational model. For powers of two, the user's n differs from the
usual binary encoding length by one; document this harmless additive difference
rather than silently redefining n. Include input/output and factor multiplicities.

## Milestones

1. Any rigorously established improvement to known general-purpose bounds.
2. A deterministic polynomial-time algorithm.
3. A practical low-degree polynomial-time algorithm.
4. Near-linear time, ideally O(n log n).

Each milestone requires its own precise statement, assumptions and worst-case
proof. Compare like-for-like models and deterministic/unconditional guarantees.
A reproducible reference implementation should ideally use C17. Independent
mathematical review and formal verification are required where feasible.

## Current evidence

None. No algorithm, bound improvement or factorization experiment was produced
by infrastructure bootstrap. Evaluate timing separately from asymptotic proof.
