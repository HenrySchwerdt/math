## Initial findings

(Written before reading the author's PRF .md or RUN .md.)

1. **Build/axioms.** Build and axiom output reproduced exactly; only the three standard axioms;
   no forbidden tokens. The theorem is machine-checked as stated.

2. **The two identities are correct for real curves (hand derivation + numerics).**
   With Q = (u,v), P = (x₀,y₀), u ≠ x₀, λ± = (v ∓ y₀)/(u − x₀):
   x(Q+P) + x(Q−P) = (λ₊² + λ₋²) − 2(u+x₀) = 2(v² + y₀²)/(u−x₀)² − 2(u+x₀).
   Clearing and using v² = u³+au+b, y₀² = x₀³+ax₀+b, u³+x₀³ = (u+x₀)(u²−ux₀+x₀²):
   2(u³+x₀³+a(u+x₀)+2b) − 2(u+x₀)(u−x₀)² = 2((x₀u + a)(u+x₀) + 2b). This is `hS`.
   The product formula `hT` is the classical one (Cassels/Washington) and was confirmed
   numerically on 33181 instances. The formulas are only valid for Q ≠ ±P, Q, Q±P ≠ O.

3. **Range of k and the edge case xs k = x₀.** At u = x₀ the left sides of `hS`/`hT` vanish but
   `hS`'s right side is 4y₀², nonzero for odd-order P (y₀ = 0 means order 2); so the identity
   genuinely fails at Q = ±P (confirmed by `edge.py`). On the curve, for 2 ≤ k ≤ m−1 with
   m = (r−1)/2 we have kP ≠ ±P (k∓1 ∈ [1, r−2] is not ≡ 0 mod r), kP ≠ O, (k±1)P ≠ O, so the
   required range never hits the edge case. The Lean range `2 ≤ k ∧ k+1 ≤ m` is exactly this.
   Note `k − 1` is natural subtraction but k ≥ 2 makes it exact.

4. **Injectivity.** x(kP) = x(jP) iff kP = ±jP iff k ≡ ±j (mod r). For 1 ≤ j < k ≤ m:
   0 < k−j < r and 2 < k+j ≤ r−2 < r, so neither holds. `hinj` is true on the curve.

5. **Non-vacuity.** For every tested real-curve instance with m ≥ 3 the hypotheses hold jointly
   (identities, injectivity, and `hg` via the Lagrange interpolant). The hypotheses are not
   contradictory, and the conclusion is non-trivial (for m ≥ 3 it is a genuine lower bound).

6. **Conclusion matches.** Informal deg g ≥ (r−5)/6 (real division) ⇔ 6 deg g ≥ r−5 ⇔
   r ≤ 6 deg g + 5, which is the corollary. With m = (r−1)/2 and r odd, r = 2m+1, and
   m ≤ 3d+2 ⇒ r ≤ 6d+5. Natural-number `(r−1)/2` is exact for odd r. `g = 0` is handled
   (natDegree 0 case: the constant must equal both 1 and 4, contradicted by 3 ≠ 0);
   informally g = 0 is excluded since g(x(P)) = 1. `(k : K)^2` matches "k² in F_p".

7. **Generality relative to the informal statement (harmless).** The Lean theorem does not
   require xs 1 = x₀, x₀ to be the x-coordinate of a point, the curve to be nonsingular, K to be
   finite, or r to be the order of anything; it holds for any field with 2 ≠ 0, 3 ≠ 0 and any
   sequence satisfying the hypotheses. This is strictly more general and does not weaken the
   intended statement. The proof only uses the identities at points 2..m−1 (k = 1 and k = m enter
   only through `hg` at the neighbours).

8. **Gaps (where the formal statement is weaker than the informal one).**
   (a) The curve-to-hypothesis bridge is unformalized: that `x(kP)` satisfies `hS`, `hT`, `hinj`
   for a Mathlib `WeierstrassCurve` point of odd order is not proved in Lean. It is established
   here by hand algebra + numerics only. This is the main limitation and is disclosed in the
   module docstring.
   (b) Characteristic 3 is excluded (`3 ≠ 0`). y² = x³+ax+b over F_3 is nonsingular when a ≠ 0,
   so the informal statement nominally includes p = 3. There, #E(F_3) ≤ 7, so r ∈ {1,3,5,7}; the
   bound is trivial for r ≤ 5, and for r = 7 one needs deg g ≥ 1, which holds because
   g(x(P)) = 1, g(x(3P)) = 9 = 0 in F_3 forces non-constant g. So the informal theorem is true
   at p = 3 but not covered formally. p = 2 is irrelevant (the curve is singular).
   (c) `2 ≠ 0` is used in the counting lemma (degree of `2g+2`); this excludes nothing relevant.

## Divergence attempts

- Edge case Q = ±P inside the hypothesis range: impossible on a curve for 2 ≤ k ≤ m−1 (finding 3).
  Extending the range to k = 1 or k = m would make `hS`/`hT` false or ill-defined, so the chosen
  range is necessary and correct.
- Off-by-one in m: checked; m = (r−1)/2 uses points 1..m, counting set is xs '' [2, m−1] of size
  m−2 by injectivity, giving m − 2 ≤ 3d.
- Vacuous hypotheses: refuted by 33181 real-curve instances (finding 5).
- Informal premise holds but Lean hypotheses fail: only for p = 3 (finding 8b), where the
  informal statement is nonetheless true by a direct argument.
- Lean hypotheses hold but informal premises fail: yes (arbitrary fields, sequences not from a
  curve); harmless since the Lean statement is then a more general true theorem.
- Bound violation search: none among 33181 instances (minimal interpolant degree always
  satisfies m ≤ 3d+2).
No counterexample to the formal-to-informal correspondence was found.

## Decision and rationale

**accept** (as a correctly stated, machine-checked CONDITIONAL theorem). The Lean declarations
`degree_bound_of_x_relations` and `degree_bound_of_x_relations_order` build at 8f844f9 with only
standard axioms; their hypotheses are exactly the denominator-cleared x-addition relations
and distinctness that hold for `xs k = x(kP)` on a short Weierstrass curve over a field of
characteristic ≠ 2,3 with P of odd order r, in exactly the needed range; the hypotheses are
jointly satisfiable; and the conclusion `r ≤ 6 deg g + 5` equals deg g ≥ (r−5)/6. The
acceptance does NOT cover an unconditional formal Theorem B: the bridge from Mathlib curve
points to `hS`/`hT`/`hinj` remains informal (hand derivation + numerics), and p = 3 is not
formally covered. Any claim must be phrased as "formal conditional on the x-addition relations".

## Significance and novelty (plain)

The result says an x-coordinate-only polynomial that reproduces k² on the first half of the
multiples of P must have degree at least about r/6, so no low-degree "x ↦ k²" shortcut exists;
this rules out one naive algebraic route to ECDLP but is weaker than what is needed for any
hardness claim, and similar degree lower bounds for interpolating discrete-log-type maps (e.g.
Coppersmith–Shparlinski, Lange–Winterhof style bounds) are classical, so the main value here is
a clean, machine-checked conditional proof with an explicit constant, not a new cryptographic
insight. No literature search was performed in this review; novelty is not established.
