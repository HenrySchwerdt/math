## Initial findings per declaration
(Written before reading the author assessment.)

**`slpStep` / `slpEval` (model).** A step `(j, l, b₁, b₂)` appends `±acc[j] ± acc[l]`; indices
≥ current length read `0`. Every S1 program (j, l < i) is represented verbatim, since at step i
the accumulator has length i. The out-of-range convention *enlarges* the program class (it adds
the operand 0, so programs can copy, negate, or produce 0). Because A1 and A2 universally quantify
over programs, enlarging the class only strengthens both theorems; the bound is unaffected since
0 = 0·P. So it does not matter for soundness w.r.t. S1. Program length = number of steps, matching
"a_0 = P, a_1..a_L".

**A1 `slpEval_mem_bound`.** States that every value in the evaluation list is n•P with
|n| ≤ 2^(prog.length). This is the uniform bound, not the per-index |n_i| ≤ 2^i of S1. The per-index
form follows by applying A1 to the prefix program (foldl over a prefix yields a prefix of the
list), but that step is not itself formalized. Minor gap in literal correspondence; the corollary
only needs the uniform form. Proof by generalized induction is straightforward and checked.

**A2 `exists_unreachable_of_addOrderOf`.** `addOrderOf P = r`, `2^(L+1)+1 < r` ⇒
`∃ Q ∈ zmultiples P, ∀ prog, prog.length ≤ L → Q ∉ slpEval P prog`. Quantifier order (one Q
defeats all programs) matches S1; "not an output" is formalized as "not among any of the
intermediate values", which is stronger than "not the final output". Infinite order (addOrderOf = 0)
is excluded by the hypothesis, consistent with "the order r". Counting: values lie in
{n•P : |n| ≤ 2^L}, at most 2^(L+1)+1 elements, and |⟨P⟩| = r. Faithful.

**`MBad` (encoding of S2).** For integers t and reals: t² ≤ 4q ⇔ |t| ≤ 2√q, and for r ≥ 0,
r² > 16q ⇔ r > 4√q — both exact. "r ∤ q" is present. "ord_r(q) ≤ M" ⇔ ∃ m ∈ [1, M] with
q^m ≡ 1 (mod r) (given r ∤ q, r prime, so the order exists); Lean writes `r ∣ q ^ m - 1` in ℕ,
and truncated subtraction is exact whenever q ≥ 1 (q^m ≥ 1). The only degenerate case is q = 0
(0^m − 1 = 0 in ℕ, divisible by everything), excluded by `2 ≤ q` in the count theorem. "q+1−t has
a prime factor r" is encoded as `(r:ℤ) ∣ q + 1 − t`; for q ≥ 2 and t² ≤ 4q, q+1−t ≥ (√q−1)² > 0,
so the zero-divisibility ambiguity never arises. Brute force found no mismatch with the real-valued
reading. Note: `r ∤ q` is logically redundant given r | q^m − 1 with m ≥ 1, and the proof of
`card_MBad_le` indeed discards it; harmless.

**B1 `trace_unique_of_dvd`.** r | t − t' and |t − t'| ≤ |t|+|t'| ≤ 4√q < r ⇒ t = t'. Correct; the
nlinarith step encodes (t − t')² ≤ 2(t² + t'²) ≤ 16q < r².

**B2 `card_primes_lt`.** Distinct primes with r² > 16q dividing N = ∏_{m=1}^M (q^m − 1) ≤
q^{M(M+1)/2}: (16q)^k ≤ (∏r)² ≤ q^{M(M+1)} ⇒ k < M(M+1). Correct, strict.

**`MBad_finite`.** Needed so that `ncard` is not the junk value 0 of an infinite set; proved
for q ≥ 1. Together with B3 the statement is meaningful.

**B3 `card_MBad_le`.** `2 ≤ q`, `1 ≤ M` ⇒ `{t : ℤ | MBad q M t}.ncard ≤ M(M+1)` via an injection
t ↦ (a chosen bad prime r for t) into R = large prime factors of N. Matches S2. The Lean hypothesis
q ≥ 2 is strictly more general than "q a prime power"; a theorem over all q ≥ 2 specializes to
prime powers, so this is fine (the prime-power condition is only needed for the elliptic-curve
interpretation, which is not part of S2). The proof actually yields `<`, stated as `≤`.

## Divergence attempts
1. Out-of-range operand exploitation: shown to enlarge, not shrink, the class; no program in S1 is
   missing. A divergence would require a program in S1 not expressible in Lean — none exists.
2. Vacuity of A2 via infinite order: hypothesis forces r > 0 finite; and `2^(L+1)+1 < r` is
   satisfiable (e.g. ZMod r), so A2 is non-vacuous.
3. Vacuity of MBad: exhibited `MBad 3 6 (-3)` in Lean.
4. Junk-value `ncard`: ruled out by `MBad_finite`.
5. Truncated subtraction: only fails at q = 0, excluded.
6. Real vs integer threshold mismatch: none algebraically; none in 9584 brute-force cases.
7. Searched for a counterexample to the M(M+1) bound for q < 1200, M ≤ 8 (all q, not just prime
   powers): none; observed counts at most half the bound.
No divergence found.

## Decision and rationale
**accept** (formal correctness of the stated declarations and their correspondence to S1/S2).
The build and axiom audit reproduce; the encodings are exact; the one literal gap (A1 gives the
uniform bound 2^L rather than per-index 2^i) is immaterial to the corollary and trivially recoverable.

Significance and novelty, plainly: both results are elementary and, in my view, folklore-level.
A1/A2 is the standard counting argument that addition chains of length L reach at most 2^L
multiples; it says nothing about generic-group lower bounds (Shoup/Nechaev √r), and the SLP model
has no access to Q, so it is not a lower bound for ECDLP algorithms of any kind — it bounds only
the reach of programs that use P alone. B3 is the standard "few traces give small embedding
degree" counting (cf. Balasubramanian–Koblitz style arguments on MOV-vulnerable curves); its
value here is as a checked lemma in the laboratory, not as a new result. Neither touches
bit-complexity, and no complexity claim is reviewed.
