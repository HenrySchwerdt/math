## Initial findings

**Build and trust base.** Build, fresh elaboration and axiom checks pass as above. Only the three
standard axioms appear. No forbidden tokens.

**Theorem statements match the informal claims.** (1) `length_bound_linear_short_weierstrass`:
`Field F`, `W.a₁ = W.a₂ = W.a₃ = 0`, `(2:F) ≠ 0`, `addOrderOf P = r`, `2N < r`, any
`prog : List (Op F)`, any index `i`, and `(evalAt prog (xCoord (k•P))).getD i 0 = k` for
`1 ≤ k ≤ N` give `N ≤ 3 * 2 ^ prog.length + 2`. The k² variant needs additionally `(3:F) ≠ 0`,
odd `r`, the full range `1 ≤ k ≤ (r-1)/2`, and concludes `r ≤ 6 * 2^L + 5`. (2)
`length_bound_rational_slp` adds `Defined prog (xCoord (k•P))` for each node and has the same
conclusion; `degree_bound_rational_short_weierstrass` is exactly the stated interpolation lemma
(no coprimality hypothesis). Nonsingularity of W is not assumed (Mathlib `Affine.Point` exists for
any W); the statements are therefore at least as general as claimed.

**Semantics/correspondence.**
- *Division and definedness.* Values are computed in F with Lean's total `x/0 = 0`, but
  `Defined` demands that every executed division (whether or not it feeds the output) has a nonzero
  divisor value at the input, at every node. Under that hypothesis `eval_agreement` shows every value
  equals num(u)/den(u) with den(u) ≠ 0, so the total-division convention is never observed. This is
  faithful to "a program that never divides by zero on the nodes". The requirement covers dead
  divisions too; this narrows the class only cosmetically (dead code can be deleted without
  increasing length). Defined is essential: with total semantics `inv0(u)` equals `u^(q-2)` over
  F_q and the degree argument would fail; the theorem correctly excludes this zero-test gadget.
- *Out-of-range indices.* An operand index `≥` current length reads 0 (value) or the pair (0,1)
  (formal). Indices refer only to earlier values, so there are no forward/cyclic references; an
  out-of-range read behaves as an implicit constant 0. This syntactically *enlarges* the class (every
  well-formed program is included), so it only strengthens a lower bound. A division by an
  out-of-range index is undefined (0 ≠ 0 fails), consistent.
- *Designated output.* `i` is arbitrary, including any intermediate value and even an out-of-range
  index (constant 0). Fine: it only strengthens the statement.
- *Constants.* `Op.const c` takes an arbitrary element of F (non-uniform, "constants free" in the
  sense of arbitrary choice, stated in both docstrings), but each constant occupies one step and is
  counted in L. Not counting constants would also be valid (degree-0 values do not disturb the
  invariant), so this is a harmless conservative accounting.
- *Degree invariant.* Proven invariant: every value in an accumulator of length m has degree
  ≤ 2^m (division-free) / numerator and denominator ≤ 2^m (fractions; add/sub use cross-multiplied
  pairs, div swaps). Base: const has degree 0, var degree 1 ≤ 2^1, out-of-range reads 0 or (0,1).
  Mul/add at step m: 2^m + 2^m = 2^(m+1). Hence final degree ≤ 2^L (slack of a factor 2 versus the
  tight 2^(L-1); harmless).
- *Single input.* Only `x(Q)` is supplied; no y-coordinate, no access to the curve beyond
  constants, no comparisons, no bit extraction, no branching.

**Non-vacuity (toy instances).** On y² = x³ + 2x + 3 over F_97 (#E = 100), P of order r = 50,
N = 24: a Horner program (L = 71, division-free) evaluating the Lagrange interpolant outputs k at
x(kP) for all 1 ≤ k ≤ 24; a program with one final division (L = 77) evaluating A/B, deg A, deg B
≤ 12, is Defined at all 24 nodes and outputs k. Small instances N = 3 (L = 8), N = 4 (L = 11) also
satisfy the hypotheses. All hypotheses are jointly satisfiable; the conclusions hold.

**Divergence attempts on the degree-level lemmas.** Exhaustive search over all nonsingular short
Weierstrass curves over F_p, p ≤ 43, all points P with (r-1)/2 ≥ 3, for the largest prefix N
(2N < r) admitting an interpolant:
- polynomial of degree ≤ 1 with g(x(kP)) = k: max N = 4 (bound 5), e.g. p = 5, y² = x³ + x + 1;
- rational A/B, degrees ≤ 1, B nonzero on nodes: max N = 5 = 3·1 + 2 — **the rational bound is
  attained**: p = 11, y² = x³ + 1, P = (9,2), r = 12, nodes x = 9,2,5,0,7, A = 1 + u, B = 3 + 2u
  (verified by direct enumeration);
- rational, degrees ≤ 2: max N = 7 (bound 8; search over the null space was randomized when its
  span exceeded 3000 vectors, so 7 is a lower estimate of the true maximum).
No counterexample; the 3d + 2 constant is sharp at d = 1.

**RationalSLP nonvanishing argument (task 3).** gcd reduction: `B ≠ 0` from B(x(P)) ≠ 0 (N ≥ 1);
`g = gcd A B ≠ 0`; exact division in the Euclidean domain F[X]; degrees of A/g, B/g do not increase;
g and B/g are nonzero at the nodes since B is; A/g = k·B/g at nodes by cancelling g; coprimality from
`isCoprime_div_gcd_div_gcd`. Edge case A = 0 makes the hypotheses inconsistent at k = 1, harmless.
Orbit propagation: if Nrat = 0, `key` gives at each 2 ≤ n ≤ r-2 the identity
B(x_n)[A(x_{n+1})B(x_{n-1}) + A(x_{n-1})B(x_{n+1})] = 2A(x_n)B(x_{n+1})B(x_{n-1})
(the den^d factor is nonzero because x(nP) ≠ x(P) for 2 ≤ n ≤ r-2, proved in
`smul_relations_full` without the 2m < r restriction). Induction from (N-1, N) upward gives
A(x_{n+1}) = (n+1)B(x_{n+1}), and B(x_{n+1}) ≠ 0 by coprimality (a common zero contradicts
sA + tB = 1). At n+1 = r-1, r-2 the x-coordinates coincide with x(P), x(2P) (`xCoord_smul_sub`, via
x(-Q) = x(Q)), so (r-1) = 1 and (r-2) = 2 in F, hence 2 = 0. Requirements N ≥ 3 (else bound
trivially true) and r ≥ 2N+1 ≥ 7 are discharged. No hidden assumption on characteristic beyond
2 ≠ 0, no primality of r, no distinctness of the values k in F (char p < N is allowed). Root counting
uses injectivity of k ↦ x(kP) on [1, N] (2N < r) and `card_roots'`; Nrat degree ≤ 3d from
`natDegree_Nrat_le`. Sound.

**Significance (task 5).** These theorems say: a branch-free, comparison-free algebraic
straight-line program over F that sees only u = x(Q) and must output the discrete logarithm k
(as the field element k) on the first N multiples — even with free arbitrary constants and with
division where defined — needs L ≥ log₂((N-2)/3) field operations; for N = (r-1)/2 this is
L ≥ log₂ r − O(1). Equivalently: the rational/polynomial function it computes has degree
≥ (N-2)/3, and an SLP of length L computes degree ≤ 2^L. They do NOT say anything superpolynomial:
log₂ r ≈ n operations is polynomial in the input size, so they do not even rule out a polynomial-size
SLP in this model (degree-r functions are reachable with O(log r) multiplications by repeated
squaring; the barrier is just the degree count, essentially tight as a degree statement, while the
true SLP complexity of the interpolant is not bounded from above or below beyond this). They give
no bit-complexity bound (the n² remark is not formalized). They do not cover algorithms that branch,
compare, hash or read bits of field elements (Pollard rho, BSGS, index calculus, Semaev-summation
approaches with Gröbner-basis case analysis, any randomized algorithm), algorithms using the
y-coordinate or several input points (e.g. P and Q jointly as inputs, which is the actual ECDLP
setting where P is an input rather than a fixed constant), or algorithms computing k mod small
moduli/bits rather than k as a field element (only the field-element output k ∈ F, or k², is
treated; outputs encoding k differently are outside scope). They are not a generic-group bound
(the Shoup √r bound is a different model). The hypothesis P fixed with arbitrary constants makes the
program non-uniform, which only strengthens the lower bound.

## Divergence attempts

- Searched for statement weakenings: arbitrary output index, out-of-range conventions, total
  division, free constants, singular W, non-prime r, small characteristic: each either strengthens
  the theorem or is excluded by an explicit hypothesis (Defined, 2 ≠ 0, 2N < r).
- Extremal search for degree ≤ 1 (polynomial and rational) and ≤ 2 (rational) interpolants over all
  short Weierstrass curves with p ≤ 43: no violation; rational d = 1 bound is attained.
- Not attempted: a search for short SLPs (as opposed to low-degree interpolants) against
  `3·2^L + 2`; the length bound follows from the degree lemma and is very loose for concrete
  programs (e.g. L = 8 already allows N ≤ 770).
- Not attempted: whether the total-division (x/0 = 0) model without `Defined` admits shorter
  programs; the theorem does not claim that.

## Decision

**Accept** (formal correctness and statement correspondence). Rationale: build, fresh elaboration
and axiom checks pass with only standard axioms; the Lean statements faithfully (and in places more
generally) express the informal claims; conventions (total division masked by `Defined`,
out-of-range reads, arbitrary output index, arbitrary constants) only strengthen the statements or
are excluded by explicit hypotheses; hypotheses are jointly satisfiable on concrete curves; the
nonvanishing argument has no hidden assumption. Condition of acceptance: every summary must carry the
significance limits above (only an Ω(log r) count of field operations in a branch-free x-only
algebraic model; no bit complexity; no statement about branching, comparison, hashing, bit-access or
generic-group algorithms; polynomial, not superpolynomial). Complexity: not applicable (formal
correctness only).
