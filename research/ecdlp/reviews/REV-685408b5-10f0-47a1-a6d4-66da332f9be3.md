## Initial findings

Written before reading the author's assessment.

1. **Soundness.** No `sorry`, `admit`, new axioms, `unsafe`, `native_decide` or `implemented_by`. The proof structure is sound:
   - Points are mapped to x-coordinates. `xCoord_smul_injOn` (which needs 2N < r) gives injectivity on [1, N].
   - The X1/X2 addition relations are instantiated at Q = kP and P' = jP. The proof establishes kP ≠ 0, jP ≠ 0 and x(kP) ≠ x(jP); the last uses k ≠ j and injectivity, with j < k ≤ N.
   - The second difference of k² is 2j².
   - The cleared polynomial `Nc` has natDegree exactly 3d when d ≥ 1. The leading term comes from D^d(2g + c), using (2:F) ≠ 0; the other summand has degree ≤ 3d − 1 by `Interp.natDegree_N_le`.
   - The d = 0 case is handled by c ≠ 0, which makes C empty.
   - I found no suspicious shortcuts. `Nat.cast_sub` is applied with j ≤ k.
2. **Filter = S_j.** A ⊆ [1, N] and 0 ∉ A. So k − j ∈ A with truncated subtraction already implies k > j, and the `j < k` conjunct is redundant. The count is exactly #{k : k − j, k, k + j ∈ A}.
3. **2N < r versus N ≤ (r−1)/2.** These are equivalent for every natural r, whether (r−1)/2 is read as floor division or real division. The Lean proof uses neither primality nor oddness of r, so it is a generalization on that axis. It also generalizes from F_p to any field with 2 ≠ 0. That condition is harmless: over F_2 no short Weierstrass curve is nonsingular.
4. **Extra hypothesis `1 ≤ natDegree g ∨ (j:F) ≠ 0`.** Over F_p this fails exactly when g is constant (or zero) and p | j. In that case the Lean theorem says nothing, while the informal statement asserts S_j = 0. The informal assertion is true, but only through Hasse:
   - S_j ≥ 1 needs k − j ≥ 1 and k + j ≤ N, so 2j + 1 ≤ N.
   - If p | j then j ≥ p, so r > 2N ≥ 4p + 2.
   - But r ≤ #E(F_p) ≤ p + 1 + 2√p < 4p + 2 for every p ≥ 2. Contradiction.

   So the Lean statement is strictly weaker than the informal one only in this degenerate case, where the informal conclusion holds trivially (S_j = 0). Recovering it formally would need Hasse, which is not formalized here. I checked the boundary the PI asked about:
   - N ≥ p needs a prime r > 2p with r ≤ p + 1 + 2√p, which can happen only for p ≤ 5.
   - A computer search over all curves with p ∈ {5,…,23} found no prime r > 2p.
   - p = 3 does allow it: y² = x³ + 2x + 1 over F_3 has 7 points (x³ + 2x ≡ 0 on F_3), so r = 7 and N = 3 = p. With j = 3, the hypothesis `(j:F) ≠ 0` fails, but S_3 = 0 because A ⊆ [1, 3].

   Also, j itself is unbounded in both statements. For example, g constant and j = p > N gives S_j = 0 trivially.
5. **Non-vacuity.** Take p = 13, E: y² = x³ + 4x + 1, P = (0, 1) with #E = 19 = ord P, N = 9, A = {2, 3, 4, 5}, g = 8 + 12X (degree 1), j = 1.
   - Check g(x(kP)) = k²: x(kP) = 4, 12, 5, 9, and g gives 4, 9, 3, 12, which equal k² mod 13.
   - Then S_1 = 2 ≤ 3. All hypotheses hold and the filter set is nonempty.

## Divergence attempts

- **Exhaustive low-degree search.** I tried every g ∈ F_p[X] with deg ≤ 2, using one curve of prime order per a-value, for p ∈ {11, 13, 17, 19, 23}, with N = (r−1)/2 and every j ≤ N. A is the full agreement set of g in [1, N]. This covered 5,489,316 (curve, g, j) triples with 0 violations of S_j ≤ 3 deg g. The best ratio was S_j / deg g = 2. This is a sanity check only; the formal proof is the evidence.
- **Hasse-gap search.** No nonsingular curve over F_p with p ∈ {5,…,23} has a prime r > 2p or r > 4p + 2. `toyec` rejects p = 3, so I handled p = 3 by hand.
- **Proof-level attacks.**
  - Could the natDegree of `Nc` collapse? No: the leading coefficient of D^d · 2g is 2·lc(g) ≠ 0.
  - Could xCoord of the point at infinity (0) create false agreements? No: every kP with 1 ≤ k ≤ N + j < r is nonzero.
  - Is k − j as a Nat cast correct? Yes, given j < k.
  - None of these attacks succeeded.

## Decision and rationale

**Accept** the formal artifact. The Lean theorem builds with standard axioms only and faithfully states HYP-a1dd5501 part (2), with these differences:

- (a) It is more general: any field with 2 ≠ 0, and no primality of r.
- (b) It adds the hypothesis `1 ≤ natDegree g ∨ (j:F) ≠ 0`. This removes only the case deg g = 0 with p | j, where the informal conclusion is trivially S_j = 0 by Hasse. That reduction is not formalized.
- (c) natDegree 0 is used for g = 0. This gives the same conclusion, S_j ≤ 0.

The statement is non-vacuous. The δ > 2/3 corollary is not covered.

## Significance and novelty

This is a small but genuine formal result. It is a machine-checked lower bound on the degree of a polynomial in the x-coordinate that agrees with k ↦ k² on a set A of multiples of P that contains many 3-term arithmetic progressions with step j. It formally rules out low-degree x-coordinate interpolation of a quadratic function of the discrete log on structured subsets. It extends earlier formalized bounds that covered consecutive ranges.

It does not bear on the hardness of ECDLP in general:

- It is restricted to polynomial maps in x and a specific target function.
- It concerns degree, not bit complexity.

Results of this type (lower bounds on the degree of interpolating polynomials for the discrete logarithm, in the style of Coppersmith–Shparlinski and Lange–Winterhof) are known in the literature for the finite-field and elliptic-curve settings. I did not perform a literature check, so I make no novelty claim for the mathematics. The novelty is plausibly in the formalization.
