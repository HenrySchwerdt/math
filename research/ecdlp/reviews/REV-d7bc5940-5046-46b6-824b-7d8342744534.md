## Initial findings (written before reading the author report)

Model made precise (needed because the HYP text leaves it implicit). A tree is a finite rooted tree. The machine state at a node is determined by the root-to-node path: registers = input u, free constants, and the results of the arithmetic nodes on that path. Registers computed on other branches are NOT available. An arithmetic node applies +,-,*,/ to two registers of the state; a test node asks "register = 0?" for any register of the state (tests cost nothing, any number of them per path); a leaf outputs one register of the state. Constants are free operands (cost nothing as registers). A division executed at u with divisor value 0 makes the run at u undefined; the hypothesis "outputs k at x(kP)" includes "defined at x(kP) on the path actually executed". Divisions on branches not executed at u are irrelevant at u, so (a)'s worry about a division defined on one branch but undefined at nodes on other branches does not arise.

(a) Model. OK once defined as above. Two points the statement should add: (i) the model must say tests are free and unbounded in number (the bound is claimed independent of depth), (ii) the generic path may reach a division whose divisor has identically zero numerator (e.g. untested x - x as divisor). Then the formal pair has zero denominator and the generic path is undefined at every u. This is not a counterexample: every valid u is then deviating and the count 2^{L+1} - 1 bounds N directly (N <= 2^{L+1} - 1 <= 9*2^L - 1). The proof should treat it as a separate case or define the generic path to stop there. Random trees (tree.py) hit this case in 293-698 of 4000 seeds per L.

(b) Generic-path degree bound. Along the path each register i (i-th arithmetic result) is a formal pair (num, den) with both degrees <= 2^i: for x/y = (a/b)/(c/d) = ad/(bc) both parts at most double, for +,- also (ad +- bc)/bd, for * clear. This is exactly `degLe_getD` in the Lean file. Deviation analysis: let u be a node; by induction on the path, as long as all divisions so far were defined and all tests agreed with the generic path, the value of a register at u is num(u)/den(u) with den(u) != 0 (`eval_agreement`). So the first deviation at u is either a test whose register has num(u) = 0 while its generic numerator is a nonzero polynomial, or a division by a register with num(u) = 0 (run undefined, impossible for valid u but harmless to count). Tests of formally-zero numerators take the "= 0" branch generically and never deviate. Counting: only the numerators of the at most L+1 registers on the generic path matter (tests may repeat the same register arbitrarily often, depth is irrelevant), so deviating u are roots of nonzero numerators of degree <= 2^i for i = 0..L: at most sum 2^i = 2^{L+1} - 1. Division denominators vanishing at u do not need separate counting because den(u) != 0 is guaranteed on non-deviating prefixes and the divisor register's NUMERATOR zero is already counted. Correct.

(c) Lemma A for arbitrary G. The Lean file proves only the case G = [1, N] (hypotheses hB0, hAB for all 1 <= k <= N), so the lemma needs a new Lean argument, but the mathematics goes through, for these reasons. (1) Reduce A/B to coprime A', B' with g = gcd: B(x_k) != 0 for k in G forces g(x_k) != 0, so G subset G' and d' <= d, no loss. (2) The nonvanishing proof of Nrat is purely polynomial-identity based: if Nrat = 0 then at EVERY node x_n (2 <= n <= r-2) the cleared second-difference relation holds. It does not use membership in G except at the start. Given any ONE consecutive pair k0, k0+1 in G' (exists whenever there is a centre) with B != 0 and A = kB there, the relation at n = k0 gives A(x_{k0-1}) = (k0-1)B(x_{k0-1}) (dividing by B(x_{k0})B(x_{k0+1}) != 0) and at n = k0+1 forward; coprimality gives B != 0 at each new node. Propagate backward to k = 1, 2 and forward to k = r-1, r-2, then the same two-line contradiction from x_{r-1} = x_1, x_{r-2} = x_2 yields 2 = 0. The Lean proof only propagates forward from N because G = [1, N] gave 1, 2 for free; with gaps one needs bidirectional propagation. (3) Then Nrat != 0, degree <= 3d', vanishes at x_k for every centre k in [2, N-1], x_k distinct by 2N < r, so centres <= 3d. Verified correct; needs new Lean work (generalise hnz to bidirectional propagation from one pair).

(d) Arithmetic. R <= 2^{L+1} - 1 deviating nodes; each u is x_k for one k in [1, N] (2N < r), each removed k kills the centres k-1, k, k+1, so at most 3R centres lost; centres available are k in [2, N-1], N - 2 of them. Remaining >= N - 2 - 3(2^{L+1} - 1) must be <= 3*2^L (Lemma A with d = 2^L): N <= 3*2^L + 6*2^L - 3 + 2 = 9*2^L - 1. Arithmetic correct. (Slack: experiment below suggests the true max centres is about 2d, not 3d.)

(e) Theorem P. The statement does not define A, R, j, or the class; I read it as: R = A/B of degree <= d, a set S in [1, N] with A(x_k) = kB(x_k), B(x_k) != 0 on S, j with 2j != 0 in F, and the polynomial Phi(u) = (B(u)A(w+) - (A(u) + jB(u))B(w+)) * (same with w-), w+- = x(Q +- jP), u = x(Q). Facts: (1) w+ and w- are the two Galois conjugates over F(u); Phi is symmetric hence a rational function of u; multiplying by (u - x_j)^{2d} gives a polynomial of degree <= 4d (cleared symmetric functions of degree <= 2d, coefficients degree <= 2d); same machinery as `natDegree_CS_le` with P replaced by jP. (2) Phi vanishes at u = x_k when k, k+j in S, provided k != j (for k = j the other conjugate is x(O), the formulas break) and (x_k - x_j) != 0. (3) Phi != 0: Phi = 0 in the domain F(E) forces H(w+) = 0 or H(w-) = 0; by Q -> -Q symmetry both give R(x(Q+jP)) = R(x(Q)) + j identically; substitute Q -> -Q - jP and use evenness R(x(-Q)) = R(x(Q)): R(x(Q)) = R(x(Q)) + 2j, so 2j = 0 in F, contradiction. So the "even-function trick" is correct and irreducibility is not even needed beyond F(E) being a domain. Also 2jP != 0 is automatic because 2j < 2N < r. Correct, with the corrections: exclude k = j from the root count, and 2j != 0 must be read in F (characteristic), not just in Z/r.

(f) Corollary P1. Derivation: class A of size m >= N/2^D; sum over j in [1, N-1] of #{k : k, k+j in A} = C(m,2), so some j has >= C(m,2)/(N-1) pairs; minus one for k = j; <= 4d = 4*2^L vanishing nodes: m(m-1) <= 2(N-1)(4*2^L + 1), giving N <= 4^D(8*2^L + 2) + 2^D <= 11*2^{2D+L}. So 40 is valid (loose by a factor ~3.6), exponent 2D + L correct. BUT the statement has no hypothesis on the characteristic. In characteristic 3 (F = GF(3^7), E: y^2 = x^3 + x + b, a != 0, 2 != 0), "outputs k" means outputs k mod 3. The partition by k mod 3 (3 <= 2^2 classes, D = 2) with the constant program (L = 0) outputs k at x(kP) for every k, while N can be (ord(P) - 1)/2 = 1093 > 40*2^{2D+L} = 640 (char3.py: #E = 2188, ord(P) = 2188). Every pair k, k+j inside a class has 3 | j, hence 2j = 0, so Theorem P is not applicable, as it states. Corollary P1 as stated is FALSE; it needs char F = 0 or char F > N (so that j < N never has 2j = 0 in F), or must pick j not divisible by char.
