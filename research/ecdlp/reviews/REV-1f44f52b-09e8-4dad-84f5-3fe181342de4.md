## Initial findings

Written before reading the author assessment.

1. **Build/axioms.** The build reproduces. Only standard axioms are used. No forbidden constructs appear.
2. **Curve model.** Mathlib's `WeierstrassCurve.Affine` with `a₁ = a₂ = a₃ = 0` is
   `y² = x³ + a₄x + a₆`. So `a = a₄` and `b = a₆`, which is the intended short Weierstrass curve.
   `W.Point` is `0` together with the nonsingular affine points, under Mathlib's chord-tangent group law.
   For an elliptic curve every affine point is nonsingular, so `W.Point` is exactly E(F).
3. **Order.** `addOrderOf P = r` with `r % 2 = 1` forces finite odd order. Infinite order
   gives `addOrderOf = 0`, which is even, so it is excluded. This matches the informal statement.
4. **xCoord at infinity.** `xCoord 0 = 0` never enters. `nsmul_ne_zero_of_lt` proves
   `k•P ≠ 0` for `1 ≤ k < r`, and `m = (r-1)/2 < r`. The x-addition relations are
   used only for `2 ≤ k ≤ m-1`, so `x((k-1)P)` has index at least 1 and `x(0·P)` is never read.
   The hypothesis `hg` ranges only over nonzero multiples. The convention therefore
   neither weakens nor trivializes the statement.
5. **Values `(k:F)^2`.** This is the image of k² in F (k² mod p in characteristic p), which is
   what "g(x(kP)) = k²" means over F. Wrapping is the intended meaning. For finite fields,
   Hasse gives `m < p` for p ≥ 7 anyway.
6. **Degenerate r.** For r = 1, 3, 5 we have m ≤ 2 and the conclusion `r ≤ 6·deg g + 5` holds
   trivially. The informal bound `deg g ≥ (r-5)/6 ≤ 0` is trivial there too, so nothing is lost.
   Since `r ≤ 6d+5` ⇔ `d ≥ (r-5)/6` over the rationals, the Lean conclusion is exactly the informal bound.
7. **Characteristic hypotheses.** `(2:F) ≠ 0` and `(3:F) ≠ 0` match "char ≠ 2, 3".
   Both are genuinely used:
   - 2 ≠ 0: the leading coefficient of the cleared polynomial N is `-2·lc(g)`, so `deg N = 3d`.
   - 3 ≠ 0: this excludes constant g, because 1 ≠ 4.
8. **No discriminant hypothesis.** The theorem does not assume Δ ≠ 0, so it also covers the
   nonsingular points of singular short Weierstrass cubics. That is strictly more general
   than Theorem B, not vacuous. Every elliptic curve instance is a special case.
9. **Non-vacuity.** For any P of odd order r, the values x(kP) for 1 ≤ k ≤ m are distinct
   (also proved in Lean as `xCoord_smul_injOn`). So the Lagrange interpolant g of degree ≤ m−1
   exists, and the hypotheses are satisfiable on every such curve point.
10. **Proof structure.** The argument is a genuine root count:
    - N(u) = D(u)^d·(g(z₁)+g(z₂)−2g(u)−2) via Newton power sums.
    - At u = x(kP) this vanishes because (k+1)²+(k−1)²−2k²−2 = 0.
    - deg N = 3d, so m−2 ≤ 3d.
    - The curve facts come from Mathlib's `xRep_add_of_X_ne`, `xRep_sub_of_X_ne` and `X_eq_iff`.
    - There is no `decide`, and no goal is closed through contradictory hypotheses except in
      legitimate `absurd rfl h` branches that rule out the point at infinity.

## Divergence attempts

- **Toy-curve search.** I used my own affine arithmetic and cross-checked it against `toyec.Curve.add` on the elliptic cases.
  - For every odd-order point I checked the injectivity of x(kP) and the cleared relations hS and hT.
  - I then computed the degree d of the minimal-degree interpolant, which is the unique Lagrange
    interpolant: any other interpolant has degree ≥ m.
  - Finally I tested whether r ≤ 6d+5.
- **Elliptic curves.** y² = x³+ax+b over F_p for (p,a,b) = (101,2,3), (103,1,1), (211,5,7),
  (227,0,7), (241,3,0), (401,11,13), (1009,2,3). 1078 odd-order points, 0 violations.
- **Singular cubics**, to test the generality in finding 8: the cusp y² = x³ over F_101, and the
  node y² = x³−3x+2 over F_103 and F_107, using nonsingular points only. 164 odd-order points, 0 violations.
- **Typical slack.** Interpolants have degree near m−1 ≈ r/2, far above r/6.
  The minimum slack observed, 2, occurs at r = 3, where d = 0.
- **Vacuity routes considered and ruled out:**
  - infinite order;
  - the infinity convention;
  - g = 0 or constant g;
  - contradictory hypotheses among `h1`, `h2`, `h3`, `h2'`, `h3'`.

No counterexample and no divergence from Theorem B were found.

**Significance and novelty.** The result is a formally verified lower bound of about r/6 on the
degree of any polynomial in the x-coordinate that maps x(kP) to k² on half of the cyclic group
⟨P⟩. That is one concrete instance of the principle that "discrete-log-like" maps have no
low-degree x-only interpolant. It does not bear on the hardness of ECDLP:
- the bound is linear in r, so it is far from what a cryptographic statement would need;
- it is about polynomial degree, not circuit or bit complexity;
- it covers only the specific target k ↦ k².

Whether it is new relative to Lange–Winterhof-style degree bounds for interpolating the elliptic
curve discrete logarithm from x-coordinates is **unsettled**. This review did not compare against
that literature, and no novelty claim should be made on the basis of this review.
