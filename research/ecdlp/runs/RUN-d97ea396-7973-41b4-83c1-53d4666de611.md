## Developed ideas

### F-A1  Homomorphic section of E(Z/p^2) -> E(F_p): second p-adic digit as a non-algebraic function of the point
- Property exploited: for N=#E(F_p) coprime to p, E(Z/p^2) = E(F_p) x E_1, with a canonical group-homomorphic section s(R)=[p*m]R~ (m=p^-1 mod N). It exists for ANY lift of the curve, so, unlike "arbitrary lifts" (HYP-f85d20a1), s(kP)=k s(P) holds exactly. Digit u(R)=(x(s(R))-x(R))/p mod p is a deterministic function on E(F_p) with cocycle structure (the lifted group law). Heuristic (unproved): u(kP) is a Birkhoff sum of an explicit rational function eta along the orbit minus (k/r)*(full sum): z(kP)=sum_{i<k} eta(iP) - (k/r) sum_{i<r} eta(iP) mod p, i.e. DL becomes "locate the index of a walk position". In characteristic 0 the analogue has a closed form (zeta function).
- Barrier escaped: algebraic-interpolation bounds (pole order, HYP-5a550ab6/eda6732a): u is not a low-degree rational function of coordinates (degree ~p^2 representation), so those bounds do not apply directly. The escape is not ruled out by the lift-uniformity result because that concerns independent lifts, not the homomorphic section.
- Obligations: (i) prove or refute any closed form / fast evaluation of the partial sums; (ii) show u gives information beyond (x,y) (impossible information-theoretically: u is a function of R; only computational structure can help); (iii) relate to Smart's log(N Q~)=k log(N P~)+N log(eps) error term.
- Killers: sequence u_k has full linear complexity and no P-recursive relation; partial sums have no closed form.
- Cheapest test (RUN, T3): Berlekamp-Massey linear complexity and P-recursive guessing of u_k, v_k.
- Prior work: Smart 2000 / Satoh-Araki-Semaev anomalous attacks (unverified recollection); Weierstrass zeta quasi-periodicity (textbook); Stange elliptic nets (verified, below) for net structure.

### F-A2  Cross-structure / Freiman test (additive combinatorics)
- Property: if x(jP) were an approximate Freiman homomorphism, field-additive coincidences x_a+x_b=x_c+x_d (or multiplicative ones) would concentrate on index-additive quadruples a+b=c+d, giving a sub-square-root collision structure (sum-product-style relation search).
- Escapes: character-sum/Weil heuristics are about single sums; a joint additive-energy measurement of both structures is not covered by "approximate characters" (which test one multiplicative character).
- Obligations: prove no Freiman-type compatibility (Weil-type bound for Sum 1[x(aP)+x(bP)=x(cP)+x(dP)]-type counts, plausible but unproved); positive result would need a faster search for such quadruples.
- Killers: z-scores vs permutation null consistent with 0; controls fire.
- Cheapest test (RUN, T1).
- Prior work: additive energy / Freiman, Bourgain-Glibichuk-Konyagin for subgroups of F_p^* (unverified recollection; no elliptic-curve version recalled).

### F-A3  Random-energy-model landscape (statistical mechanics)
- Property: treat H(k)=dist(x(kP),x(Q)) as an energy landscape on the hypercube of k's bits; annealing exploits correlation length.
- Escapes: "only generic search"; if correlation length > 0 at some metric, local search beats random sampling.
- Obligations: show autocorrelation Sum_R f(R)g(R+dP) is Weil-small for all low-complexity metrics (plausible, not proved here).
- Killers: correlation ~ N^-1/2; annealing <= random sampling.
- Cheapest test (RUN, T2). Prior work: Derrida, "Random-energy model: an exactly solvable model of disordered systems", PRB 24, 2613 (1981) and PRL 45, 79 (1980) (verified via search). For REM no algorithm beats exhaustive search; ECDLP rho is already sqrt of that.
