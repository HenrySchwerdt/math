## Mathematical analysis
Setting: `W: y^2=x^3+ax+b`, `P` of order r, `2N<r`, `x_k = x(kP)`, `x0 = x_1`, `D=(u-x0)^2`,
`SA = numS` (deg<=2), `TB = numT` (deg<=2). For 2<=k<=r-2: `(x_{k+1}+x_{k-1}) D(x_k) = SA(x_k)`, `x_{k+1}x_{k-1} D(x_k) = TB(x_k)` (CurveX relations, extended here to all k in [2,r-2]).

Let `A, B in F[X]`, `d >= max(deg A, deg B)`, `B(x_k) != 0`, `A(x_k) = k B(x_k)` for 1<=k<=N.

1. Cleared symmetric sums. With `z1,z2` roots of `Z^2 - (SA/D) Z + TB/D`, define
   `W_ij = TB^min(i,j) * q_{|i-j|}` (`q` = Interp.q, `q_m(u) = D^m (z1^m+z2^m)`), so
   `W_ij(u) = D^max(i,j) (z1^i z2^j + z1^j z2^i)` and `deg W_ij <= 2 max(i,j)`.
   `CS(f,g) = sum_{i,j<=d} f_i g_j D^{d-max(i,j)} W_ij` evaluates to `D^d (f(z1) g(z2) + f(z2) g(z1))` and has degree `<= 2d`.
2. `Nrat = B*CS(A,B) - A*CS(B,B)`, degree `<= d + 2d = 3d`, and
   `Nrat(u) = D^d [ B(u)(A(z1)B(z2)+A(z2)B(z1)) - 2 A(u) B(z1) B(z2) ]`.
   No division is needed (so no issue if some B(z)=0 off the nodes).
3. Vanishing at nodes: for 2<=k<=N-1, `u=x_k, z1=x_{k+1}, z2=x_{k-1}`, substituting `A(x_j)=jB(x_j)`, j=k-1,k,k+1: bracket = B(u)B(z1)B(z2)[(k+1)+(k-1)-2k] = 0. So `Nrat` has the N-2 distinct roots `x_2..x_{N-1}` (injectivity, 2N<r).
4. NONVANISHING (the key point; proved, no extra hypothesis beyond 2 != 0). First reduce to `gcd(A,B)=1`: write A=gA', B=gB'; since `B(x_k)!=0`, `g(x_k)!=0` so `A',B'` satisfy the same hypotheses with degree <= d. Suppose `Nrat = 0` as a polynomial (A,B coprime, N>=3). Then for every k in [N, r-2] the bracket vanishes at `u=x_k` (D(x_k) != 0 because x_k != x_1 for 2<=k<=r-2). Given `A=jB`, `B!=0` at x_j for j=k,k-1, the bracket equals `B(x_k)B(x_{k-1}) (A(x_{k+1}) - (k+1)B(x_{k+1}))`, hence `A(x_{k+1}) = (k+1) B(x_{k+1})`; if `B(x_{k+1})=0` then also `A(x_{k+1})=0`, contradicting coprimality (Bezout). By induction `B(x_k) != 0` and `A(x_k)=k B(x_k)` for all N<=k<=r-1 (propagation along the whole orbit). But `x_{r-1}=x_1`, `x_{r-2}=x_2` (as (r-j)P=-jP), and `A(x_1)=B(x_1)`, `A(x_2)=2B(x_2)` with `B(x_1),B(x_2)!=0`; so `r-1 = 1` and `r-2 = 2` in F (r-1=s+2, r-2=s+1 for r=s+3): `(s+2)=1`, `(s+1)=2`, giving `2 = 0`, contradicting `2 != 0`. Hence `Nrat != 0`.
   Interpretation: `Nrat = 0` would say `g=A/B` is discretely harmonic on all of E, so `g(x_k)=k` propagates around the finite cyclic orbit and cannot close up (x_{r-k}=x_k forces 2k=r in F for all k).
5. Counting: `N-2 <= #roots <= deg Nrat <= 3d`, so **`N <= 3d + 2`** (c=3, c'=2), identical constants to the polynomial case. For SLP length L, `d <= 2^L`.
   Remark: the bound is not tight for rational g; the true minimal degree is about N/2 (below), so the c=3 constant can plausibly be improved to ~2 but that is not proved.
