## Analysis
Generalize the root count from step 1 to step j and subset A. For k in C_j = {k in A : j<k, k-j in A, k+j in A} put u = x(kP), x0 = x(jP),
z1 = x((k+j)P), z2 = x((k-j)P). The x-addition identities (CurveX.xCoord_relations with Q = kP, P' = jP, needs x(kP) != x(jP)) make z1,z2 the roots of
Z^2 - S(u)Z + T(u) over D = (u-x0)^2. The cleared polynomial Nc = sum_i g_i D^(d-i) q_i - D^d (2g + c) has
eval = D^d (g(z1)+g(z2)-2g(u)-c), with c = (k+j)^2+(k-j)^2-2k^2 = 2j^2. For d = deg g >= 1, 2g + c has degree d for ANY c (leading coeff 2*lead, 2 != 0), so
Nc has degree exactly 3d (first sum has degree <= 2d); hence it is nonzero and its roots, which include the distinct x(kP), k in C_j (injectivity, 2N<r), number <= 3d.
The constant c is irrelevant for d >= 1 (as in LinearInterp). For d = 0 the bound says C_j = empty, which needs c != 0, i.e. (j : F) != 0.
IMPORTANT FINDING: for d = 0 and (j:F) = 0 the statement can fail (g = 0, A = multiples of char F, in an extension field with char <= N: k^2 = 0 = g constant while S_j > 0).
So the theorem needs hypothesis (1 <= deg g or (j:F) != 0). The corrected HYP "S_j/3 for every j" should carry it (it is vacuous only in the degenerate d=0 case); 3 != 0 and r odd are NOT needed.
Not needed also: hodd, h3'. (I did not construct an explicit F_{p^n} counterexample; this is an argument-level observation, the Lean theorem simply carries the hypothesis.)
