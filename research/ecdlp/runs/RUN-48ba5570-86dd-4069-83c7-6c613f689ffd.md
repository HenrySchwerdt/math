### Item (1): deg f >= T_j/2
- Regularity: h_j = f∘tau_{jP} - f - j. At Q = kP with k, k+j in A, f is regular at kP (k in A) and f∘tau is regular at kP iff f is regular at (k+j)P, which holds because k+j in A. Yes, k+j in A guarantees it.
- Distinct zeros: kP, k in 1..N, are pairwise distinct since N <= r (kP = k'P iff r | k-k'). Value h_j(kP) = (k+j) - k - j = 0 in F_p. Correct.
- deg(f∘tau) = deg f since tau is an automorphism of the curve; constants add no poles; so deg h_j <= 2 deg f, and a nonzero function has at most deg many zeros (counted over the algebraic closure, ours are F_p-rational). Correct.
- Nonvanishing is stated as "h_j != 0 since otherwise deg f >= r". This is a dichotomy, not a nonvanishing proof: h_j == 0 is possible only if f has poles (constant f gives h_j = -j, nonzero mod p because j < N <= p), and then the pole set is a nonempty finite jP-invariant set whose orbits have size r (r prime, 0<j<r), so deg f >= r > N > T_j and the bound still holds. Further, iterating f(Q+jP) = f(Q)+j r times gives r*j = 0 mod p, so h_j == 0 forces p = r (anomalous). So the bound is correct in all cases; the proof text should say "either h_j != 0 or deg f >= r >= T_j/2".
- Constant f (deg 0): then f(kP) = k for k in A forces |A| <= 1 when N < p, so T_j = 0 for all j; covered (vacuous), and h_j = -j != 0.
- The hypothesis N < p is stronger than needed: the proof uses only j <= N-1 < p (so p does not divide j), distinctness of kP and j < r. So N <= min(p, r) suffices (k = r gives O, which is allowed if f is regular at O). The stated "N < p is necessary" is therefore an overstatement; what is true is that N <= p is the sharp threshold on p (counterexample needs N >= p+1). Exhaustive test: all subsets A of {1..p}, p in {5,7,11}, all curves with r >= p: 26218 cases, 0 violations of deg_poly >= T/2.
- The p=5, r=7 counterexample is genuine: curve y^2 = x^3 + 2x + 1 over F_5 has 7 points, 1P = (0,1), 6P = (0,4), f = 1 agrees with k mod 5 on {1,6}, N=6 >= p, T_5 = 1, bound would require deg f >= 1/2 but deg f = 0. (Here N = 6 > p; N < r = 7 holds.) It shows N <= p is needed; it does not show N < p is needed.
VERDICT (1): correct with corrections (nonvanishing wording; hypothesis weakened to N <= min(p, r); "necessity of N < p" should read "N <= p necessary and sufficient for the stated range of j").

### Item (2): x-only, deg g >= S_j/3
- G = g∘x has degree 2 deg g (pole of order 2 deg g at O only). H_j(Q) = G(Q+jP)+G(Q-jP)-2G(Q)-2j^2 has poles at -jP, jP, O, each of order <= 2 deg g, so deg H_j <= 6 deg g (distinct points because r odd, 0<j<r). Zero at kP when k-j, k, k+j in A: (k+j)^2+(k-j)^2-2k^2-2j^2 = 0. Correct.
- Nonvanishing: if deg g >= 1, H_j has a pole of order exactly 2 deg g at jP (neither G nor G∘tau_{jP} is singular there), so H_j != 0; if g is constant H_j = -2j^2 != 0 mod p (p odd, p does not divide j). Correct and simpler than (1) (no orbit argument).
- H_j is even, so it also vanishes at -kP. The claimed bound needs 2 S_j DISTINCT zeros (6 deg g >= 2 S_j). The points kP, -kP = (r-k)P coincide for k, k' in K_j exactly when k + k' = r. If r != p this cannot occur for k != k' in A: x(kP)=x(k'P) would force g-values k^2 = k'^2 mod p, i.e. p | r(k'-k) with 0<|k'-k|<N<p, impossible. Hence bound holds for r != p. If r = p (anomalous curve), A may contain complementary pairs (k, p-k), x(kP)=x((p-k)P) and k^2 = (p-k)^2 mod p consistently, and the zero count drops to the number of distinct classes {k, p-k} of K_j, which can be as small as S_j/2. The correct statement is deg g >= (number of ± classes of K_j)/3 >= S_j/6 in general.
