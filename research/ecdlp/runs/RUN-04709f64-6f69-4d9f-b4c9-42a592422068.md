## Technique (new): additive (cuspidal) degeneration + Schwartz-Zippel
Route (a) of the task was followed, but with the ADDITIVE degeneration A = B = 0 (cusp y^2 = x^3, group G_a, x(kP) = x0/k^2) instead of the nodal one. It is exactly computable and, for the target k^2, p-uniform. The idea: c_{N-1} is a regular function of tau = (A, x0, y0) in F_p^3 (B := y0^2 - x0^3 - A x0) on the locus where kP != O and the nodes are distinct; if it is nonzero at one cusp point tau0 = (0,1,1), it is a nonzero polynomial after clearing denominators, so it vanishes on few tau.

## Statements and proofs

**D0 (cusp divided differences; elementary, proved).** Nodes y_k = x0/k^2 (k=1..n, in a field where 1/k^2 are distinct and defined). (i) Target k^2: f[y_1..y_{j+1}] = (-1)^j (j+1)!^2 x0^{-j} != 0 (divided differences of 1/y are (-1)^j / prod y_i; here f(y_k) = k^2 = x0/y_k). (ii) Target k, characteristic 0: f(y) = x0^{1/2} y^{-1/2}-type; for real positive distinct nodes the mean value theorem gives f[y_1..y_{j+1}] = f^{(j)}(xi)/j!, f^{(j)}(y) = (-1)^j (2j-1)!!/2^j y^{-1/2-j} != 0 (take x0 = 1). So every c_j(0) is a nonzero rational number, sign (-1)^j. (iii) Target k, char p > 2N: c_{N-1}(0) mod p is the reduction of that rational number (denominators are products of (l^2 - i^2), prime to p); it is nonzero iff p does not divide the numerator Num_N of c_{N-1}(0). Num_N has prime factors > 2N (e.g. p = 11, N = 3: points (1,1),(3,2),(5,3) collinear mod 11), so this is a genuine condition (see check B). Define Bad_N = {p > 2N prime : p | Num_N}; finite, computable.

**D1 (division-polynomial facts used; standard identities, checked numerically, not re-proved).** psi_m weighted homogeneous of weight m^2-1 (wt x=2, y=3, A=4, B=6); x_m = x - psi_{m-1}psi_{m+1}/psi_m^2; x_i - x_l = -psi_{i+l}psi_{i-l}/(psi_i^2 psi_l^2); psi_m(P) = 0 iff mP = O (P affine, nonsingular curve); at the cusp point (A=B=0, x=y=1) psi_m = m (check C).

**Theorem D (proof attempt, complete modulo the standard facts in D1).** Let p be prime, N >= 3, p > 2N, and set w_N := (N-1)[ N(N+1)(2N+1)/6 - (N+2)/2 ] = N^4/3 + O(N^3). Let Z = {tau in F_p^3 : curve nonsingular, kP != O and x_1..x_N distinct (i.e. (i+-l)P != O, 1<=l<i<=N) , c_{N-1} = 0}. Then
 (a) target k^2: |Z| <= w_N p^2 (fraction <= w_N/p of the p^3 triples (A, x0, y0)), for every such p;
 (b) target k: the same bound whenever p not in Bad_N.
Hence for such p, all but a fraction w_N/p of (curve, point) pairs have mindeg(N) = N-1 exactly (deficit 0) [by L1]; deficits D >= D0 >= 1 are a subset.
Proof. On U = {prod_{m<=2N-1} psi_m(tau) != 0}, write c_{N-1} = sum_i f_i prod_{l != i}(x_i-x_l)^{-1}. By D1, 1/prod_{l!=i}(x_i-x_l) = prod_{l!=i} (-theta_i theta_l/(psi_{i+l}psi_{i-l})) with theta = psi^2 (signs by ordering). Multiply by W = prod_{a<b} psi_{a+b}psi_{b-a}: c_{N-1} = Num/W with Num = sum_i +-f_i theta_i^{N-1} prod_{l!=i}theta_l * prod_{a<b; a,b != i} psi_{a+b}psi_{b-a} a polynomial in (A,B,x0,y0). A weight count shows every summand has the same weight 2(N-1)S2 - (N-1)(N+2), S2 = sum l^2 (independent of i; hand-derived, w_N equals half of it; N=2 gives 6 = wt(psi_2^2), consistent with c_1 = -psi_2^2/psi_3). Substituting B = y0^2-x0^3-A x0 keeps weight, and every variable has weight >= 2, so deg Num <= w_N. At tau0 = (0,1,1): psi_m(tau0) = m != 0 for m < p, so tau0 in U, x_k(tau0) = 1/k^2, and (Num/W)(tau0) = cusp divided difference of D0, nonzero under (a) or (b)'s hypotheses. So Num is a nonzero polynomial of degree <= w_N, and Z is contained in its zero set; Schwartz-Zippel (unverified recollection of the standard lemma) gives |Z| <= w_N p^2. QED.

**Corollary D' (characteristic 0, generic).** Over Q(A,x0,y0) (and hence on a Zariski-open dense set of (A,B,P) over any field of characteristic 0 / in the cusp's neighbourhood), c_j != 0 for every j >= 0 and both targets, i.e. mindeg(N) = N-1 for every N. Proof: D0 (i),(ii) give nonvanishing at tau0, and the same specialisation argument. Numerically illustrated (check A: c_j(eps)/c_j(0) -> 1 as eps -> 0 on rational curves).

**Obstruction / sharpness remarks.** (1) The qualifier "generic" cannot be dropped: L3 (proved) gives deficit >= 1 on anomalous j=0 curves, and in char 0 the hypersurface c_2 = 0 (x1+x3 = 2x2) meets real curves (check D: sign change at A in (1.6,1.7), P=(1,1), B=-A) so there is no all-curves statement of this type. (2) The bound w_N/p is non-trivial only for N <~ (3p)^{1/4}; the true deficit frequency is ~1/p (check E), so the method loses a factor N^4. It improves alpha from 1/3 to 1 only for N <~ p^{1/4}, and only generically; for large N it gives no improvement on Theorem C. (3) For N > p^{1/4} the structure c_{N-1} = Num/W with deg Num ~N^4 means no argument via a single specialisation can reach N ~ p; a different input (e.g. sharper degree of the irreducible factors of Num, or Lang-Weil/Chebotarev on the hypersurface Num = 0 showing it is geometrically irreducible with ~p^2 points) would be needed.
