## Part (b) New hypotheses (all speculative unless stated)

### D1 — No cheap canonical form for scalar-multiplication orbits (Lattes dynamics)
1. Statement. For E/F_p, odd N = #E(F_p), m >= 2 coprime to N, phi_m(x(R)) = x(mR). (i) [proved sketch] any nonconstant polynomial h with h∘phi_m = h on X = x(E(F_p)\{O}) has deg h >= |X|/m^2. (ii) [conjecture, tested] the least such degree d* equals the generic value |X| - c + 1 (c = number of phi_m cycles), i.e. phi_m is indistinguishable from a random permutation of the same cycle type. Consequence (speculative): a walk on classes of the equivalence R ~ mR gains sqrt(class size) in steps but pays >= class size per canonicalisation, so no net gain unless the equivalence is generated by a finite-order automorphism.
2. Property used. h∘phi_m - h has numerator degree <= m^2 deg h and is nonzero because deg(h∘phi_m) = m^2 deg h (Lattes maps have no nonconstant invariant functions).
3. Why it might help. It is the clean negative boundary of the question "can equivalences beyond Aut(E) (negation, a few units) speed up rho?". A counterexample (low-degree invariants) would be the first algebraic handle on orbit canonicalisation.
4. To prove. (i) rigorous bookkeeping at x = infinity and 2-torsion (done for odd N here); (ii) needs an irreducibility/monodromy argument for iterated Lattes maps, hard; extension to a cost model in which canonicalisation is any straight-line program.
5. Invalidators. Any curve family with d* < |X| - c + 1 by a margin; or a non-polynomial (rational/higher-genus) class function of low degree.
6. Cheapest decisive test. Executed below.
7. Sources. Equivalence-class rho via automorphisms: Wiener and Zuccherato (SAC 1998) and Gallant-Lambert-Vanstone (CRYPTO 2000) — cited from memory, UNVERIFIED. Bos-Kleinjung-Lenstra negation-map analysis — from memory, UNVERIFIED. Novelty of (i)/(ii) NOT checked.

### D2 — ECDLP as recovering a diamond operator on X_1(r)
1. Statement (speculative). A pair (E,P),(E,Q=kP) of order-r points is a pair of F_p-points of the modular curve X_1(r) related by the diamond automorphism <k>. Claim: the Tate-normal-form coordinates (b_k,c_k) of (E,kP) are rational functions of (b_1,c_1) of degree Theta(k^2) with no sub-quadratic representation, so no low-complexity inversion k <- (b_k,c_k) exists; any gain must come from non-algebraic structure of the X_1(r) point set.
2. Property used. <k> acts as an automorphism of X_1(r) over Q; the quotient is X_0(r). Orbits are the fibres of the j-map.
3. Why it might help. It changes the group in which the problem lives: DL in Z/r becomes an automorphism-identification problem on a variety whose points over F_p are structured (cusps, Atkin-Lehner, Hecke correspondences T_l act on pairs).
4. To prove. Degree growth of <k>; whether Hecke correspondences give relations among (E,P) at neighbouring l-isogenous curves usable as relations in k (an isogeny walk that stays inside the pair space, which I argued earlier only reproduces the same k).
5. Invalidators. Degree is only O(log)-computable through the group law, i.e. it is the group law restated; isogeny images carry Q_i = kP_i with the same k, giving no new collisions.
6. Cheapest test. r <= 13: tabulate (b_k,c_k) and fit minimal-degree relations; mostly a consistency check (expect nothing). Not run.
7. Sources. Tate normal form / X_1(r) — standard (e.g. Husemoller, Elliptic Curves; from memory, UNVERIFIED). Isogeny-class random self-reducibility: Jao-Miller-Venkatesan, ASIACRYPT 2005, LNCS 3788 pp. 21-40, DOI 10.1007/11593447_2 (verified record; abstract: DL on same-order curves randomly reducible within near-equal endomorphism rings).

### D3 — Class-invariant endomorphism budget (what really depends on the isogeny class)
1. Statement. The number of efficiently usable equivalences for a walk is bounded by the elements of small norm in End(E) ⊇ Z[pi], pi^2 - t pi + p = 0. For a curve with t^2 - 4p of size ~ p (generic case, probability 1 - o(1) over curves), the shortest non-scalar element of Z[pi] has norm Omega(sqrt(p)), so the only "free" equivalences are +-1: speed-up factor <= sqrt 2, class-invariant. Speed-ups beyond that exist only in the sparse set of classes with t^2 - 4p = -D f^2, small D.
2. Property. Norm form of Z[pi] is x^2 + t x y + p y^2 with discriminant t^2 - 4p; End(E) is an order containing it, constant across the isogeny class up to the volcano level.
3. Why. Identifies exactly which curve choices (vs random ones) forfeit GLV-type speedups, supporting a classification of "weak classes".
4. To prove. Quantitative density of small-norm elements across all orders between Z[pi] and O_K; interaction with E(F_p) structure (units of order 4/6 vs cyclic point group).
5. Invalidators. Efficient non-algebraic equivalences (outside End, e.g. hash-defined) — not covered by the model; known results already likely contain this (GLV/Duursma-Gaudry-Morain 1999).
6. Cheapest test. Enumerate small primes, compute min nonscalar norm in Z[pi] versus p; trivially predicted. Not run.
7. Sources. Random self-reducibility (JMV above). Lenstra, "Complex multiplication structure of elliptic curves", J. Number Theory 56 (1996): E(F_p) as O-module — from memory, UNVERIFIED. GLV: from memory, UNVERIFIED.

### D4 — Lifting/lattice route is exactly the xedni obstruction (honest negative hypothesis)
1. Statement. For E/Q of rank rho >= 2 with generators P_i, reduction mod p identifies DL of Q = sum a_i P_i with finding a short vector in the relation lattice L = {n in Z^rho : sum n_i P_i = O mod p}. Heights of lifts grow as k^2 * (canonical height), so any lift of a size-p subgroup element has Theta(p^2)-bit data unless the lattice L is known; knowing L is equivalent to solving DLs. Conclusion: no lattice shortcut without an oracle for L.
2. Property. Reduction is a group homomorphism E(Q) -> E(F_p); heights are quadratic forms.
3. Why (speculative). If L could be sampled via a cheap structure (e.g. Heegner/CM points with known reductions) relations might come for free.
4. To prove. Min over lifts of height, lower bounds on lattice determinant (~ index = r).
5. Invalidators. Already recorded in the literature: xedni calculus.
6. Cheapest test. Not run; literature outcome suffices.
7. Sources (verified records). J. Silverman, "The xedni calculus and the elliptic curve discrete logarithm problem", Des. Codes Cryptogr. 20 (2000) 5-40, DOI 10.1023/A:1008312401197. Jacobson-Koblitz-Silverman-Stein-Teske, "Analysis of the xedni calculus attack", same issue, pp. 41-64; abstract: experiments show odds against a suitable lifting are prohibitive.

### D5 — Multi-instance amortisation beyond sqrt(M r): non-generic precomputation
1. Statement (speculative). Generic multi-instance lower bounds are ~sqrt(M r) total steps for M instances (generic-group model), and non-uniform precomputation reaches ~r^{1/3} online time with ~r^{2/3} advice in the generic model. Hypothesis: use of the curve's explicit Lattes/x-line structure (e.g. canonical orbit labels via division polynomials) cannot beat these; a refutation would need a non-generic structured set S of size ~ r^{1/2} with membership-and-index computable in polylog time.
2. Property. Generic-group counting; D1 shows orbit labels cost class size.
3. Why. States the amortisation boundary the lab can cite.
4. To prove. The structured-set claim reduces to D1 (class functions) and to the SPIC/interpolation exclusions.
5. Invalidators. A cheap index function on a large subset (would break D1/Theorem A).
6. Test. None independent of D1.
7. Sources. Kuhn-Struik, "Random walks revisited: extensions of Pollard's rho algorithm for computing multiple discrete logarithms", SAC 2001, pp. 212-229 (bibliographic record verified; claims about sqrt(M r) are from memory, UNVERIFIED). Bernstein-Lange, "Non-uniform cracks in the concrete: the power of free precomputation", ASIACRYPT 2013 (record verified; the r^{1/3}/r^{2/3} figures from memory, UNVERIFIED).
