## (b) Routes the lab has not tested, with priors

Priors are my judgment of the chance that the route yields a generic sub-sqrt(p) prime-field algorithm; they are not
calibrated. Cheap decisive tests are suggested where I can see one. "Tested" below refers to what STATUS.md reports.

1. Dedicated (non-Groebner) relation finder at m = 4 or 5, S1's stated open problem. Prior about 1%. The lab tested finders at
   m = 2 and 3 (inventors D, F). A paper-level test: what finder cost is needed? See (c)(2). A new idea for solving
   S_{m+1}(x_1..x_m, X)=0 with x_i in a structured base in time below p^{1/4} at m = 4 is required; I have none, and I found
   none in the literature.
2. Mahalanobis-Mallick "Problem L" and the 2026 zero-minor follow-up (S14, S15). Prior below 0.5%. Not in the lab. By the stated
   success probability the 2017 version has exponent about 1; the open question is whether the 2026 solver changes this. Needs the
   full text of S15 (I read the abstract only). A cheap check is to implement Problem L on toy curves and measure passes
   per success, using the lab's fit alpha*sqrt(r) + gamma discipline.
3. Isogeny-distance to structured curves (backlog item). Prior about 1%. I retrieved no 2015-2026 source on it, so I cannot
   cite a literature status; random self-reduction via isogenies is a pre-2015 idea that I did not retrieve. Inventor B tested
   orbits and volcano ascent only.
4. Large-m / subexponential regime of Semaev index calculus with a non-Groebner finder. Prior well below 1%. S4 (NP-completeness
   of deciding zeros of S_r, under an assumption) is an obstruction to any large-m finder that is generic in r.
5. Machine-learning style attacks beyond predicates already tested (ECDLP-41, HYP-130de9b1). Prior well below 1%. S22 predicts null results for gradient methods on
   parity bits, consistent with the lab's nulls. S21 is unvetted and self-described as overfitting.
6. Using the Epoch AI public ECDLP instance (S24) as an external benchmark. Not an algorithm route; prior of hidden structure
   very small (the page itself lists "unexpected structure" as a risk). I did not capture the instance parameters.
7. Not routes, for the record: quasi-subfield polynomials (char small only, no speedup, S8), Weil descent (needs extension
   field), quantum-inspired classical (nothing found), Diem/Gaudry-type (extension fields).

## (c) Contradictions and sharpenings of ledger results

Everything in this section is my own derivation from quoted sources; it is unreviewed and should be checked before being
copied into any status file.

1. Inventor D's obstacle matches PKM's own criterion. STATUS says "finder cost >= p^{1/2-1/(2m)} per relation vs required
   < p^{1/2-1/m}". S1 (full text read) states exactly the second quantity (T < p^{1/2-1/m}) as the condition to beat sqrt(p).
   Agreement, not contradiction; the needed finder cost is not new.
2. Possible sharpening of "Only m >= 3 (S_4) remains" (inventor E, round 14). Take S1's cost model, with base size s = deg L:
   cost about m! p T / s^{m-1} + s^omega. With free finder (T = 1) and omega = 2 the optimum is s = p^{1/(m+1)} (m-1+omega = m+1),
   cost p^{2/(m+1)}: m = 3 ties sqrt(p) (p^{2/4}), m = 2 gives p^{2/3}, m = 4 gives p^{2/5}. With finder cost p^t, m = 4
   needs t < 1/4 (derived: balance p^{1+t}/s^3 = s^2). So in S1's model m = 3 cannot win even with a free finder and m >= 4 is
   needed; this is stronger than "m >= 3 remains". Caveat: inventor E/F's supply bound is for closed relations inside the
   base (closed S_3 triples, s >= (3r)^{1/3} for m = 3), while S1's model uses randomised-target relations aP + bQ = sum of m base points,
   whose supply is unlimited and whose cost is the finder. I do not know whether E/F's accounting excludes the
   randomised-target form; if it does not, their "supply floor" and S1's finder-cost model are different constraints and
   both should be stated. Resolving this needs the E/F run records, which I did not re-read.
3. Inventor F's m = 3 cost (about 1.5 r^{2/3}, exponent 0.651): consistent with both models above. Supply floor
   s >= (3r)^{1/3} plus linear algebra s^2 gives >= r^{2/3} directly, and S1's model gives p^{1/2} at best at T = 1.
   Not contradicted. Not sharpened beyond "m = 3 cannot win with omega = 2", unless dense/sparse linear algebra exponents or
   structured matrices break s^2. I would note that s^omega with omega < 2 is not known.
4. Inventors C and H (precomputation): the retrieved bound ST^2 = Omega~(eps N), tight up to logs (S16), is exactly the frontier
   the lab reproduced (S T^2 ~ r). Sharpening from S20: for non-adaptive algorithms the online time cannot go below sqrt(N)
   unless S > sqrt(N) bits, which is a stronger constraint than ST^2 for tables used with fixed query sets. Since inventor H's
   "sorted tables / comparison trees" are presumably non-adaptive in the query set, S20 gives a theoretical reason for H's
   null result (I did not check H's definition of adaptivity).
5. A consistency check I made (derived): index-calculus-with-advice at m = 3 stores S ~ p^{1/3} base logs and pays online cost
   about m! T; with D's finder cost T ~ p^{1/3} this gives S T^2 ~ p, i.e. it lands on the Corrigan-Gibbs-Kogan frontier,
   not below it. Any improvement below the frontier would require T < p^{1/3} at m = 3.
6. HYP-130de9b1 / ECDLP-41 (no near-character; integer-structure distinguishers null): S22's result that parity-bit gradients
   concentrate is a literature analogue for the ML framing, not a contradiction.
7. Literature that is NOT in the ledger by name (to add as citations, not as results): Kosters-Yeo S4 (NP-hardness of zeros of S_r),
   Euler-Petit S8, Kousidis-Wiemers S6, Yokoyama et al. S10 (lower bound on Groebner cost for naive Semaev), Mahalanobis-Mallick S14, Dinur-Keller-Marmor S20.
   I grepped research/ecdlp for 'P-224|Mahalanobis|zero minor|Takhanov|Dinur|quasi-subfield|Yokoyama'; only RUN-62168bb1 matched,
   and its text shows the match is 'P-224' (PKM), not the other names. Kosters-Yeo and Kousidis-Wiemers were not grepped. So absence from the ledger is
   likely but unconfirmed.
