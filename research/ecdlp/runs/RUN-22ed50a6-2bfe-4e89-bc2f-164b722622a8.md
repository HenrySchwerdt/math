## 1. Question and inputs
Can a Groebner / resultant / Semaev-S_3,S_4 finder on an algebraically defined factor base (small x, coset of a subgroup of F_p^*, image of a low-degree map) produce relations cheaply enough that relation search + linear algebra < sqrt(r)?

What PKM say (read directly): factor base F = {x : L(x)=0}, L a composition of small-degree maps (subgroup of smooth order: L_j(x)=x^{p_j}); relation search = "generalized root-finding problem" f(X_1..X_m)=0, L(X_i)=0; cost

## 2. Item 1 - mechanism (and the finders compared)
Index calculus needs s unknown logs and s relations. With |V|=s, m summands and one target equation mod p, a relation exists with probability pi ~ s^m/(m! p). The quantity that matters is the per-relation finder cost T_rel; total = s T_rel + LA. The algebraic finders try to make T_rel cheaper than a collision search.

F1 Semaev S_3 / S_4 enumeration (fix all but one x_i, solve the univariate S in the last, test membership).
F2 Resultant + gcd (PKM/Semaev-1 style for m=2): eliminate x_2 from {S_3(x1,x2,x_T)=0, x2^d=c} giving h(x1) of degree ~4d; gcd with x1^d - c (reduction mod x1^d-c is a coefficient fold, O(d)); or evaluate h on the coset by an NTT of length d (d=2^n | p-1). Cost Otilde(d)=Otilde(|V|) per target with large constants, same exponent as F1; NOT implemented (it computes the same solution set as F1, see check below).
F3 Groebner basis on PKM chain system (x_{j+1}=L_j(x_j)) with hybrid/field equations: m=2 measured here with sympy; scaling ~d^{2.1-3.0} (table below) and PKM's Magma scaling ~d^3: worse than F1.
F4 Lattice / Coppersmith decomposition on small-x or Farey bases: measured negative by inventor A (RUN-ff67c875, candidate A2: S/E = 0 at 16/20/24 bits); the linearised 9-dim lattice has shortest vectors ~p^{1/9} while solutions have size ~p^{2/3}.
F5 Birthday/MITM join (inventor A): sqrt(p s) per batch (measured 29-43x rho at 24 bits).
Chosen prototype "D2" = F1 for m=2 on the PKM multiplicative-coset base V = {x in g*mu_d : x^3+ax+b square}, d=2^n | p-1, plus a small-x control "D2s" of identical size.

## 3. Item 2 - pseudocode / prototype (`d2lib.py`, `run_d2.py`)
```
FB:   zeta = element of exact order d=2^n; V = {g zeta^i} filtered by curve membership, one y each (Tonelli-Shanks)
loop: T = aP+bQ  (32-entry branching walk, 1 addition per new target)
      for each signed v in V:  W = T+v ; if x(W) in V:  T = W - v   -> relation  a + b k = s1 l(u1) + s2 l(u2)  (mod r)
      (vectorised numpy over V; d additions per target counted)
      insert each relation row into incremental sparse-aware Gaussian elimination over F_r, columns (l_1..l_s, k)
      stop when a pivot row contains only k  -> k = rhs ; check kP = Q
```
Instances: p = 1 mod 2^n, prime order r found by BSGS on a random point (any size up to 28 bits in < 1 s; cross-checked against `Curve.order()` at 12 and 14 bits: 3299, 13999 equal). `t_smoke.py` (evidence 3ca5ad8a): all 1,581 relations over 6 curves (12/14 bits) satisfy the relation with brute-force true logs (bad = 0), and the pipeline returns correct k for 12 of 12 coset/small-x runs.
Gröbner cross-check (`groebner_check.py`, sympy, lex, GF(p), evidence 8a230174): solution sets of {S_3(x1,x2,x_T), x1^d-c, x2^d-c} equal the exhaustive pair list at all 4 sizes:

Time ratios per doubling of d: 4.2, 6.8, 7.9 (exponent 2.1 -> 3.0; trend matches PKM Table 4). Sage/Magma/Singular are not installed; sympy is far too slow beyond d ~ 128, so Groebner could not be run at 16-28 bits (stated limitation, not a result about Groebner at those sizes).

## 5. Item 4 - complexity model
Let s=|V| (x-values), pi = probability a random point is V+V (measured 0.41-0.48 at d ~ sqrt p, matching 1-exp(-d^2/(2p))).
- F1/F2 per target: Theta~(d) (=s*2 additions). Per relation: T_rel = d/(pi * rel/target) ~ 2p/d... with d = sqrt p this is ~sqrt(p). Relations needed ~0.9 s (cycles in the 2-term relation graph pin k; LA mults measured 1.7e4 at 28 bits vs 4.5e7 finder additions, so LA is < 0.1%).
  Total ~ s * 2p/d ~ p, independent of the choice of d (D2b d~p^{1/3} measured the same, alpha 1.075). Memory O(s); preprocessing O(d sqrt-ops).
- Required for success (PKM formula): T < p^{1/2-1/m}. m=2: T = O(1), impossible (target generation alone costs 1 addition/relation attempt). m=3: need p^{1/6} (ECDLP-16: not achieved). m=4: p^{1/4}, LA s^2 = p^{1/2} already ties rho. LA beats rho only for m>=5 (sparse, s^2=p^{2/m}); then T < p^{1/2-1/m}.
- Heuristic ceiling for every finder that only *tests/hashes candidates* (F1, F2, F5): T >= |V|^{ceil((m-1)/2)} ~ p^{1/2-1/(2m)} (m odd) — above the requirement p^{1/2-1/m} by a factor p^{1/(2m)}. An algebraic finder must therefore be strictly below square-root-of-search-space, i.e. exploit non-generic structure of S_{m+1}.
- Gröbner (F3): per-relation time measured/PKM ~ d^{2.1-3.4} (m=2) = p^{1.05..1.7} per relation; no demonstrated asymptotic below F1; PKM state asymptotics are unknown.
- Sparse-LA is not the obstacle at m=2; it is at m=3,4 (cf. ECDLP-16: 3p^{2/3} already > sqrt p for |V| = p^{1/3}).

## 7. Item 6 - exact obstacle
Cost per relation is >= Theta(sqrt r) for every implemented/analysed finder on a prime-field factor base, because the finder must locate a point of the hypersurface S_{m+1}=0 inside V^m and the algebra of S_{m+1} offers no cheaper route than (a) enumerating one side (|V|^{m-1}), (b) a collision join (|V|^{ceil((m-1)/2)}), or (c) Groebner/resultant elimination, which on the PKM systems collapses to a univariate polynomial of degree ~|V|, i.e. enumeration with larger constants (verified: same solution set; time ~d^3). Quantitatively, PKM's own accounting demands T < p^{1/2-1/m}; the best verified finder sits at p^{1/2-1/(2m)}. Weil restriction (Gaudry/Diem) gets m equations over a subfield from one over the extension - the lever absent over F_p: there is no subfield, so the "1 equation, m unknowns, |V|^m/p ~ 1 solutions" count cannot be turned into a low-dimensional system (F4, lattice route: rank-one Veronese constraint is not a lattice condition). To win one would need either a rational parametrisation/ fibration of S_3=0 compatible with a small factor base, or a Groebner degree of regularity bounded independent of |V| *and* a polynomial-size system - PKM observe D_reg ~ 4-6 but time still ~d^3 because the systems have d-dependent size.
