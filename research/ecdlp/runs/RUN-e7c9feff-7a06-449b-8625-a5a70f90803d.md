## Target ladder
Common conventions. Instance: field F_q (encoded by p, and a modulus polynomial if q=p^e), curve (a,b), P, Q, with promise Q in <P>. n = total encoded length, so log q <= n. r = ord(P). Two output conventions, which differ in difficulty and the lab must fix one: (R) any integer k in [0,#E) with kP=Q (relation); (M) the least non-negative k with kP=Q. Under (M), Q=-P yields ord(P)-1, hence ord(P): an order-finding problem not obviously poly-time without factoring #E (open; recollection). The lab's HYP-2de84d42 should say which.

### T1 Generic group oracle, group-operation count
- Model: Shoup (random injective encoding of Z_r) or Maurer (abstract group + equality tests); cost = number of oracle calls (add, negate, equality); bit cost ignored. Input: oracle handles for P, Q, r known.
- Statement: any (possibly randomized) algorithm making T oracle calls succeeds with probability O(T^2/p_max) where p_max is the largest prime factor of r (V1); equivalently T = Omega(sqrt p_max) calls are needed for constant success probability. For deterministic algorithms Nechaev (unverified).
- Status: o(sqrt r) impossible in this model (known). Upper bound: BSGS O(sqrt r) calls and O(sqrt r) memory (deterministic), Pollard rho O(sqrt r) calls, O(1) memory, heuristic/randomized; Pohlig-Hellman reduces to prime-power parts, needs the factorization of r.
- Relation to PI-verified facts: HYP-57d71f43 is a different, weaker statement (reachability: an addition/subtraction SLP of length L only produces Q = n P with |n| <= 2^L, so L >= log2(r-1) - 1 to reach an arbitrary Q from P alone). It does not give sqrt r; the sqrt r bound needs a collision/probabilistic argument (the algorithm sees P and Q; length-L programs yield aP+bQ with |a|,|b| <= 2^L, and a success needs two distinct programs/handles with equal value, hence the birthday-type T^2/r).
- Cheapest proof obligation: Lean-formalize the Schwartz-Zippel-style argument for V1 (bound: probability that two distinct linear forms in the unknown (x) collide over T queries <= C(T,2)/r). Falsification: none (theorem); the relevant question is whether the generic model is the right model for "universal" ECDLP: it is not, because the target is a bit-complexity claim about explicit curves.

### T2 Generic with preprocessing (non-uniform advice)
- Model: algorithm = (preprocessing phase, S-bit advice depending on the group only, online phase T oracle calls); fixed group; success probability eps over Q.
- Statement: S * T^2 = Omega~(eps * N) (V3). Matching attacks with S*T^2 = O~(N) exist (V3; and V5 table l^(1/3) with 1.77 l^(1/3) online ops for l-order group); non-uniform P-256 "cracks" (V4).
- Status: lower bound known (generic model); upper bound known (generic). Achievable: e.g. S=T=N^(1/3) with N^(2/3) preprocessing.
- Relevance: the O(n log n) target is uniform (one algorithm for all curves) and worst-case over (curve, P, Q), so T2 gives no lower bound on it and no route to it; T2 only quantifies what non-uniformity could buy for a single fixed curve. Note precomputation cost N^(2/3) is not charged.
- Proof obligation/falsification: check the matching-upper-bound constants (V5 is average-case in the interval setting); cheap test: implement the table method on toy groups and measure oracle calls. Not done here.

### T3 Algebraic models (representation-specific, but no bit tricks)
Two sub-models with exact statements. Proofs are in the next section (Theorems A, A', B); status "proof-attempt" until reviewed.
- T3a Polynomial/rational-function interpolation. Model: E/F_q short Weierstrass, P of order r, find f in F_q[X,Y] (or F_q(E)) with f(kP) = k * 1_{F_q} for 1 <= k <= N <= r-1. Complexity measure: total degree / pole degree. Known: for F_p^* the analogous exact-interpolation degree bound is trivial (multiplicative translation x -> gx: f(gx) - f(x) - 1 has p-2 roots, so degree >= p-2) and the hard, published statement is approximate interpolation, V6 (sqrt(2Dp)) improved by V7. For elliptic curves V8, V9 give polynomial degree lower bounds (exact theorem statements NOT seen by me). Our Theorem A gives pole degree >= (N-1)/2 and polynomial total degree >= (N-1)/6; the empirical minimum of the pole order over toy curves is exactly r in 40/40 tested cases (below), so an unproved tight statement is "m* = r".
- T3b Algebraic straight-line programs. Model: SLPs over F_q with operations +,-,*,/ (unit cost per op), inputs x(Q), y(Q), a, b, constants allowed in F_q, no branching, division only by non-zero values at the instance; output k mod p. Theorem A' => length >= log2((N-1)/12). Bit cost: each op on generic n-bit residues costs Omega(n) bit operations, giving Omega(n^2) bit ops (assuming every op charged Omega(log q); a model assumption, not a theorem). Hence T5-type quasi-linear cost is impossible in this specific model (output k mod p as an F_p element obtained by field operations alone). Caveat: the bound only requires degree 2^s, so it is Omega(n) operations: Theta(n) is the best this method can ever give, and no algebraic SLP of poly(n) length is known (open).
- Status: lower bounds in these models known/proof-attempt, upper bounds open (no poly-size SLP known). Real attacks leave the model (see below).
- Why this does not contradict the anomalous-curve algorithm (V12): Smart/Semaev/Satoh-Araki lift to Z/p^2 or p-adics (ring operations beyond F_p, and p-adic logs); a rational function with f(kP)=k exists in characteristic r=p by Artin-Schreier (f(Q+P)=f(Q)+1) but has pole degree >= r, so degree >= r/6 polynomial; the quick algorithm does not compute it as an F_p-algebraic function. Also empirically m*=r=p on an anomalous toy curve (p=103).
- Cheapest proof obligation: review Theorems A/A'; Lean-formalize Theorem B (univariate, elementary). Falsification: find an interpolating f of pole order < (N-1)/2 (impossible if A is right); a toy search found none (m*=r).

### T4 Polynomial-time universal ECDLP
- Model: multitape TM (or word RAM with log n-bit words), classical, uniform, deterministic or randomized (specify: Las Vegas/Monte Carlo with error <= 1/3 and exact success criterion), worst case over all (q, a, b, P, Q) with Q in <P>, output convention (R) or (M).
- Statement: there is an algorithm running in time n^c for some constant c.
- Status: open. Known unconditional bounds: upper O~(sqrt r) group operations (each O(M(n)) bit ops, M(n) = n log n by the recollected Harvey-van der Hoeven), i.e. exp(n/2) overall; no super-linear unconditional lower bound in the bit model beyond reading the input (Omega(n)).
- Implications if true: breaks all ECC; shows ECDLP is far easier than the generic bound (no contradiction since T1 is about oracle algorithms); would not contradict T2/T3 (non-generic, non-algebraic-SLP). Does not follow from quantum results (Shor/Proos-Zalka are quantum; unverified recollection). Under (M) it would also put order-finding in P for these groups (modelling consequence, see above).
- Cheapest falsification test: an algorithm family that is polynomial on a structured subfamily that provably contains all prime-field curves of prime order of a fixed size class would already be big news; no cheap test.

### T5 Quasi-linear universal ECDLP
- Model: as T4; statement: time O(n log n) (or O(n polylog n)) bit operations.
- Status: open and, as far as I can tell, far stronger than T4; no evidence supports it. Reading the input is Omega(n), so it is within polylog of the trivial lower bound.
- Relation to verification: checking a candidate k with kP=Q takes ~ log r group operations (double-and-add) each O(1) field mults of cost M(n), i.e. O(n * M(n)) = O(n^2 log n) bit operations with standard arithmetic. Quasi-linear scalar multiplication is not known to me (open/unverified). So the target is a factor Theta~(n) below the cost of the best-known verification of its own output: an algorithm running in n log n cannot afford to verify its answer by scalar multiplication. Combined with Theorem A' it also rules out any algorithm of the "algebraic SLP outputting k mod p" type (Omega(n^2) bit ops there under the stated charging).
- Cheapest falsification test: find a model-independent argument that DL needs more than quasi-linear time (none known), or an unconditional lower bound for scalar multiplication beyond n M(n)/log n (none known to me). Open.

### T6 Restricted families
- Anomalous curves (#E(F_p) = p): polynomial-time via p-adic lifting (Smart, Semaev, Satoh-Araki; V12). Bit-complexity exponent not verified by me; known as polynomial in log p.
- Small embedding degree (supersingular k <= 6, or any k): MOV/Frey-Ruck reduce ECDLP in <P> to DL in F_{q^k}^* (V10); cost = pairing + F_{q^k} DL, subexponential L_{q^k}(1/3) via NFS (recollection); polynomial only when q^k is small relative to... it is subexponential in k log q, so effective for k = O(log q) only.
- GHS/Weil descent (extension fields F_{q^m}, composite degree): GHS (V11) transfers ECDLP to a genus g curve over F_q where index calculus (Gaudry, Diem, recollection) can be sub-generic for suitable m; applies to a subset of curves over fields of composite extension degree.
- Prime fields, large embedding degree, #E not anomalous (the cryptographic case): open for anything better than O~(sqrt r) generic. Index calculus via summation polynomials (Semaev, V13; Gaudry; Diem) has not produced a subexponential bound over prime fields. Whether any general speed-up exists is open.
- Cheapest falsification test: for a structured toy class (e.g. curves with a given embedding degree), measure the proportion of that class whose ECDLP is solved by MOV in < sqrt r operations; the existing round experiments may already cover this (not read per instruction).

## New lower-bound proposals

Notation. E: y^2 = x^3 + a x + b over F_q, char != 2, 3, P of order r. Pole order of a regular function on E^aff = E minus {O}: ord_O(1/f); basis x^i, x^i y with orders 2i, 2i+3. For f in F_q[X,Y], reduce modulo the curve equation; the pole order m(f) <= 3 deg f (and <= 2 deg f + 1 for deg_Y <= 1 reduced form).

### Theorem A (proof attempt; exact degree bound for polynomial interpolation of the DL)
Let 2 <= N <= r-1 and f in F_q[X,Y] with f(kP) = k * 1_{F_q} for all 1 <= k <= N. Then the pole order m of f at O satisfies m >= (N-1)/2, hence deg f >= (N-1)/6. (If reduced to deg_Y <= 1: deg f >= (N-2)/4 roughly.) No condition relating q, r or char to r.
Proof sketch. Let h(Q) = f(Q+P) - f(Q) - 1, a rational function on E. f regular on E^aff, so f has a pole of order m >= 1 only at O (m=0 would make f constant, contradicting f(P)=1, f(2P)=2). The translate f o tau_P has a pole of order m at -P only (P != O so -P != O), where f is regular. Therefore h has a pole of order exactly m at -P, in particular h != 0, and its pole divisor has degree 2m. A non-zero rational function has at most as many zeros (with multiplicity) as its pole degree. h vanishes at kP for 1 <= k <= N-1 (both kP and (k+1)P are in the interpolation set), which are N-1 distinct points since N-1 < r. So N-1 <= 2m <= 6 deg f. QED.
Tightness: toy computation gives minimal pole order exactly r (not just >= (r-2)/2), so the constant is not tight; conjecture m* >= r-1 (open, not proved).
Rational-function version (Theorem A'): if f = u/v in F_q(E) is regular at kP with f(kP)=k for 1 <= k <= N, then the pole degree of f is >= (N-1)/2, and deg u + deg v >= (N-1)/12 for the bound in total degrees. Proof: as above with h = f o tau_P - f - 1. h has pole divisor of degree <= 2 deg(f)_infty. If h = 0, then pole set of f is invariant under tau_P, every orbit has r > (N-1)/2 points so deg(f)_infty >= r (this case really happens when p | r by Artin-Schreier, so the argument must not claim h != 0 in general); otherwise zeros >= N-1. A straight-line program with s operations in {+,-,*,/} on (x,y) has numerator/denominator degrees <= 2^s, and its pole degree is <= 6 * 2^s (pole of u/v at O of order <= 3 deg u + 3 deg v at most), so s >= log2((N-1)/12).
Duplication check: probably duplicates the polynomial-interpolation degree bounds of Lange-Winterhof (V8) and Satoh (V9), whose precise statements I could not retrieve. The translation trick g(gx) = g(x) + 1 is the standard finite-field argument. The tension with V6/V7 is: those are the hard approximate (partial agreement) results; ours is exact interpolation, where this trivial argument works. The partial-agreement version for elliptic curves (a function f of degree D agrees with k on at most about sqrt(D r) points of <P>) is the genuinely open/novel analogue of V6/V7 for curves.

### Theorem B (proof attempt; Lean candidate; elementary, x-only)
Let char F_q = p > 2, r odd and the r-1 points kP distinct with distinct x-coordinates for 1 <= k <= (r-1)/2. Let g in F_p[X] with g(x(kP)) = k^2 mod p for 1 <= k <= (r-1)/2 (this is the "folded" k <-> r-k identification, since x(kP) = x(-kP); k^2 is an example of a nonlinear target making the argument work through a quadratic relation). Then deg g >= (r-5)/6.
Proof sketch. Write D = deg g >= 1, x_P = x(P), s(x) = x(Q+P) + x(Q-P) = [2(x x_P + a)(x + x_P) + 4b]/(x-x_P)^2, t(x) = x(Q+P) x(Q-P) = [(x x_P - a)^2 - 4b(x+x_P)]/(x-x_P)^2 (checked on 2519 cases, below). For a symmetric polynomial in x_+, x_- of weight <= D, g(x_+) + g(x_-) = N(x)/(x-x_P)^{2D} with deg N <= 2D (each of s,t has numerator degree 2 over (x-x_P)^2). At x = x(kP), 2 <= k <= (r-3)/2: x_+ = x((k+1)P), x_- = x((k-1)P), and g(x_+) + g(x_-) = (k+1)^2 + (k-1)^2 = 2k^2 + 2 = 2 g(x) + 2. Hence M(x) := N(x) - (2 g(x) + 2)(x-x_P)^{2D} vanishes at the (r-5)/2 distinct x(kP), 2 <= k <= (r-3)/2. deg M = 3D with leading coefficient -2 g_D != 0 (p odd), since deg N <= 2D < 3D. So 3D >= (r-5)/2. QED.
Toy data: minimal degree of g is exactly (r-3)/2 in 40/40 toy curves (so lower bound D >= (r-5)/6 is loose by a factor <= 3 asymptotically; conjecture D = (r-3)/2 always, as for generic interpolation; unproved).
Why a Lean candidate: only polynomial algebra (degree, leading coefficient, roots count <= degree) and the addition formulas for x(Q+-P) (Mathlib WeierstrassCurve.Affine has addX; sum/product formulas need a short lemma). No Riemann-Roch or divisors are needed, unlike Theorem A. Statement for Lean: for a Weierstrass curve over a field of char != 2 with P of odd order r and distinct x(kP) for k <= (r-1)/2, any g in F[X] with the stated interpolation has natDegree >= (r-5)/6.
Duplication check: Theorem B is a specialization of the same idea as A, probably covered by V8/V9 for the x-coordinate; the target k^2 and the relation via x(Q+P)+x(Q-P) are chosen so that no divisors are needed; I did not find this exact formulation (not exhaustive; recollection only).

### Remarks on what these bounds mean for the ladder
1. Degree lower bounds are of order r (= 2^Theta(n)) but algebraic circuits can reach degree 2^s with s ~ n, so the T3b bound is Theta(n) operations at best: matching verification-level scalar multiplication size. They are not a barrier to polynomial-size algebraic SLPs and do not touch bit-level algorithms.
2. They do prove: no *low-degree* (polynomial in n degree) interpolation exists, ruling out "evaluate a fixed small polynomial" strategies uniformly, including on anomalous curves.
3. Cheapest new falsifiable target: prove the partial-agreement version (analogue of V6/V7 for curves) with the Stepanov method; that is the natural open research direction.
