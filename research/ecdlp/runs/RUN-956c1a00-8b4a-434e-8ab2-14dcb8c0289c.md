## Verdict (one paragraph)
**Negative on every route; no prototype built (gate in PROTOCOL not met).** The source's technique is a generic exponent-reduction
for *Boolean* counting problems whose cost is 2^{f·n} in the number n of Boolean variables (all circuit wires included).
ECDLP enters only through a circuit of N(ell) = Theta~(ell^2..ell^3) wires (measured 48·ell^2.83, 95% CI [2.73,2.91] for the lab's
affine encoding, 503·ell^2.41 [2.29,2.56] for the ladder, over ell = 5..16 / 5..12), while rho costs 2^{ell/2}. By the paper's own
displayed parameters the algorithm is not even better than exhaustive search over all N wires until log2 N > 6.8e10. No
sparse-polynomial form of k -> x(kP) exists (ANF density 0.5, F_p-multilinear density ~1, measured). Nothing here changes the status of
HYP-2de84d42 (open, unproved). The source is external, not peer reviewed; we did not verify its theorem or its Lean claim.

## 2. Mechanism extracted (item 1: what could reveal information about k)
Setting: count x in {0,1}^n satisfying F = AND_e Phi_e(x_{I_e}) (k-CNF, <=3 occurrences/variable after sparsification and copying),
or common zeros of <= cn polynomials over **F_2**, each with <= (log n)^c monomials of degree <= k (Thm 2.2, 5.x).
- Write #F = sum_x prod_e Phi_e(x) (degree <= M <= 3n). Replace each variable occurrence Xv in clause e by a *replacement linear form*
  <P_{e,v}(T), X> with P(0)=e_v (restores the formula) and deg_T P <= R. H(T) = sum_x prod_e Phi_e(<P_{e,v}(T),x>) has H(0)=#F, deg H <= 3nR.
- At each of Q nonzero points t, choose a *design*: r groups S_g of the variables (|S_g| <= 2n/r), one assigned group per clause, and
  integer measurement matrices C_g with <= 2^{tau n} rows total and coefficient L1 norm <= D, such that every form P_{e,v}(t) depends on
  variables of other groups only through the shared measurements y_h = C_h x_h. Fix the measurement tuple y; the sum then factors over groups:
  H(t) = sum_y prod_g B_g(y) (eq. 2.6). Cost per evaluation: (2D+1)^{tau n} * r 2^{2n/r}.
- Recover H(0) from Taylor coefficients (orders <= q = floor(3nR/Q)) at t = 1..Q (inclusion-exclusion over U ⊆ E, |E| <= q; cost
  sum_{j<=q} C(n,j) 2^j ≈ (2en/q)^q) and rational interpolation. Low degree R << Q is obtained by a swap-matrix polynomial f(W0)
  construction (Sec. 4) so that "variable outside assigned group at only few points" can be killed by factors (1 - T/t).
- Ring/field: variables Boolean; counting is exact over Z (mod 2^{n+1}; Beigel-Tarui-type lift p_ell for the F_2 parity test, Sec. 5.1);
  interpolation over Q; polynomial equations only over **F_2**. Appendix D re-derives the same bound by contraction of *Boolean*
  tensor networks with s = #wires, tensor entries in (Z/2^P0)[V]/(V^ell).
- Exponent drivers: n (number of Boolean variables/wires, all auxiliary ones included), sparsity (<= polylog n monomials, <= cn equations),
  degree <= k constant, max occurrences per variable polylog. Time (n+m)^{O(1)} 2^{O(n loglog n / sqrt(log n))} (n/sqrt(log n) at bounded density).
  Own explicit parameters (Lemma 4.8, beta=1): lambda=ceil(log2 n), nu=ceil(log2 lambda), r=floor(sqrt(lambda)/nu^2), Q=floor(lambda/(128 nu)),
  R=4 ceil(sqrt(lambda)), tau=1/(r lambda), D=r^{2Q}.
- Information about k? **None specific.** The mechanism is oblivious to the group law: it speeds up counting for *any* formula with n
  variables. Any ECDLP use goes through "encode, then count" and inherits n.

### 3.2 Route D, direct CNF (E1; evidence `...command-9e27eb4f...`)
Minimal explicit n(ell): (i) information floor n >= ell (the key bits). (ii) Smallest polynomial-size encodings we can write down or
measure: Tseitin circuits with ell iterations of an ell-bit modular group addition. Measured (builds only, no solving):

| ell | 5 | 8 | 10 | 12 | 14 | 16 |
|---|---|---|---|---|---|---|
| affine double-and-add (round-10 encoder), median vars | 4.5k | 17.5k | 28.7k | 57.1k | 87.7k | 127.6k |
| x-only Montgomery ladder (round-11 encoder) | 24.9k | 73.2k | 130.5k | 198.7k | – | – |

OLS fits log2 vars vs log2 ell (bootstrap CI over instances, seed 7): affine 2.83 [2.73, 2.91]; ladder 2.41 [2.29, 2.56]. Schoolbook
modmul gives Theta(ell^3) asymptotically (fit exponents < 3 reflect small-size constants; extrapolation to 256+ bits is outside the
measured range and unreliable by a factor of several). With asymptotically fast multiplication Theta~(ell^2) is the best we can see
(ell iterations x Theta~(ell) bits per modmul), constants enormous; a fixed-base table encoding also costs >= Theta~(ell^2/log ell).
A truth-table encoding has n = ell exactly but m ≈ r clauses, so (n+m)^{O(1)} >= r: worse than rho. Whether n(ell) = O(ell polylog) is
possible is exactly the question of circuit complexity ~ell polylog for scalar multiplication; unknown, and would be remarkable in itself.

**Exact crossover (headline form, constant C):** time 2^{C n/sqrt(ln n)} (bounded density, true for Tseitin circuits) beats rho iff
  C n / sqrt(ln n) < ell/2  <=>  n/ell < sqrt(ln n)/(2C).
Since n >= ell, necessary: sqrt(ln n) > 2C. For n = c ell^a, a>1: need c ell^{a-1} < sqrt(ln c + a ln ell)/(2C), impossible for all
ell >= 1 when c >= 1, C >= 1 (LHS polynomial, RHS ~sqrt(log)). Even n = ell exactly would require ell > e^{4C^2} (C=1: ell > 55).
At the measured constants (C = 1 generous): ell = 256 needs 70.6M vs rho 128 (headline column in `out_q1.json`; ratio ~5.5e5).
**With the paper's explicit parameters** (3.1): even the idealised n = s·ell encodings beat rho only for log2 ell >= 5.35e11 (s=1),
3.6e12 (s=2), 2.3e13 (s=4), and not within log2 ell < 1e14 for s = 16 (`idealised_n_equals_s_times_ell` in out_q1.json). For measured
n ≈ 48 ell^2.8: no solution for any ell: f(log2 n) >= 2/r(log2 n) >= 2/sqrt(log2 n) ≈ 0.4 whereas the needed f < ell/(2n) ≈ 1/(100 ell^1.8).
Note additionally that the algorithm counts over *all* n wires; the trivial 2^ell enumeration of key bits (gates determined by inputs)
already beats 2^n, so to beat even brute force over k one needs n f < ell, i.e. essentially n ≈ ell with f<1.
Space: poly(n) (paper). Preprocessing: poly(ell) to build the CNF (ell doublings for constants C_i = 2^i P). Success probability 1 (deterministic).

### 3.3 Technique route, (a) summation-polynomial decomposition over F_p (E4+E5; evidence `...command-a1a83c92...`, `...97e6cf62...`)
Index calculus with factor base |V| = p^theta, m-fold decomposition S_{m+1}(x_1..x_m, x(R)) = 0, x_i in V.
- Free-oracle bound (valid for ANY decomposition method, even cost 0): trials = p^{1-(m-1)theta}, sparse linear algebra p^{2theta}, total
  p^{max(1-(m-1)theta, 2theta)}, minimized at theta = 1/(m+1): p^{2/(m+1)}. m=2: p^{2/3} > sqrt p (route dead regardless); m=3: p^{1/2} = rho
  (needs T_dec = O(1)); m>=4 beats rho only if log2 T_dec <= ((m-1)/(m+1) - 1/2) L (m=4: 0.10 L, m=5: 0.17 L, m=6: 0.21 L; table in `route_models.py`).
  Brute-force decomposition costs p^{(m-1)theta} = p^{(m-1)/(m+1)}, always ~p^{1/2} too slow at the m=3 optimum.
  This is the lab's known "decomposition cost" obstruction (ECDLP-16 etc.); the technique would have to save ~sqrt(p) over brute force on the
  free bits (m-1)theta L.
- Encoding the decomposition test for the technique: the free bits number (m-1)theta L < L, but the CNF of S_3 mod p has measured
  **N_dec = 45.5 (log2 p)^{1.996}** variables (m=2, log2 p = 8..64; larger m costs more). N_dec >> L, so exponent N_dec·f >= N_dec·(2/r) with r>=2... Needed
  N_dec f(log2 N_dec) <= L/2 (m=4 needs 0.1 L): f <= 1/(90 L) vs f >= 2/sqrt(log2 N_dec) ≈ 0.4. **Impossible within the model** (and the model
  exponent equals N_dec > free bits, i.e. worse than brute force over the free bits).
- Structural mismatch beyond counting: (1) variables must be Boolean, equations over F_2 with polylog monomials and constant degree;
  S_{m+1} over F_p has degree 2^{m-1} per variable and is dense as a polynomial in the bits of x_i (arithmetic mod p mixes all bits).
  (2) Counting solutions is not what is needed; one needs to *find* one among p^{...} (the paper's self-reduction gives it at poly overhead, fine).
- Remark, untested: over **binary fields** the same decomposition becomes a system over F_2 with ~n variables and n equations after
  Weil descent (the one place ECDLP is natively "polynomial equations over F_2 in O(log q) variables"); but equations are dense (Theta(n^2)
  monomials for m=2, degree >= 2), violating the (log n)^c sparsity; sparsifying adds aux variables. Out of scope (prime fields are the
  lab's residual hard class) but the only place a sparse-system variant might be worth a thought.

### 3.4 Route (b): counting k with a structured predicate on x(kP)
Counting #{k : Phi(x(kP))} with Phi on x only equals counting points of E(F_p) with x in a set, independent of Q = [k0]P beyond
Q's coordinates; this is the Weil/Legendre equidistribution regime already measured null (HYP-242da418/80158648: no leak). For the count to depend on k0
the predicate must involve Q and a range on k', e.g. #{k' < T : x(k'P) in I(x_Q)} ≈ T|I|/p + [k0 < T]; the indicator is visible only when
T|I|/p ≲ 1 (noise sd sqrt(T|I|/p)), reducing to a decision SAT-like search over k' with an N(ell)-variable circuit: time model = route D (3.2).
A separate Boolean-variable family (k bits only, predicate via circuit) is route D again. No new mechanism; no speedup.

### 3.5 Route (c): bit-decomposition polynomial system for [k]P
(i) As a polynomial in the ell bits k_i: measured (E3, evidence `...command-6b2f31c0...`, ell = 6..16, 2 curves each, 22 ECDLP rows) every output bit of x(kP)
has ANF density 0.45-0.50 (min over all rows 0.281 at ell=6; >= 0.44 for ell >= 8), degree ell-1 or ell, i.e. ~2^{ell-1} monomials, equal to random-function
controls; F_p-multilinear representation has density 0.92-0.99998 (min 0.922) and degree ell. The paper needs <= (log n)^c monomials (n = ell: 3375 at ell=15 vs measured >= 16,273 monomials; the gap grows exponentially).
Decision rule of the protocol met (dense everywhere): the sparse-polynomial form is killed. (This is the same interpolation-type
obstruction as the lab's HYP-57d71f43 / Theorem B family, now seen as a sparsity obstruction.)
(ii) With intermediate points as extra variables (the circuit form), the system is sparse (local gates) but has N = Theta~(ell^2..ell^3) Boolean variables: route D.
(iii) Over F_p-valued variables the technique has no F_p version (its group sums are over {0,1} domains, interpolation uses Z/2^P0 rings); encoding F_p variables in bits is (ii).
Model cost: p^{...} = 2^{N f} as in 3.2; memory poly(N).

## 4. Pseudocode / prototype (item 2) and correctness (item 3)
Pseudocode of the *only well-defined candidate* (route D), executable parts are the encoders already in the lab (affine: round10 `sat_ecdlp.encode`;
ladder: round11 `sat_ladder.encode_ladder`):
```
ECDLP_via_count(E,P,Q,r):          # candidate, NOT efficient
  F <- Tseitin_CNF(ladder/double-and-add circuit, ell key bits, assert result = x(Q))   # n(ell) vars, bounded occurrence after Tovey copying
  c <- Count_k_SAT(F)               # paper's algorithm; deterministic, poly space; here == exhaustive 2^n below the paper's threshold
  if c==0 or c>2: fail              # solutions: k and r-k (x-only) -> c = 2 for k != r/2
  k <- self-reduce: fix key bits one at a time keeping count > 0   (poly(n) calls)
  verify [k]P == Q; return k
```
Correctness: if Count_k_SAT is correct (paper's Theorem 1.1, unverified by us) the output is a satisfying key; verified by one scalar multiplication; success
probability 1 (deterministic). Correctness of encoders was established in rounds 10/11 (solver outputs verified). Not run: the counting algorithm is not
implementable at a meaningful size (parameters in 3.1; the algorithm degenerates to exhaustive search over n ≈ 10^4..10^5 variables at toy sizes,
2^{22941} for the smallest ladder instance vs rho 5.5 ops). **No benchmark vs rho was built: Q3 gate (some route survives Q1/Q2) failed; a
fitted-exponent comparison would be a benchmark of exhaustive search over N wires, which carries no information. No speedup is claimed.**

## 5. Exact obstacle (item 6)
O1 (variable inflation): the technique's exponent is linear in the number n of Boolean wires; every known ECDLP check circuit has n >= Omega~(ell^2) (measured ~ell^{2.4-2.8},
asymptotically ell^3 schoolbook), versus a target budget ell/2. Closing it needs either a CNF/circuit family for [k]P = Q with n = O(ell sqrt(log ell)) (below any known
scalar-multiplication circuit, and n f < ell/2) or an extension of the technique to count over the *input* bits only (circuit-SAT in terms of inputs), which is not what the paper gives and
would be a far stronger statement (SETH-type regime).
O2 (regime): even with n = s·ell, the paper's own parameters give a gain only for log2 n > 6.85e10 (f<1) and log2 ell > 5e11 for f<1/2: no physical ell.
O3 (sparsity/representation): the only low-variable representation (bits of k -> x(kP)) is dense (measured ANF density ≈1/2, degree ell, F_p density ≈1), violating polylog sparsity.
O4 (decomposition): route (a) needs T_dec <= p^{(m-1)/(m+1) - 1/2}; the technique cannot be applied to F_p arithmetic without N_dec ≈ 45 (log p)^2 wires.
O5 (information): the mechanism is group-oblivious (counting/interpolation); nothing in it distinguishes E(F_p) from a random group, consistent with generic lower bounds on
what an encoding-blind method can do (Shoup/Nechaev apply to the group oracle, not to circuit-SAT; so this is not a lower bound, just no mechanism).
