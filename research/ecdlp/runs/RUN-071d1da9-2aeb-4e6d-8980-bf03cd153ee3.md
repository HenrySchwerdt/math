## 3. Developed ideas (role-file fields)

### F-B1 — SAT/CDCL on the bit-level encoding of [k]P = Q
- Property exploited: the double-and-add circuit is a short, *structured* constraint system (n conditional additions of
  known constants 2^i P); CDCL learns clauses and could in principle discover sub-exponential shortcuts (meet-in-the-middle style relations between key bits).
- Escaped assumption / why escape is not already ruled out: Shoup/Maurer/Nechaev bounds assume encoding-blind (generic) algorithms. A SAT solver sees the circuit, so it is non-generic. This escape is not ruled out by any lab result (summation-polynomial work is algebraic elimination, not a CDCL search). The literature uses SAT only for binary-curve index-calculus point decomposition (Petit-style, WDSat), not for the raw ECDLP.
- To prove: nothing positive unless solver cost scales sub-sqrt; a negative result is empirical, no proof of hardness possible (a bound on CDCL would be a proof-complexity statement).
- Killers: slope of conflicts vs r >= 0.5 (rho) across m = 6..10; flat-in-key-entropy floor.
- Cheapest test: T1/T1b below (executed).
- Prior work: arXiv/ePrint 2019/313 (WDSat, binary curves, index calculus: verified); no prime-field raw ECDLP SAT benchmark found in one search (absence not established).

### F-B2 — Learned bit predictor for k from (x(kP), y(kP))
- Property: none assumed; tests the "pseudorandomness of the encoding for bounded learners" at toy size over the whole group (exhaustive, so the empirical distribution IS the distribution).
- Escaped assumption: no one on the lab tried *discriminative learning* (earlier work: fixed predicates of the coordinates vs k mod m, a different direction). The learning direction asks whether any feature function of (x,y) leaks bit j of k.
- To prove: nothing; decisive null at toy sizes; positive result would be a *table-compressible* structure.
- Killers: no label beats majority by 4 sigma, controls pass (power shown).
- Cheapest test: T2 (executed, ~5 s per curve).
- Prior work: bit security of ECDH (Jetchev–Venkatesan CRYPTO 2008, verified): LSB hardcore *conditionally* (GRH, over a family of curves). Predicts an unconditional leak to be absent; supports expectation. ML on ECDLP: no verified source found.
- Limits: the label under negation k <-> r-k: x determines min(k, r-k) only; bit0 etc. are sign-ambiguous by construction (including the information-theoretic ceiling, see Verdicts).

### F-B3 — Learn-then-decode pipeline (speculative, analysis only)
- Property: random self-reducibility: for random t the point tQ is uniform, so an oracle with advantage eps on a bit of DL(tQ) is queryable with independent noise; decoding "k from noisy bits of (k t_i mod r)" is the Akavia–Goldwasser–Safra / Boneh–Venkatesan hidden-number setting (unverified recollection for AGS; HNP verified only through the Jetchev–Venkatesan citation chain).
- Escaped assumption: "no bit oracle can exist" — not escaped by anyone's data; it is *the* hypothesis T2 falsifies at toy scale.
- Accounting (derivation, labelled analytic): each query yields at most 1 - H(1/2+eps) ~ 2 eps^2/ln 2 bits, so >= n ln2 /(2 eps^2) queries are needed information-theoretically; each costs one scalar mult (~ n^2 log n bit ops) plus the oracle. Even eps = 1/poly(n) would give a poly(n) algorithm *if* the oracle existed at one random multiplier cost. Detectable advantage in T2 at n_test ~ 2000 at 4 sigma: ~0.045; below that the test cannot exclude a useful-but-weak oracle (limitation).
- Killers: T2 null at toy sizes (observed); asymptotically unaddressed.
- Cheapest test: none beyond T2 (decoding step is known).

## 5. Verdicts
- F-B1: **refuted as a route** (toy range): plain CDCL on the straight circuit scales at conflicts ~ r^1.2 (worse than brute force, far above rho's r^0.5), and is insensitive to key entropy. Not a proof of anything about SAT in general; richer encodings (table-lookup gadgets, x-only ladders, XOR-aware solvers, using the rho-style meet-in-the-middle structure explicitly) were not tried. Experimental, toy sizes, n = 5..10 only.
- F-B2: **null** (decisive for logistic/MLP + Fourier/bit features on exhaustively enumerated groups with r in 859..6607). Detection floor ~0.045 absolute advantage at n_test ~ 2000; weaker leaks and other learners/larger groups untested. Under negation symmetry bits of k are not even determined by x, so the ceiling for "bit of k from x" is chance; the sign-invariant label also gave no flag.
- F-B3: **blocked** at the oracle step; pipeline arithmetic (information bound) is a sound known template. Speculative, no new claim.
- Killed ideas (4-7, 9-14) are recorded above; none was tested beyond reasoning, so those kills are "argued", not "measured".
