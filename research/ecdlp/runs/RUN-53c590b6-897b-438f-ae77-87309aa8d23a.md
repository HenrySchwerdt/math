## 3. Algorithm classes escaping all of B1-B9

An escaping algorithm must (a) be non-generic: read coordinates; (b) use operations outside the field's ring structure
(comparisons, bits, floor/division of integer representatives, factoring) — else B4/B5 apply; (c) not be a homomorphic
transfer (B6) and have no pairing/anomalous/extension-field structure (B10); (d) not decompose over a (sub)variety/interval
factor base solved by Groebner (B7) nor use covers (B8); (e) use predicates of high Fourier complexity (B9) or none;
(f) be adaptive and multi-input (it can compute aP+bQ for any a,b). Concrete shapes that satisfy (a)-(f) and are not yet
excluded: (i) lattice / linear-algebra methods acting on *integer lifts* of coordinates; (ii) smoothness-type filters
on x-coordinates (NFS-like); (iii) lifts to characteristic 0 with a height as size function (xedni); (iv) hybrid
algebraic-decision-trees with integer comparisons (open lower-bound question).

Transplant analysis (mechanism, not group):

| Mechanism | What makes it work (essential structure) | What is missing in E(F_p), p prime, r prime |
|---|---|---|
| NFS (F_p^*) | (1) ring homs Z[alpha] -> F_p from factorial/Dedekind rings: group elements = products of "primes"; (2) a norm (size function) multiplicative for the ring law, so smoothness has probability rho(u); (3) relations are LINEAR in unknowns (a,b) -> lattice sieving; smoothness is the only nonlinear event | The curve group is additive with no ring map from a factorial ring onto points; group law is rational, not linear, in coordinates; the integer size of x(P+Q) is independent of sizes of x(P), x(Q) (no compatible size function). Relation Sum n_i P_i = O is linear in the n_i but their lattice is the unknown relation lattice (needs dlogs) |
| FFS / Joux-Lercier / Diem on F_{q^n} | Subfield structure gives algebraic factor bases; Weil restriction turns decomposition into polynomial systems | F_p has no subfield; interval factor base is not algebraic |
| Quasi-polynomial (Barbulescu-Gaudry-Joux-Thomé; Kleinjung-Wesolowski), small characteristic | PGL_2(F_q) acts on P^1; X^q - X = prod(X-a) forces smoothness *algebraically*; descent by degree halving; works because field contains the intermediate fields F_{q^k} | E(F_p) has no intermediate field/subgroup chain; the analogue of X^q-X is x^p-x whose divisor is *all* of E(F_p) (trivial relation). No small automorphism group (|Aut E| <= 6) |
| Class groups (Hafner-McCurley, Buchmann) | Elements are reduced ideals/forms with a norm bounded by sqrt|Delta| and multiplication is norm-multiplicative up to reduction: size function compatible with the group law | On E(Q) the canonical height is such a function (quadratic form), but reduction mod p destroys it: x mod p is an arbitrary integer. (E(F_p) is also not the class group: it is the torsion module O/(pi-1) ~ Z/r) |
| Lattice reductions / BKW / Wagner k-list (LWE, subset sum) | Ambient Z_q^n with computable coordinates and small-error structure; generalised-birthday cascades zero out computable quotient coordinates | The cascade needs a computable coordinate in Z/r (the dlog) or a quotient chain; Z/r, r prime has none and E(F_p) offers no computable map to it (B6, B9): coordinate integers are unrelated to dlog |

Net: every successful DLP mechanism uses either a computable quotient/size structure compatible with the group law or an
algebraic factor base with a polynomial-time decomposition solver. E(F_p) offers neither; the candidates below test the two
loopholes (integer boundedness via lattices; integer smoothness predicates) and three theory kills.

## 4. Candidate mechanisms

**C1. Lattice (Coppersmith/Howgrave-Graham) decomposition of Semaev S_3 into interval-factor-base points.**
Property: S_3(x1,x2,xR) in F_p[X,Y], monic in X^2Y^2; integer boundedness x_i < B=p^alpha is the one condition a Groebner
solver cannot see but LLL can. Escapes: B7 (solver), B4/B5 (uses integer bound), not generic. Why not already excluded:
ECDLP-16 tested Groebner/summation polynomials at m=3, not lattices (BACKLOG item 3). Obligations: need alpha >= 1/2
(see cost law below). Killers: Howgrave-Graham determinant condition; Cheapest decisive test: T1. Prior work: Semaev
2004 (ePrint 2004/031, abstract-level verified: summation polynomials proposed, no root-finding method suggested);
Coppersmith's method for bivariate modular equations (unverified recollection); a lookup found no paper combining
Coppersmith with summation polynomials over prime fields (absence of search hits is not proof of absence).
**Cost law (derived here, elementary):** with |V|~B=p^alpha points, a random R is a V+V sum with prob ~p^(2alpha-1), so
any decomposition procedure that only works inside the box costs >= p^(1-2alpha) tries per relation and >= p^(1-alpha)
overall (|V| relations) -- beating sqrt p requires alpha >= 1/2.

**C2. Unreduced Miller / orbit-product cocycle ("pairing with trivial reduction").** Property: f_{r,P}(X+P)=c f_{r,P}(X)
g(X)^r with g=(x(X)-x_P)^{-1}; since gcd(r,p-1)=1 the r-th power map is bijective on F_p^*, so u(X)=f_{r,P}(X)^{1/r}
computes the orbit product prod_{j<k}(x(jP+S)-x_P) from the point kP in polylog time (a prefix-product oracle). Escapes:
B6 (not a homomorphism; a cocycle), B9 (non-local function), not generic. Why not excluded: Frey-Ruck/MOV is usually
discussed only when r | p^k - 1. Obligations/killer (derivation, NOT executed): from div f_{r,Q}=r(Q)-r(O)~k r((P)-(O)) we get
f_{r,Q}=c f_{r,P}^k / f_{k,P}^r; every element of F_p^* is an r-th power, so for every k' the equation is solvable with some
unknown value f_{k',P}(X): the system constrains nothing (pairing target F_p^*/(F_p^*)^r is trivial). KILLED by theory:
the "transfer" is cohomologically trivial, not just the homomorphic one. Cheapest test: none needed. Prior: Frey-Ruck,
Menezes-Okamoto-Vanstone (unverified recollection).

**C3. Integer-structured (smoothness-type) coordinate predicates as approximate characters.** Property: predicates such
as "x is B-smooth", "x prime", "squarefree", Liouville lambda(x) have l1 Fourier norm ~ sqrt p or more over F_p, so the B9
bound does not exclude correlation with characters of E(F_p) ~ Z/r. If g(k)=pred(x(kP)) had even one exceptional Fourier
line h*, then 1 bit-per-query oracle about k*h* mod r follows (character test). Escapes: B9, B1. Killers: spectrum
indistinguishable from the symmetry-aware shuffle null. Cheapest decisive test: T2. Prior: HYP-130de9b1 (40 functions,
no smoothness among them as far as the summary states), Kohel-Shparlinski (unverified).

**C4. Height-linearisation / xedni (lift to E(Q), use canonical height as the missing size function).** Property:
heights give a group-compatible quadratic size function on E(Q); dependence among lifts of the factor-base points would
give relations. Escapes B7/B8 (no decomposition), B1. Not excluded by lab. Obligations: lifts of N random points to
rational points of bounded height on one E/Q with rank < N; killer: Jacobson-Koblitz-Silverman-Stein-Teske, "Analysis of
the Xedni Calculus Attack", Des. Codes Cryptogr. 20 (2000) 41-64: experiments show the odds of a suitable lift are
prohibitive (search-snippet level; full text unread); a later paper (unnamed in my lookup) says it was shown unlikely
asymptotically. Status: KILLED BY LITERATURE, not re-tested (no PARI/Sage here to compute ranks). Prior: Silverman, "The
xedni calculus and the elliptic curve discrete logarithm problem", Des. Codes Cryptogr. 20 (2000) 5-40.

**C5. Comparison-augmented algebraic decision trees (integer order on representatives).** Property: B5 shows equality
branching halves the exponent only; order comparisons and bit tests are not covered by any proved barrier. Question: what
is the minimal length of a program with ring ops, division, and tests "g(u) < c" (integer order of the residue) that
outputs k for all u=x(kP), k<=N? Escapes: B4, B5, B1. Obligations: (i) prove the rational analogue (HYP-6aef8c30) to make B5
unconditional; (ii) find a counting/ VC-type bound for comparison trees, or a construction. Killers: a Theorem-C-type bound
for semialgebraic leaves. Cheapest decisive test: exhaustive search of tiny trees (r<=30) is feasible only in toy form and
was NOT run here. Prior: none found; Ben-Or style topological bounds are for R, not F_p (unverified recollection).
