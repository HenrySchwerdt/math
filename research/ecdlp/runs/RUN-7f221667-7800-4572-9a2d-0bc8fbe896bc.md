## 4. D3: norm form of Z[pi] and small-norm elements

Setting: E/F_p ordinary, trace t, D = t^2 - 4p < 0, pi^2 - t pi + p = 0, Z[pi] of discriminant D.

Lemma (proved). Let O be an order in an imaginary quadratic field of discriminant Delta < 0, O = Z[w], w = (Delta + sqrt Delta)/2. For alpha = a + b w with b != 0:
N(alpha) = a^2 + ab Delta + b^2 (Delta^2 - Delta)/4 = (a + b Delta/2)^2 + b^2 |Delta| / 4 >= |Delta|/4,
with equality iff Delta even, b = +-1, a = -b Delta/2. For Delta odd the minimum over nonscalar elements is (|Delta|+1)/4.
Proof: complete the square; b != 0 gives the second term >= |Delta|/4, and the first is a rational square-shift of an integer by b Delta/2 (a half-integer for Delta odd, hence >= 1/4). Larger |b| only increases the second term (|b|=2 gives >= |Delta|), so b = +-1 is optimal. QED.

Corollaries (all proved by the lemma).
1. For Z[pi]: N(a + b pi) = a^2 + t a b + p b^2; every non-integer element (b != 0) has norm >= |D|/4. Hence |t^2-4p| >= c p implies norm >= c p/4 (c' = c/4, sharp up to the +1/4 parity term). Since |D| <= 4p (Hasse) the best possible c is 4; norm of a nonscalar element is at least ~ p only when t is near 0.
2. The only nonscalar elements of norm 1 (units) in an order exist iff Delta in {-3,-4}. So the unit group is {+-1} unless Delta in {-3,-4} (classical: units of orders of discriminant -3 and -4 have order 6 and 4).
3. IMPORTANT correction to the question's phrasing: End(E) is an order O with Z[pi] <= O <= O_K, with Delta(O) = D / u^2, u = [O : Z[pi]]. The lemma for Z[pi] alone does NOT imply "End-based equivalences are impossible when |D| is large": a curve with D = -3 u^2 and large u has End = Z[zeta_3] and six automorphisms (when defined over F_p). The correct, rigorous statement is: End-based equivalences beyond +-1 need Delta(End(E)) in {-3,-4} (j=0 or 1728), a condition on End(E) and not on t; moreover nonscalar endomorphisms of norm n need n >= |Delta(End)|/4. For a given t the isogeny class contains a curve with End = O for each order Z[pi] <= O <= O_K (Waterhouse; [R]), so the class contains a j=0 curve iff d_K = -3 (resp. j=1728 iff d_K=-4); the property is not a function of t alone for the individual curve.
4. Speedup for rho. An equivalence relation by a subgroup G of Aut_{F_p}(E) acting on <P> (as multiplication by lambda in (Z/r)^*) gives classes of size #G and a speedup of sqrt(#G) in the number of walk steps, in the standard analysis [Wiener-Zuccherato, V-metadata; step-cost overhead and fruitless cycles ignored]. #Aut(E) over F-bar equals |O^*| in {2,4,6}; over F_p the full group is available iff the needed roots of unity are in F_p (p = 1 mod 3 for j=0, p = 1 mod 4 for j=1728). So the speedup is at most sqrt 6 ~ 2.45 over no equivalence, i.e. at most sqrt 3 ~ 1.73 beyond negation (sqrt 2), and sqrt 2 beyond negation for Delta=-4. This holds for every imaginary quadratic field, not only fixed CM field, since |O^*| <= 6 always: a constant factor. Non-unit endomorphisms are not bijections on E(F_p) and no sourced rho speedup from them is known to me; orbit normalisation cost with m orbit elements is m evaluations, so the naive gain sqrt m does not materialise unless the evaluation is far cheaper than a group operation (this is what makes Frobenius special in DGM [R/D]). Over a prime field Frobenius acts as the identity on E(F_p), contributing nothing.
5. Density among curves: j in {0,1728} gives at most 10 F_p-isomorphism classes among about 2p, density O(1/p) [D]. Among traces, the fraction with d_K in {-3,-4} is small but trace-counting is not curve-counting; weighted counts would use Hurwitz class numbers H(D) (not done).

## 5. Residual hard class and known-results statement

Class R: E/F_p with p prime, #E(F_p) = r prime (so cyclic, Pohlig-Hellman vacuous), r != p (not anomalous), embedding degree k of r with respect to p larger than (log p)^c (c >= 2 suffices for the pairing-to-F_{p^k} route to lose to sqrt(r) by the derivation in B; no sourced threshold), j not in {0,1728} (otherwise a constant sqrt(3) or sqrt(2) extra from automorphisms).

Known-results statement (not a theorem): for curves in class R, the best published algorithms known to me are Pollard rho and variants with O(sqrt r) group operations, improved by at most a constant (sqrt 2 from negation; at most sqrt 6 total in the j=0 case), and the index-calculus approaches (Semaev summation polynomials, Gaudry-Diem) have no known advantage over F_p; the Galbraith-Gaudry survey (https://eprint.iacr.org/2015/1022, [V title/abstract only; the exact statement about prime fields is [R]]) is the natural citation. No unconditional super-generic lower bound is known for any specific elliptic-curve group: the only proved bound is for the generic group model (Shoup 1997 [R]; Corrigan-Gibbs-Kogan 2018 [V] for the preprocessing trade-off). Silverman-Suzuki (Asiacrypt 1998) negative result on x-coordinate-lifting index calculus [R]; Jao-Miller-Venkatesan random self-reducibility over an isogeny class [R]: neither gives a speedup. "Most curves belong to class R" is a heuristic (Koblitz-type prime-order density, [R]), not proved.

Link to the laboratory target HYP-2de84d42 (worst-case O(n log n) bit operations): nothing in this classification suggests such an algorithm, and none of families A-K reaches it for class R.
