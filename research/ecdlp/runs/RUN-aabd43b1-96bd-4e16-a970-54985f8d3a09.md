## 2. Candidates

Notation: E/F_p, base P of prime order n (~2^b), target Q = kP. A "group op" = one affine point addition or
doubling (1 inversion + ~3 mults). Walk f: R -> R + S_j, j = x(R) mod 31, S_j random combinations; tags (a,b)
track R = aP + bQ. DP = distinguished point, x & mask == 0, mean walk length L.

### C1 - Negation-class rho with fruitless-cycle escape (C1 frozen; C1b = post-hoc repaired variant)
1. **Mechanism.** The walk lives on classes {R, -R} (canonical y <= p/2, tags negated with the point), so the
   birthday space has n/2 elements: expected collision at ~sqrt(pi n /4) instead of sqrt(pi n /2) (factor sqrt 2).
   Obstacle: the walk on classes has 2-cycles (R -> R' -> R up to sign) with probability ~1/(2r) per step: a fruitless cycle
   that never reaches a DP. Fix (Wiener-Zuccherato; Bos-Kleinjung-Lenstra): detect the cycle, double its smallest-x member
   (deterministic, so merging walks still merge). Frozen C1 detected periods 2 and 4; C1b detects any repeat in the last
   W = 16 classes.
2. **Pseudocode.**
```
rho_neg(P,Q,n):  S_j = a_j P + b_j Q (j<31); table = {}
 loop: (a,b) <- random; R <- aP+bQ; canon(R,a,b); hist <- []
   repeat up to 20*L steps:
     if DP(R): if R in table with other walk and b != b': return (a'-a)/(b-b') mod n
               else store; break
     hist.push(R,a,b);  R += S_{x(R) mod 31}; (a,b) += (a_j,b_j); canon
     if x(R) = x(hist[-d]) for some 2<=d<=W:   # fruitless cycle
         M <- member of the cycle with smallest x;  R <- 2M; (a,b) <- 2(a_M,b_M); canon; hist <- []
```
   Prototype: `algos.py::rho_neg` (frozen, d in {2,4}), `algos2.py::rho_neg_w` (C1b). Both recovered k in all runs
   (C1 76/76, C1b 88/88; dlog_bsgs cross-check on the first 4 trials per size up to 32 bits).
3. **Correctness.** Every stored DP is exactly aP+bQ with tags kept consistent through canonicalisation
   (-R has tags (-a,-b)). Two different walks reaching the same canonical point give a+bk = a'+b'k mod n, hence
   k = (a-a')/(b'-b) when b != b' (probability 1 - 1/n per genuine collision; n prime). Escapes preserve the invariant
   R = aP+bQ. Termination with probability 1 (walks are capped and restarted).
4. **Complexity model.** Ops = collision phase ~ sqrt(pi n/4)*(1+o(1)) group ops + DP overhead 1/theta per detected
   collision + 1 doubling per detected fruitless cycle (~1/(2r) of steps, ~1.6% for r = 31) + O(log n) per restart
   + one-time setup ~93 log2 n. Memory: n^(1/2)*theta stored points (here ~16-1000 entries). Field cost per op identical
   to rho. Success probability: ->1 (restarts). Exponent in n: 1/2.
5. **Measured (Section 4).** Frozen C1: failure. C1b: exponent 0.482 (0.458, 0.504) vs ref 0.486 (0.467, 0.506);
   ratio ref/C1b per size 0.69-1.45, pooled (post-hoc) 1.13-1.14 (95% CI about (0.95, 1.33)).
6. **Obstacle.** Negation identifies only 2 points (|Aut(E)| = 2 for generic curves), so the collision space is
   n/2: exponent stays 1/2, constant at best 1/sqrt 2 on ops. Measured gain is below sqrt 2 because small r = 31 gives
   many fruitless cycles (BKL show r in the thousands is needed for the full gain) and because the frozen
   detector is *not scale-robust*: its capped (cycle-trapped) walks per run grow with L (0.06 / 0.25 / 0.88 / 4.1 / 14 at
   24/28/32/36/40 bits), giving a fitted exponent 0.687 (0.652, 0.719) on 24-40 bits. Larger Aut (CM curves, Frobenius on
   Koblitz-type curves) gives sqrt|Aut| only on those special families.

### C2 - Preprocessed fixed-walk table (S*T^2 trade-off)
1. **Mechanism.** Use a walk f that depends on the point only (no Q). Preprocessing (instance-independent, done once per
   (E,P)): run m chains from random sP, store each reached DP with its exponent a (R = aP). Online for any Q: walk
   from Q + tP (t = 1,2,...) with the same f until a DP; if the DP is in the table (R = Q + cP = aP) then k = a - c.
   Online walk meets the table coverage (~mL points) with probability ~mL^2/n per walk, so with m ~ L ~ n^(1/3):
   T = O(n^(1/3)), S = O(n^(1/3)) (DPs), preprocessing O(n^(2/3)). Ties exactly to the generic S*T^2 ~ N bound.
2. **Pseudocode.**
```
PRE(P): S_j = a_j P; for i<m: s<-rand; R=sP; a=s; walk with f to DP (cap 20L); table[R] = a (point key incl. y)
QUERY(Q): R <- Q+P; t<-1; loop: walk(R,c=t) to DP (cap) ; if DP in table: return (table[DP]-c) mod n
          else R <- R+P; t <- t+1
```
   Prototype `algos.py::PreTable` (`pre`, `query`).
3. **Correctness.** Table points are exactly aP; online points are exactly Q+cP; equal point => a = k+c mod n, so
   k = a - c. Table key includes y: (found and fixed in development) keying on x alone conflates R and -R and
   produced wrong k in the batch prototype. Every one of 160 queries returned the planted k.
   Success probability per walk ~ 1 - exp(-coverage*L/n) ~ 0.3-0.6 (measured mean restarts 1.8-2.7), so the online
   cost is geometric; no failure mode other than the cap.
4. **Complexity model.** Preprocessing ~ m*L ~ 2 n^(2/3) ops (measured 1.2-2.2 n^(2/3)); memory S = #distinct DPs ~ 1.5
   n^(1/3) (merging chains lose ~20%); online T ~ 1.6-2.0 n^(1/3) ops; total for Q queries = pre + Q*T.
5. **Measured.** See Section 4.
6. **Obstacle (what keeps it from beating the generic bound).** It *meets* S*T^2 ~ 4 N (fitted slope of log(S T^2/n) vs bits
   = 0.03; constant 2.7-5.0), it does not beat it. Online exponent 1/3 buys preprocessing exponent 2/3 > 1/2 for a single
   instance; beating the bound requires non-generic information (CGK prove S*T^2 = Omega~(N) in the generic group model).

### C3 - Multi-instance batch with shared DP set (Kuhn-Struik style) 
1. **Mechanism.** Solve M instances Q_j = k_j P together. All walks use the same point-only f, walk tags are
   scalar c (R = Q_j + cP, node j; node 0 = P itself). A collision between walks of nodes j != j' gives
   k_j' - k_j = c - c'; maintain a union-find with potentials (offset to the root). When component of node 0 contains all
   nodes every k_j is known. Walks are started only from unresolved nodes (plus node 0) to avoid the coupon-collector tail.
   Number of cross-node collisions grows like W^2/n for W total walk points => total ~ sqrt(M n) rather than M sqrt(n).
2. **Pseudocode.**
```
batch(P, Q_1..Q_M): UF over nodes 0..M with offsets; table = {}
 loop: j <- random unresolved node or 0; c <- rand; R <- Q_j + cP (R<-cP for j=0)
   walk with f to DP: (c += step scalar)
   if DP in table from another walk (j',c') : if j != j': union(j', j, d = c' - c)   # k_j - k_j' = c' - c
   store; stop when node 0's component = all nodes; return k_j = off[j] - off[0]
```
   Prototype `algos.py::batch_rho`.
3. **Correctness.** Same point implies k_j + c = k_j' + c' (mod n); each union records an exact linear relation; union-find
   composes relations exactly, k_0 = 0 anchors. Same-node collisions carry no information and are ignored. All 138 batches
   (54 + 84) returned all k_j correctly (the first versions mixed R and -R by keying on x only; fixed pre-registration).
4. **Complexity model.** Total ~ c_M * sqrt(M n) group ops (measured c_M = 1.8-2.0 for M >= 4), memory ~ total/L DPs
   (L = sqrt(n/(M+1))/8; ~330-370 stored), per-instance cost ~ c_M sqrt(n/M). Needs M >= 2 for gain; total cost can never be
   below M (output size), and sqrt(M n) <= M n^(1/2) only. For M ~ n^(1/2): n^(3/4) total, n^(1/4) per instance.
5. **Measured.** Section 4.
6. **Obstacle.** Exponent in n of the cost per instance stays 1/2 for any fixed M; the gain is a factor sqrt(M)
   (amortised). It is a multi-instance advantage, not a break of the single-instance bound (Kuhn-Struik; Bernstein-Lange
   also give the same sqrt(M) for the generic model).

## 6. Most promising next step
Within this territory only constant/amortised gains are available, so progress must come from **non-generic structure**. Concrete
cheap decisive tests that this run did not do: (1) an *iteration function whose collision graph is not random*: choose partition/
DP functions from algebraic invariants available for free (e.g. x-coordinate orbit under a nontrivial endomorphism or
low-degree isogeny images on CM / j = 0, 1728 curves where |Aut| = 4 or 6) and measure the realised group-size reduction vs sqrt|Aut|,
which gives the sub-sqrt 2 constants on special families; (2) for the lab's universal goal, the multi-target/preprocessing
setting is the only place where an exponent in a *different cost coordinate* moves (online T = n^(1/3)); a proof-grade statement of the
exact S*T^2 bound and whether **bit-complexity of lookups** (hash/RAM model vs circuit model) changes the picture would
sharpen the barrier map; (3) the failure of C1 shows walk-detector robustness must be tested at scale: any future
"adaptive restart" candidate must report capped-walk rates versus L.
