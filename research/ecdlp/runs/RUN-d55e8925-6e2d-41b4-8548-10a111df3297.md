### 2. Is Num a polynomial; does clearing W matter; Num(tau0) != 0 (item 2): CONFIRMED
- Num is *defined* as an explicit finite sum of products of integer-coefficient division polynomials (and constants f_i in {i, i^2}), so it is a polynomial in Z[A,B,x0,y0] and, after substituting B, in Z[A,x0,y0]; no cancellation or division is needed. The only thing to verify is Num = W * c_{N-1} where W != 0. This holds as an identity in Z[A,x,y]: the relation (x_i - x_l) theta_i theta_l = -psi_{i+l} psi_{i-l} is a polynomial identity in the ring Z[A,x,y] (B substituted, so the curve equation holds identically), hence it holds at every point of F_p^3 including the singular tau0, and only the final division by theta's/psi's needs psi_m(tau) != 0.
- Numeric confirmation: Num == W * c_{N-1} (group-law divided difference) mod 1000003 at 5 random points for each of N = 3, 4 and both targets (all OK).
- Exact values at tau0 = (A,x0,y0) = (0,1,1): W(tau0) = 120 (N=3), 151200 (N=4). Num(tau0)/W(tau0) = 36 = 3!^2 (N=3, k^2), -576 = -(4!)^2 (N=4, k^2); 33/5 (N=3, k), -2416/35 (N=4, k). These equal the direct cusp divided differences with nodes 1/k^2 (checked independently with Fractions in `badn.py`). So Num(tau0) != 0 follows from the cusp divided difference, and W cannot "cancel" anything because W(tau0) = product of integers <= 2N-1 (nonzero mod p for p > 2N).
- Corrected equivalence: for p > 2N, p does not divide Num(tau0) iff p does not divide the numerator of the rational number c_{N-1}(0). Hence "Num_N" in D0(iii) (an integer) and "Num" (the polynomial) are different objects; the report should write Bad_N := {p > 2N prime : p | Num(tau0)} = primes > 2N dividing the numerator of c_{N-1}(0). ### 3. Schwartz-Zippel on F_p^3 versus U (item 3): LEGITIMATE
Z subset {tau in F_p^3 : Num(tau) = 0}: for tau in Z, W(tau) != 0 (see item 6) and c = 0, so Num = W c = 0. The lemma is applied to the nonzero polynomial Num mod p on all of F_p^3, which is a superset; no condition "on U" is needed for the lemma, only for the inclusion, which holds. Total degree after substituting B is the right degree for the lemma (it is a polynomial in the three free variables A, x0, y0 only after the substitution), and deg <= weight/2 holds because every monomial A^c x^a y^b has weight 4c+2a+3b >= 2(c+a+b), and the substituted B has weight 6 and degree <= 3. Num nonzero mod p is guaranteed by Num(tau0) != 0 mod p. Exhaustive check: Z is contained in the zero set of Num in every case (violations: 0; see below).

### 4. tau0 in U for p > 2N; psi_m(cusp) = m (item 4): CONFIRMED, now proved
Hand proof by strong induction (not in the original, which only checked m <= 20): with A=B=0, x=y=1: psi_1..psi_4 = 1,2,3,4; psi_{2m+1} = psi_{m+2}psi_m^3 - psi_{m-1}psi_{m+1}^3 = (m+2)m^3 - (m-1)(m+1)^3 = 2m+1; psi_{2m} = psi_m(psi_{m+2}psi_{m-1}^2 - psi_{m-2}psi_{m+1}^2)/(2y) = m[(m+2)(m-1)^2 - (m-2)(m+1)^2]/2 = m*4/2 = 2m. Also machine-checked m <= 60 (`badn.py`). Then x_k(tau0) = 1 - (k^2-1)/k^2 = 1/k^2, nodes distinct mod p because k^2 = l^2 mod p iff k = +-l, impossible for k != l <= N < p/2. psi_m(tau0) = m != 0 for m <= 2N-1 < p, so tau0 in U (tau0 is a singular point of the cuspidal cubic, but U is defined by non-vanishing of the psi polynomials, and Z is separately restricted to nonsingular curves; this is not a gap).

### 6. Does "mindeg = N-1 off a fraction w_N/p" follow? (item 6): follows, with a correction
- If tau is a valid triple (nonsingular curve, W(tau) != 0, i.e. all kP finite and x_1..x_N distinct) and tau not in Z, then c_{N-1} != 0; the N nodes are distinct so the interpolant is the unique polynomial of degree <= N-1 through them, and a polynomial g with degree < N-1 matching all N values would equal it; hence mindeg(N) = N-1 exactly. (Uses L1; this inference itself is elementary: divided difference c_{N-1} is the leading coefficient of the interpolant.)
- Correction 1: the sentence "all but a fraction w_N/p of (curve, point) pairs have mindeg(N) = N-1" is imprecise. The theorem bounds |Z| (the valid deficient triples) by w_N p^2. Triples that are not valid (singular curve; kP = O for some k <= N; or x(iP) = x(lP) for i != l, where no polynomial g exists at all because targets differ) are not in Z, are not covered by the bound, and are of size up to about (6 + deg W) p^2 (singular: degree 6 after substitution; W = 0: degree of order w_N). Correct statement: among valid triples, at most w_N p^2 have mindeg(N) < N-1; the valid triples are a (1 - O(N^4/p)) fraction. Exhaustive data show valid triples are ~0.9 p^3 for N = 3 and 0.6 to 0.9 p^3 for N = 4 at p ~ 20-50, i.e. not negligible at these sizes.
- Correction 2: "(A,x0,y0) triples" count (curve, affine point) pairs with each curve weighted by its number of affine points; this is not the uniform measure on curves. Harmless but should be said.
- "D >= D0 >= 1" in the proof/conclusion uses an undefined symbol D0 (clashes with the name of the lemma D0); delete.
