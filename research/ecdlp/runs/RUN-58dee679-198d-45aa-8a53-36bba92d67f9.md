## Candidate B1 — Automorphism-orbit rho (walk on the quotient E(F_p)/Aut(E))
1. Mechanism. Change representation from points to Aut-orbits (x-only/Kummer line for -1; (zeta x, y) for j=0, |Aut|=6; (-x, i y) for j=1728, |Aut|=4). An Aut element acts on <P> as a scalar mu in F_r^*, so a collision of orbits R=aP+bQ, R'=a'P+b'Q gives a+b k = mu(a'+b' k): k=(mu a'-a)/(b-mu b'). Information about k per collision is the same, but the birthday set shrinks to r/|G|. Barrier escaped: none of the three (it keeps the generic square-root form); it escapes only the "plain group" assumption of Shoup-type constants (the lab's barriers do not forbid constant factors). Known technique (Wiener-Zuccherato, GLV/Bos et al.); not novel.
2. Pseudocode. `ecinv.rho`: build step table (m=256, sums of earlier entries) -> repeat: start = sum of 3 table points; loop { R <- canon(R+S[h(x(R))]) tracking (a,b) <- mu (a+u, b+v); on cycle (ring 8) double smallest cycle point; if x(R) is DP store/lookup }; on non-trivial DP collision output k. canon(R)=lexicographic min over the |G| images, mu recorded. Prototype is run on j=0, j=1728 toy curves; all 450 runs recovered k (0 failures).
3. Correctness. Coefficients are tracked exactly through canonicalisation (R_canon = mu R), so any DP collision with b != b' (mod r) yields k with certainty after verification; trivial b=b' collisions are skipped. Cycle escape is deterministic in the cycle so merged walks stay merged. Success probability = P(collision within budget) -> 1 (no failures in 90 runs per family).
4. Cost model. Group ops ~ c_G sqrt(pi r/(2|G|)) (ideal c=1) + O(m + table seeds) setup (~ 3*1.5 log r + m + 200 adds) + DP overhead 1/theta per trail + cycle losses (observed 0.1-1.4 escapes per 1000 steps); canonicalisation 4-5 field mults per step; memory #DP ~ sqrt(r)*theta*const; no preprocessing beyond setup; field-op bits O(M(log p)) per op.
5. Measured (T1, N=30 instances/size, same instances and seeds for all methods, counted group ops, mean):

**Verdict B1: constant-factor only, known; exponent 1/2.**

## Candidate B2 — Isogeny-volcano ascent to a j=0 curve, then B1
1. Mechanism. Rational 2-isogenies phi: E->E' restrict to group isomorphisms on the odd part of E(F_p) (gcd(deg, r)=1), so (P,Q)->(phi P, phi Q) transports k exactly, even though prime-order-subgroup transfers (barrier i) cannot change r. Representation change: climb the volcano to the crater curve (End = Z[omega], j=0) where Aut(E')=6 gives the B1 quotient; climbing from the floor is cheap (O(a) steps, Kohel/Fouquet-Morain style), while for generic curves the isogeny class is huge (~sqrt p curves) and j=0 is one vertex. Barrier (ii) escaped? No: #E and r are preserved by design; the idea uses only that isogenies are *free* representation changes, and that special end-curves have exploitable automorphisms. Equivalent in kind to Jao-Miller-Venkatesan 2005 / Galbraith 2024 "Climbing and descending tall volcanos" (known).
2. Pseudocode. ascend(E,P,Q): while A != 0: list rational 2-torsion roots x0 of x^3+Ax+B (gcd with x^p-x, Cantor-Zassenhaus), drop the backtracking neighbour; if >1 option, pick the one whose random non-backtracking walk to a dead end (floor) is longest (up-edge path >= down path + 2); apply Velu (A'=A-5t, B'=B-7 x0 t, t=3x0^2+A) and map P,Q by x'=x+t/(x-x0), y'=y(1-t/(x-x0)^2). Then run B1 with Aut(j=0). Prototype: `iso.py`, `run_t2.py`; instances are volcano floors of D=-3*4^a, p=s^2+3*4^(a-1), #E=4r, r prime, produced by random descent from j=0 (attacker sees only E,P,Q). 150/150 recovered k, verified on the original curve.
3. Correctness. Velu maps are group homomorphisms of degree 2 coprime to r, injective on <P>, so phi(Q)=k phi(P); the ascent terminates at A=0 because the up-neighbour is the unique neighbour with strictly longer dead-end walks (parity/depth argument; at floor degree 1). If the walk picks wrongly the volcano loop is detected by step cap and reports failure (never observed). B1 correctness as above.
4. Cost. Ascent: a = O(log p) steps, each with <= 3 neighbour lists and 2 dead-end walks of length <= a, i.e. O(a^2) isogeny evaluations, each O(log p) poly-mults mod a cubic = O(log p) field mults * O(1): total O(log^3 p) field mults polylog; measured iso evals 255, 357, 472, 615, 760 for a=10..18 (log-log slope vs a: 1.86). Then B1: c sqrt(pi r/12) group ops. Memory as B1. Success probability ~1 on the family. Applicability: only curves isogenous (same trace) to a smooth-conductor CM curve with small discriminant; for generic ones ascending needs isogenies of degree ~ conductor f ~ sqrt(p) (Velu cost ~ f) or class-group walks of length ~ h(D) ~ sqrt(p).
5. Measured (T2; floor curve vs plain rho on the same E, 30 instances per a; r bits 20,24,28,32,36; ops include 2*steps map evaluations and W=10 group-op equivalents per isogeny evaluation):
Mean ops: plain rho 2207, 6766, 29131, 122454, 690247; B2 (W=0) 1693, 4959, 28642, 66988, 247992; B2 (W=10) 4243, 8529, 33366, 73141, 255592. Exponents: plain 0.519 [0.475,0.560]; B2 W=0 0.454 [0.408,0.494]; B2 W=10 0.373 [0.335,0.407]; orbit-rho part alone 0.455 [0.407,0.495].
Pre-registered rule outputs: W=0: CONSTANT-FACTOR ADVANTAGE (pooled ratio 1.56 [1.20,2.06], dslope -0.065 [-0.127,-0.002]); **W=10: the rule literally outputs "ASYMPTOTIC-IMPROVEMENT evidence" (dslope -0.146 [-0.204,-0.090], pooled ratio 1.10 [0.87,1.38]). I judge this a FALSE POSITIVE caused by the rule design, not a real effect:** (a) the isogeny cost is an additive polylog term that is 60% of B2's cost at r=2^20 and 3% at r=2^36 (post-hoc overhead shares 0.60, 0.42, 0.14, 0.08, 0.03), so it flattens a log-log slope over 16 bits of r while the asymptotic cost is dominated by sqrt(r)/sqrt6; (b) plain rho is heavy tailed (sd/mean ~1, N=30; mean ops/sqrt(r) 3.05,2.34,2.51,2.64,3.72 whereas medians are 1.3-2.2) and its last-size mean inflates the plain slope (0.519). Normalised B2(W=0) ops/sqrt(r) = 2.34,1.71,2.47,1.45,1.34 and orbit-only medians 1.44,0.86,0.70,0.82,0.67 against plain medians 2.21,1.67,1.32,1.73,1.67 — compatible with a constant ratio ~2-2.5 (<= sqrt6), i.e. exponent 1/2. No asymptotic improvement is claimed; the rule should be amended in a future protocol (fit M - overhead, or compare normalised costs with N >= 200).
T3 (applicability): probability that a uniformly random E/F_p is F_p-isogenous to a j=0 curve (trace in the six CM traces), p = 1033..65539: 0.0355, 0.025, 0.016, 0.0158, 0.0105, 0.0098, 0.0038; fitted exponent in p = -0.467 [-0.576,-0.382] (bootstrap parametric), prediction -1/2. So B2 applies to ~p^(-1/2) of curves: a weak family.
6. Obstacle. (1) Applicability ~p^{-1/2}; (2) on a generic class the distance to j=0 (or to any curve with extra structure) is ~h(D) ~ sqrt(p) isogenies — the same cost as rho; (3) even where it applies the quotient gain is the constant |Aut|=6; (4) isogenies are group isomorphisms on <P>, so the DL instance itself (r, group structure) is unchanged: no information about k is created — only a cheaper birthday constant.
**Verdict B2: correct, polylog ascent on a vanishing weak family, constant-factor (<= sqrt6) at best; known in kind; no asymptotic gain.**

## Considered and rejected on paper (no prototype, so not candidates)
- Isogeny-pooled walk (states (E_i,x), identified via phi): phi is a bijection on <P>, so the pooled state space has r classes; collision probability is unchanged — pure overhead.
- Twist-pooled x-only / Kummer walk: x-only has no addition for the r-adding step; the only exploitable symmetry is -1 (B1 neg, measured no gain).
- Other-model change (Edwards/Hessian/quartic): group-isomorphic, same r; only field-op constants differ.

## Most promising next step
Nothing here is promising for sub-sqrt(r). The only quantitatively interesting handle is the *distance-to-structure* question: how many isogeny steps separate a random curve of a class from a curve whose endomorphism ring supports a cheaper algorithm? Measure it exactly on toy classes (T3 style: count class sizes H(t^2-4p) vs p) to confirm the ~sqrt(p) cost; if some small-degree isogeny cordillera structure shortens it, that is the only route for B2. Otherwise stop: representation changes that preserve (r, group structure) cannot beat the generic birthday except by Aut-sized constants.
