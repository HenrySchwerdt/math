## 2. Proven statements

### L1 (exact characterisation of the minimal degree; elementary)
Let x_1..x_n be distinct in a field F, v_k in F, and c_j = f[x_1..x_{j+1}] the Newton divided differences (c_j depends only on the first j+1 nodes and values). For N <= n, the minimal degree of any g in F[X] with g(x_k) = v_k (k <= N) equals mindeg(N) = max{ j < N : c_j != 0 } (and mindeg(N) = 0 if all c_j, j>=1, vanish, with c_0 = v_1 != 0).
Proof. g(x_k)=v_k for k<=N holds iff g ≡ I_N mod Π_{k<=N}(X-x_k), where I_N = Σ_{j<N} c_j Π_{i<=j}(X-x_i) is the Newton interpolant (degree <= N-1). A polynomial of degree < N congruent to I_N modulo a degree-N polynomial equals I_N; any other solution is I_N + h·Π(X-x_k), degree >= N or equal I_N. So mindeg = deg I_N = largest j<N with c_j != 0. QED.
Consequences: (i) mindeg(N) <= N-1 always ("Lagrange degree"); (ii) the deficit D(N) := N-1-mindeg(N) is exactly the length of the run of zeros c_{N-1}, c_{N-2}, ...; (iii) mindeg is nondecreasing in N, and a single pass computes all N; (iv) for f(k)=k: c_1 = 1/(x_2-x_1) != 0, c_2 = 0 iff x(P)+x(3P) = 2x(2P). Combined with Theorem C: every zero run c_j = ... = c_{N-1} = 0 (j>=2) satisfies N <= 3j-1 (otherwise mindeg(N) <= j-1 < (N-2)/3).

### L2 (Theorem C is optimal within the "translation annihilator" method; answers idea (a)/(b) negatively)
Let S ⊂ Z be a finite support with |S| = s, width w = max S - min S, and coefficients c_i (i in S) not all zero with Σ c_i = 0 and Σ i c_i = 0 (the exact condition for Σ c_i (k+i) ≡ 0 in k). Let D(Q) = Σ_i c_i G(Q + iP), G = g∘x, g of degree d >= 1. Then (a) s >= 3 and hence w >= 2; (b) D is a nonzero rational function on E whose pole divisor is 2d·Σ_{i in S}(-iP), degree exactly 2ds (poles at distinct points since |i-i'| <= w < N < r); (c) D vanishes at kP whenever k+i in [1,N] for all i in S, and at -kP whenever k-i in [1,N] for all i in S (as G(-kP+iP) = G((k-i)P) = k-i since G is even), i.e. at >= 2(N-w) distinct points (k P ≠ -k' P for k,k' in [1,N] since 2N<r). Hence 2(N-w) <= 2ds, i.e. N <= ds + w, and the minimum over admissible (s,w) is s=3, w=2, giving exactly Theorem C: N <= 3d+2. Using more translates (larger s) or wider support only weakens it.
Proof. s>=3 since two points with Σc=Σic=0 force c=0. (b): the term G(Q+iP) has a pole of order exactly 2d at Q=-iP (G = g∘x has pole order 2d at O, g of degree d) and the other terms are regular there; so D has exact pole order 2d at each -iP. (c) is the computation above, using Σ c_i (k+i) = 0 = Σ c_i(k-i). A nonzero function has at most as many zeros as poles. QED.
Also (iterating doubling) G∘[m] vs mG: x(mQ) is a rational function of x(Q) of degree m^2, so g(R_m(x)) - m g(x) has degree <= m^2 d and vanishes at the floor(N/m) nodes x_k with mk <= N: N/m <= m^2 d + (small), d >= N/m^3 - O(1): strictly weaker than Theorem C (proof sketch only, not formalized; not needed).
Status: L2 is an elementary proof written here; not formalized, not independently reviewed. It shows that the Riemann-Roch/zero-count method cannot give more than N/3 without new input (any improvement must use information beyond "G is regular away from O with pole 2d and G(kP)=f(k)").

### L3 (structural deficit family: anomalous j = 0 curves, k^2, full range)
Claim. Let E: y^2 = x^3 + b over F_p, p ≡ 1 mod 3, #E(F_p) = r = p (anomalous; forces p ≡ 1 mod 3 since j=0 is supersingular for p ≡ 2 mod 3), P ≠ O, N = (p-1)/2, and g in F_p[X] with g(x(kP)) = k^2 mod p for 1<=k<=N. Let ζ in F_p be a primitive cube root of 1, ω(x,y) = (ζx,y) (automorphism of E over F_p), ωP = λP with λ in F_p^* (E(F_p) = <P> ≅ Z/p, ω acts as a scalar λ with λ^2+λ+1 = 0 in Z/p). Then (i) the minimal interpolant g (deg <= N-1, unique) satisfies g(ζX) = λ^2 g(X), (ii) hence g = X^s h(X^3) with s in {0,1,2}, ζ^s = λ^2, s != 0, and (iii) deg g <= N-3+s: deg g <= N-2 if s=1 (deficit >= 1) and only deg g <= N-1 if s=2 (N ≡ 0 mod 3 since 3 | p-1, so N-1 ≡ 2 mod 3).
Proof. As r = p, G(Q) = m^2 mod p for every Q = ±mP (m in F_p^*), well-defined since m^2 = (-m)^2, i.e. g(x(mP)) = m^2 for ALL m ≠ 0, and the nodes {x(mP)} number exactly N. For a node x = x(mP): ζx = x(ωmP) = x(λmP) so g(ζx) = (λm)^2 = λ^2 g(x). So g(ζX) - λ^2 g(X) has degree <= N-1 and N distinct roots, hence is 0. Coefficientwise g_i(ζ^i - λ^2) = 0, so g_i != 0 only for ζ^i = λ^2, i.e. i ≡ s mod 3; s=0 would need λ^2 = 1, impossible as λ has order 3. The deficit bound follows from N-1 ≡ 2 mod 3. QED.
Observed (cm_anomalous.py, deterministic, all anomalous j=0 curves y^2=x^3+b, p ≡ 1 mod 3, 7 <= p < 500, one P per curve): 207/207 cases satisfy the support lemma; in all 207 s = 1 and the minimal degree is exactly N-2 (deficit exactly 1). That s = 1 always is OBSERVED, not proved (conjecturally lambda = zeta^{-1}, from the action of ω on the formal group / invariant differential).
Significance: this is a PROVED family with mindeg < N-1 (so "mindeg = N-1 always" is false), but the saving is a constant (1), not a positive fraction of N: the ω-symmetry reduces the number of free coefficients to ~N/3 but not the degree (the same phenomenon for j = 1728 would force parity of g; it cannot occur anomalously since trace 1 is impossible for p = a^2+b^2).
Not covered: k (linear): G(mP) = |m| mod p is not ω-equivariant; r != p: reduction of λk mod r vs mod p breaks the identity. Larger endomorphisms (CM by non-maximal orders, e.g. p = 19, 79, 109, 167, 269, 383 where excess top-level deficits for k^2 were observed, see §3) give relations g∘R = μ^2 g with deg R = deg β > 1; these have degree ~ deg(β)·d >= N and do not by themselves force a vanishing, so the excess there is an unexplained (probably CM-endomorphism) effect; not analysed.

## 4. Constructions / counterexamples
- Counterexample to the folklore "mindeg = N-1 always": L3 family (proved deficit >= 1 at N=(p-1)/2 whenever s=1, observed always) and the generic random deficits (e.g. p=19, a=4, b=8, r=19, N=9, k: D=3; p=31 a=23 b=7 r=17 N=7 k: D=3).
- No family with deficit growing with N was found. Whether sup D is bounded by an absolute constant (heuristically it is not bounded, ~ log(#cases)/log p ≈ 3-4 for each p, so slowly unbounded over all p) remains open.
