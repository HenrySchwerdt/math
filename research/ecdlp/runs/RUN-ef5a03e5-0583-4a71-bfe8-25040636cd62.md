## 2. Item 1 — mechanism
Setting: E/F_p, base B (negation-closed, s points, c = s/2 x-classes), target R = aP + bQ uniform. Question: is R = P1+P2+P3+P4 (Pi in B, signs free), and find it.
Supply (measured, see 5): P(R in 4B) = lambda ~ s^4/(24 p) (= 16 C(c,4)/p), so s relations need p/s^3 targets at s = p^{1/5}. Total = (p/s^3) T_test + LA(s) + precomputation, so the PI target T_test < p^{1/10} is only meaningful with the precomputation counted (see 6).
Finders implemented (all verified on planted targets, see 3):
- **F_MITM (2+2 hash).** Table of x(Pi +- Pj) (M ~ s^2/4 pair-sum classes, built once). Per target: for every pair sum U compute R -+ U and look up x. T_test = 2M ~ s^2/2 EC additions.
- **F_TOWER (candidate (a), resultant tower / S_3 chaining).** R = U + T, U, T in B+B. A2(X) = prod_j (X - X_j) over pair-sum x-values (once). Per target Q(X') = Res_X(S_3(X, X', x_R), A2(X)) = prod_j S_3(X_j, X', x_R) (S_3 is quadratic in X; product tree of 2M-degree), then g = gcd(Q, A2) (half-gcd, flint nmod_poly). g nontrivial iff R is in (B+B)+(B+B) (S_3(xU, xT, xR) = 0 iff +-U +-T = +-R). Roots of g give T, then U = R - T by lookup. This is the S_3 tower with both elimination steps done by one resultant and one gcd; it is the best chaining I could find, and it cannot go below deg A2 = M ~ s^2/4.
- **F_MITM31 (3+1 with a table of triple sums).** Same, with the table of x(Pi+-Pj+-Pk) (size ~ 2 M c) and s adds per target.
- **F_GB (candidate (b), Groebner basis).** S_5 eliminated through U, T: {S_3(x1,x2,U), S_3(x3,x4,T), S_3(U,T,x_R), xi^d = c} (m = 3: {S_3(x1,x2,U), S_3(U,x3,x_R), xi^d = c}), grevlex, over F_p, p ~ d^5, planted target; sympy 1.14 and Singular 4.4.1 `std`.
- **(c) Descent using x^d = c.** Analysed, not a separate finder. S_5 has degree 8 in each variable, independent of d, so on the coset it is a band-limited Fourier series on Z_d^4 (6561 frequencies). Fixing 3 variables, the 4th is a univariate root problem solvable by gcd with x^d - c in Õ(8 log d) (cheap), but looping 3 variables costs s^3 > s^2; fixing 2 variables and eliminating one more costs Õ(s) per pair (degree 8d eliminant) vs O(1) hash lookup. No grading of the base structure beats list lookup, because EC addition is additive in discrete-log coordinates while the base is multiplicative in x: the only maps between them are the S_m polynomials. Only CM curves j = 0, 1728 have an automorphism x -> zeta x that preserves a coset base; that gives a constant factor (orbit size 3 or 2), not an exponent.
- **(d) Small-x / phi(t) bases via Coppersmith-type small roots (analytic only, not implemented).** For |xi| < X, S_5(x1..x4, x_R) = 0 mod p with n = 4 unknowns and degree e = 8 per variable: the standard shift lattice (my own derivation, unreviewed, dense polynomial assumed) gives the bound X < p^{2/(n(n+1)e)} = p^{1/80}, versus the p^{1/5} needed (a polylog finder would need X >= p^{1/6} for total (p/s^3) polylog < sqrt p). Flagged as a heuristic derivation, not a measurement.

## 6. Item 5 — benchmark vs rho and Item 6 — exact obstacle
**Item 5: not run.** The PROTOCOL gate (a finder with beta_hi < 0.10 and total cost accounted) failed, so no pipeline, no linear algebra, no rho comparison was built. Model only (not measured): with MITM 2+2 at s = p^{1/5}, total ~ (p/s^3) s^2/2 = p^{4/5}/2 additions vs rho ~ sqrt(p); the ratio grows as p^{0.3}.
**Item 6: the obstacle, exactly.**
1. *Intermediate-sum size.* Every chaining finder (hash MITM, S_3 resultant tower) handles the set B+B of s^2/4 pair sums as an object it must read or build a polynomial of degree s^2/4 over. For the coset base A2 has no closed form of lower degree: A2(X) = Res_{x1}(x1^d - c, Res_{x2}(x2^d - c, S_3)) has degree ~ 2d^2 in X with generic-looking coefficients. So T_test >= s^2 = p^{2/5} (measured beta ~ 0.4-0.6), a factor p^{3/10} above the p^{1/10} target.
2. *Precompute trades against T_test.* The 3+1 table gives T_test = s (beta = 0.2, measured) but precompute s^3 (measured slope 0.595). A 4-sum table gives O(1) T_test at precompute s^4. The best total over all splits is p^{m/(2m-1)} = p^{4/7} > p^{1/2} for m = 4 (analytic).
3. *Gröbner does not exploit the base.* The system {xi^d = c, S_5 = 0} has d^4 candidate points (the s^4 grid) of which s^4/p ~ p^{-1/5} satisfy S_5; the quotient algebra has dimension ~ d^m before the single equation S_5 prunes it. Measured: Singular m = 3 time ~ d^5.3 and m = 4 beyond 45 s at d = 8, whereas a hash table needs s^2.
4. *Structure mismatch.* The base is multiplicative in x; the group law is additive in discrete-log coordinates. No homomorphism links them except through the degree-2^{m-2} S_m polynomials, so no FFT or character-sum shortcut exists without knowing logarithms (the Fourier transform of 1_B over E is the DLP itself). CM automorphisms give only constants.
5. *Small roots.* Coppersmith-type methods for small-x or phi(t) bases give X < p^{1/80} by my derivation (unverified), far from p^{1/5}.
Therefore: T_test = p^{2/5}.. p^{0.6} measured vs p^{1/10} needed. Any finder below p^{1/10} would have to decide membership in a set of size s^4 ~ p^{4/5} without reading intermediate sums of size p^{2/5}.
