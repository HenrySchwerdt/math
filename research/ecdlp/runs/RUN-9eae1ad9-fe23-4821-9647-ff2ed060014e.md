## 3. Cost model and encoding (fixed exactly)

Model M-TM (reference model): deterministic or randomized multitape Turing machine,
binary alphabet; cost = number of steps ("bit operations"). Harvey-van der Hoeven's bound
is stated in exactly this model. Comparisons below are only meaningful inside one model,
because at the n log n level a log factor is the whole question:
- word-RAM (word size Theta(log n)): bit-complexity bounds do not transfer without care
  (U: multitape time T can be simulated on a RAM within the same order, but the converse
  and the multiplication cost in RAM-word operations is not claimed here);
- Boolean circuits: multitape time T(n) gives circuit size O(T log T) by Pippenger-Fischer
  (1979, "Relations among complexity measures", JACM 26; U). Hence M-TM O(n log n)
  multiplication yields circuits of size O(n log^2 n) by this route; I do not claim a direct
  O(n log n) circuit.

Encoding E-W (fixed): input = (field description, a, b, P, Q) with
- F_q, q = p^m: prime p in binary (log p bits) and m in binary, and for m>1 an irreducible
  f in F_p[x] of degree m (m*log p bits); elements as coefficient vectors;
- curve in general Weierstrass form with coefficients a_1..a_6 (or short form for char != 2,3);
- P, Q as full affine pairs (x,y) (or the point at infinity flag);
- optionally the order r of P (convention O3 below).
Then n = Theta(log q) in every field case (about 7 log p for m=1 with a,b,P,Q), and by
Hasse r <= q+1+2 sqrt(q), so log2 r <= log2 q + 1 = O(n). Write b = log2 q.
Compressed points, other curve models and implicit field descriptions are EXCLUDED: point
decompression needs a square root in F_q, which by known methods costs Theta(b) multiplications,
i.e. already the same superlinear order as scalar multiplication (U on exact exponent; the
Tonelli-Shanks/exponentiation approach is textbook). So the encoding choice can silently
add the very cost under discussion.

Output conventions (they change the problem): O1 any k >= 0 with [k]P = Q; O2 least
k >= 0 (needs ord P, no known quasi-linear way to obtain it without extra input);
O3 r = ord P is prime and given in the input, k in [0, r). Recommendation: baseline on O3,
treat O1/O2 as separate variants. Under O1/O2 the answer is a coset k0 + (ord P)Z (Lemma L1).
Promise: Q in <P>. Algorithm may be randomized (Las Vegas / Monte Carlo) only if stated.

Primitive costs under M-TM and E-W (m=1; b = log p). KNOWN-BOUND unless noted.
- Integer multiplication: M(b) = O(b log b) [Harvey-van der Hoeven, Annals 2021, verified].
- Reduction mod p (Barrett/Newton division): O(M(b)) [textbook, Brent-Zimmermann, Modern
  Computer Arithmetic, 2010; U on exact citation form]. So F_p multiplication costs O(b log b).
- Inversion in F_p: O(M(b) log b) = O(b log^2 b) via half-gcd [Schonhage 1971; Moller, Math.
  Comp. 2008; U]. Projective/Jacobian coordinates avoid per-step inversions.
- Group operation in projective coordinates: a constant number c of F_p multiplications:
  O(b log b) bit operations.
- Scalar multiplication [k]P, k < r: double-and-add costs <= 2b group operations
  (<= b doublings + b additions) and sliding-window/Brauer chains cost b + O(b/log b) group
  operations (Brauer 1939, U) => O(b M(b)) = O(b^2 log b) = O(n^2 log n) bit operations.
- Extension fields F_{p^m}, N = m log p bits: multiplication O(N log N) bit operations
  using Kronecker substitution plus fast reduction (see also Harvey-van der Hoeven-Lecerf,
  "Faster polynomial multiplication over finite fields", J. ACM 2017, U) => same shape:
  scalar mult O(n^2 log n).
- Point counting (Schoof/SEA) and factoring of #E are polynomial but not near-linear (U).

## 4. Barrier statements

Notation: E/F_q, P of order r, Q in <P>, b = log2 q, n = Theta(b), G_P = <P>.

### C1. (KNOWN-BOUND, upper bound) Verification cost
Statement. Under M-TM + E-W + O3: given (E, P, Q, k) one can decide [k]P = Q in
O(n^2 log n) bit operations (prime field; same order for extension fields). No unconditional
lower bound above Omega(n) is known for this verification problem.
Hence: O(n log n) "as literally stated" is below the BEST KNOWN cost of verifying a candidate
by the natural method by a factor Theta(n). This is NOT a theorem that verification needs
n^2 log n bit operations, and NOT a contradiction: an inverse map can be cheaper than the
forward map (additive group Z_N: forward map k -> kP is a multiplication, inverse is a division).
Assumptions. M-TM; exponent size b; projective formulas.
Must prove for a real barrier. An unconditional multitape lower bound for scalar
multiplication (or for multiplication) exceeding Omega(n); unknown and I do not claim it.
Invalidated by. A sub-quadratic algorithm for [k]P on arbitrary curves (open; nothing known
beyond (b/log b)-type precomputation savings in fixed-base settings, and those require
input-dependent tables), or a non-straight-line method for exponentiation.
Sources. Harvey-van der Hoeven 2021 (verified). Remaining items U.

### C2. (PROVEN-ELEMENTARY, restricted model) Group-operation certificates need Omega(b / log b) operations
Statement. Let G = <P> have order r. A straight-line program (SLP) of length L over G is a
sequence a_0 = P, a_i = e1 a_j + e2 a_l (j,l < i, e1,e2 in {+1,-1}), output a_L.
The number of SLPs of length L is prod_{i=1..L} 4 i^2 = 4^L (L!)^2, so they compute at most
that many points. If 4^L (L!)^2 < r, some Q in G cannot be computed by any SLP of length
<= L (the program may depend on Q). Hence any SLP "certificate" that [k']P = Q, for ANY
representative k' of k mod r and any choice of chain, has L >= L_0(r), where L_0 is the least L
with 4^L (L!)^2 >= r; L_0(r) = (1+o(1)) log2 r / (2 log2 log2 r) (asymptotics derived by
Stirling, not checked numerically beyond the table in section 2).
Numerics (computed): r ~ 2^256 gives L_0 = 29; 2^521 gives 50.
Consequence in the restricted model "each group operation costs >= c b bit operations
(it must write an operand pair of Theta(b) bits)": certifying a worst-case Q costs
Omega(b^2 / log b) = omega(n log n). Also upper bound b + o(b) ops (Brauer), so the number
of group operations in the SLP model is tight up to a log factor.
Assumptions. Verification is carried out as an SLP of group operations ("generic" verifier);
Q ranges over all of <P>; counting over ordered pairs and signs (loose, makes bound weaker).
What must be proved for a TM statement. Nothing here bounds bit-operations of a verifier that
exploits field structure inside the group operations; that is exactly the open C1 gap.
Invalidated by. Non-SLP verifiers; verifier given a short certificate/advice (e.g. a proof
string checkable faster); counting error (rechecking the 4 i^2 factor is cheap).
Sources. Elementary counting in the spirit of Strassen; Schonhage (1975, "A lower bound for
the length of addition chains", Theoret. Comput. Sci. 1; U) gives log2 k + log2 nu(k) - 2.13
for a specific k with only additions of earlier terms.

### C3. (KNOWN-BOUND) Generic-group lower bound
Statement (Shoup 1997, Maurer 2005, Nechaev 1994; details of the exact probability bound U
beyond the abstract-level Omega(sqrt p)). Model: cyclic group G of order N, p the largest prime
factor of N. Shoup's generic algorithm: G is encoded by a uniformly random injection
sigma : Z_N -> S, |S| >= N; the algorithm receives sigma(1), sigma(x) and has oracles for
sigma(u)+/-sigma(v) -> sigma(u+/-v) (and may see/compare encodings); x uniform; the algorithm
may be adaptive and randomized. Then any algorithm making m group-oracle calls outputs x with
probability O(m^2 / p) (prime N = p: O(m^2/N)), hence needs Omega(sqrt p) calls for constant
success probability. Verified: Shoup's abstract states Omega(sqrt p), p the largest prime divisor
of the group order, matched by Shanks' baby-step giant-step. Maurer's model (verified at abstract
level): abstract ground set, state variables holding group elements, operations and relation
queries where generic = equality (optionally order) tests only; the bound is over the random
secret and does not need a random encoding because the algorithm never sees one. Nechaev's
(Math. Notes 55(2), 1994, verified bibliographically) result concerns deterministic algorithms
(U on exact quantifiers).
Role of random encoding: it removes all information in the representation except equality
structure (collisions of encoded elements). Bound is average-case over (x, sigma) [Shoup]
or over x [Maurer], so it implies a worst-case-over-x bound for the oracle model.
Assumptions. (i) the only access to group elements is via the group operation/inverse oracles
and equality; (ii) cost counts oracle calls only (all other computation free); (iii) the group
is Z_N with N, and for composite N the factorization is irrelevant to the bound (Pohlig-Hellman
is matched).
Does NOT say. It says nothing about bit complexity of non-generic algorithms and nothing about
any specific encoding such as E(F_q) with affine coordinates. Also, passing from "m oracle
calls" to bit complexity requires cost per oracle call >= 1 only for lower bounds; not Omega(b).
What a non-generic algorithm must exploit. At least one of: (a) the encoding is the structured
tuple (x,y) in F_q^2, giving access to field arithmetic, polynomial identities, smoothness,
factor-base decomposition, Frobenius, valuations; (b) auxiliary maps out of G into other
algebraic objects (pairings; lifting to Q_p; isogenies; Weil restriction; class-group
embeddings); (c) the curve is a member of a family with extra structure.
Invalidated by. Misapplication: Koblitz-Menezes (Adv. Math. Commun. 1, 2007, "Another look at
generic groups", U) discuss the limits of interpreting generic bounds as evidence of hardness.

### C4. (KNOWN-BOUND, derived) Generic preprocessing barrier
Statement (Corrigan-Gibbs-Kogan, Eurocrypt 2018, ePrint 2017/1113; abstract verified):
generic algorithms for DL in a group of prime order N with S bits of preprocessed advice,
online time T and success probability eps satisfy S T^2 = Omega~(eps N).
Derived consequence (mine; simple algebra): in the generic model for a FIXED group, online
time T = n^{O(1)} with constant eps requires S = Omega~(N / T^2) = exp(Omega(n)) bits
of advice. So "amortization over a fixed curve" does not rescue a generic algorithm.
Assumptions. Generic model only; advice depends only on the group; and the exact meaning of
"time" (group operations vs bit operations) is as in the paper (U).
Invalidated by. Non-generic advice-based attacks (precomputed index-calculus factor-base
relations for a fixed E over F_{q^m} are known to amortize, U).

### C5. (KNOWN-BOUND / heuristic) Non-generic algorithms and what each assumes
All items below are U unless marked verified.
1. Index calculus with Semaev summation polynomials [Semaev, "Summation polynomials and the discrete
   logarithm problem on elliptic curves", ePrint 2004/031, U]. Needs a notion of smoothness
   (decomposition into points with x in a subspace/subfield), Groebner/polynomial system solving
   for decomposition. Over prime fields no known asymptotic advantage over rho for general curves
   (Petit-Kosters-Messeng 2016, U).
2. Gaudry 2009 / Diem 2011 for E(F_{q^n}) [Diem, Compositio Math 147 (2011) 75-104, verified at
   abstract level]: for suitable sequences of prime powers and extension degrees growing with the
   field size but slower than the log, subexponential expected time; also Diem, "On the discrete
   logarithm problem in elliptic curves II", Algebra & Number Theory 7(6) 2013. Requires
   extension field structure with n >= 2 (n>=3 for beating generic by Gaudry's 2004 algorithm,
   per Diem's introduction, verified at abstract level) and a field-compatible factor base;
   n=1 (prime fields) excluded. Some versions are rigorous, those with Groebner steps use
   heuristic regularity assumptions.
3. Petit-Quisquater (Asiacrypt 2012, ePrint 2012/146, verified): heuristic subexponential
   2^{c n^{2/3} log n} for F_{2^n}, c < 2, conditional on a degree-of-regularity conjecture
   (first fall degree small) supported by experiments. Critiques: Huang-Kosters-Yeo (CRYPTO
   2015, ePrint 2015/573, verified abstract) give computational evidence casting doubt on the
   first-fall-degree assumption, prove small last fall degree only for HFE systems and
   conclude that bounding last fall degree for the Weil-descent systems arising here is open.
   Hodges-Petit-Schlather (Finite Fields Appl. 2014) give a rigorous general first-fall-degree
   bound (reported in search results, not read).
4. MOV / Frey-Ruck (Menezes-Okamoto-Vanstone IEEE Trans. IT 1993; Frey-Ruck Math. Comp. 1994; U):
   reduces ECDLP in <P> to DL in F_{q^k}^*, k the embedding degree (least k with r | q^k - 1).
   Useful only if k is small (k = polylog q); generic curves have k of size ~ r. Assumption:
   efficient pairing evaluation and a subexponential DL algorithm in F_{q^k}^* (NFS family), still
   not quasi-linear.
5. Anomalous curves #E(F_p) = p (Smart 1999, Satoh-Araki 1998, Semaev 1998, U): p-adic logarithm
   gives polynomial (quasi-quadratic order in bit cost, U) time. Needs exactly #E = p.
6. GHS Weil descent (Gaudry-Hess-Smart, J. Cryptology 2002, U): for E over F_{q^n} with
   suitable q, n, maps to a hyperelliptic/genus g curve over F_q with index calculus; works on a
   thin set of curves; Diem showed the odd characteristic/prime-degree cases fail or are weaker (U).
7. Quantum (Shor 1994/97; Proos-Zalka 2003, U) is out of scope (classical target).
Summary. For E/F_p with prime order r and trivial embedding degree, the best known classical
algorithm is Pollard rho / BSGS with Theta(sqrt r) group operations (Pollard 1978, Shanks 1971, U),
exp(Theta(n)) bit operations. Every non-generic gain known applies to a proper subclass of
curves/fields; none is universal.

### C6. (KNOWN-FACT / CONJECTURE) Conditional implications
(a) Trivial direction: an ECDLP algorithm solves CDH and (with it) breaks ECDH/ECDSA-type
    schemes on those curves. A universal quasi-linear algorithm would break all pairing-free
    and pairing-based EC schemes classically; this is a statement about cryptographic
    assumptions, not a mathematical impossibility.
(b) CDH <= DL always; the converse is open in general. Partial: den Boer (Crypto 1988; DH =DL if
    p-1 is smooth), Maurer (Crypto 1994) and Maurer-Wolf (SIAM J. Comput. 1999) equivalence given
    a suitable auxiliary group of smooth order; Muzereau-Smart-Vercauteren (LMS J. Comput.
    Math. 7, 2004) for practical elliptic curves (all U, not re-verified). Maurer-Wolf (Eurocrypt
    1998, "Lower bounds on generic algorithms in groups", cited in search results) is
    generic-only.
(c) DDH is separate: DDH is easy on pairing-friendly curves while DL stays presumed hard, so
    DDH hardness is not implied by DL hardness or conversely trivially.
(d) Factoring: NO known reduction in either direction between ECDLP over F_p (p public prime)
    and factoring. Known (U): Bach 1984 (UCB tech. report "Discrete logarithms and factoring")
    DL in (Z/N)^* for composite N yields a factoring algorithm, which is a statement about the
    composite-modulus setting and does not apply here. Both are solved in quantum polynomial time.
    A quasi-linear classical ECDLP algorithm would not by any known argument give a factoring
    algorithm, nor vice versa.
(e) Structural class: decision/bit versions of ECDLP lie in NP intersect coNP, indeed in the
    unambiguous classes UP intersect coUP, when the group order and its factorization are given
    (unique witness k mod r; this uses Lemma L1; folklore, U). Hence NP-hardness of ECDLP
    would imply NP = coNP; there is no hardness theorem to expect.

### C7. (CONJECTURES, mine) Candidate barrier lemmas to target
- CJ-A (scalar-multiplication hardness): for prime p and curves over F_p, [k]P on arbitrary
  input needs omega(b log b) multitape steps. Status: unproved, no known route short of a
  general multiplication-superlinearity result. The only related unconditional-looking facts:
  Afshani-Freksen-Kamma-Larsen (ICALP 2019, verified abstract) show a superlinear Boolean circuit
  lower bound for n-bit integer multiplication CONDITIONAL on the Network Coding Conjecture.
  So even Omega(b log b) for ONE multiplication is conditional, and cannot be used to prove
  CJ-A without further work. Falsifiable if someone gives a sub-quadratic exponentiation method.
- CJ-B (hardness-core conjecture): for curves over F_p with prime order and embedding degree
  > polylog(p), no classical algorithm using o(sqrt r) group operations exists. This is the
  standard heuristic assumption of ECC; it is NOT implied by C3, which only excludes algorithms
  that cannot use the coordinates.
- CJ-C (non-NC conjecture): iterated squaring / modular exponentiation with b-bit exponent is not
  in NC (long-standing open question; related to the Rivest-Shamir-Wagner sequential squaring
  assumption, U). If true, scalar multiplication cannot be parallelised to depth polylog
  and no constant-depth verifier exists.
- Compound barrier (derived, conditional): a universal O(n log n) algorithm A would have to be
  simultaneously (i) non-generic (violates assumptions of C3), (ii) escape the preprocessing
  barrier (C4) without per-curve advice, (iii) work for the subclass in CJ-B for which every
  known non-generic technique fails, and (iv) run in time below the best-known cost of
  evaluating the map it inverts (C1). (i) is necessary; none of (i)-(iv) is known sufficient or
  provably impossible. "Escaping the generic model is necessary, not sufficient."

## 5. Assumptions a faster algorithm must escape (checklist)
A1 No access to field structure (generic): escape by using coordinates. A2 Random-encoding
indistinguishability (Shoup): escape by non-uniform/structured encodings. A3 Cost counted in
oracle calls: for bit-complexity one must also pay field/arithmetic costs (C1). A4 Preprocessing
barrier C4: escape by non-generic precomputation or none. A5 The embedding-degree barrier: MOV/
FR useless when k is large. A6 No smoothness structure in prime-field coordinates (summation
polynomial index calculus lacks a natural factor base over F_p). A7 No extra endomorphism/
automorphism structure beyond constant speedups (Gallant-Lambert-Vanstone-type and symmetry
speedups are constant-factor or sqrt of small factor; U). A8 Output/representation conventions
(O1-O3, point compression) that can hide an extra Theta(b) multiplications.

n; report "vs best known" in a table: Pollard rho exp(n/2) bit ops. T2: group operation count:

(e.g. algebraic model where the algorithm may evaluate polynomial identities of bounded degree

T3: polynomial time (n^{O(1)}) for classes where structure exists (anomalous, small embedding
degree, smooth order: Pohlig-Hellman Theta(sqrt(p_max)) group ops, F_{q^n} with n>=3) and
explicit mapping of the remaining class. T4: preprocessing for a fixed curve (C4): exact
advice/time trade-offs in non-generic models. T5: restrict to an easier output: the most
significant bits or a single bit of k (hard-core bit results, Boneh-Venkatesan 1996 and
follow-ups, U). T6: "O(n log n) verification" as a separate question: is [k]P computable in
n^{2-eps}? That is a cleaner, publishable, falsifiable subquestion (CJ-A).
Information-theoretic remarks (proven, trivial): the answer has ceil(log2 r) bits so any algorithm
needs Omega(n) steps just to write k (r >= q^{1-o(1)} for cryptographic curves, but r can be 1
for degenerate P, so this holds only for the hard instances with log r = Theta(n)); the answer
depends on P and Q, so Omega(n) reading time is needed. These give no superlinear barrier.
Model-restricted lower bounds: SLP model (C2, proved); generic model (C3); algebraic decision
trees/bounded-depth circuits: I know of no relevant proven bounds for ECDLP itself (U);
for iterated multiplication, powering is in TC0 for the integers but modular exponentiation is
not known to be in NC (CJ-C; U); the algebraic group model (Fuchsbauer-Kiltz-Loss, CRYPTO 2018, U)
only constrains outputs that are group elements, so it gives no lower bound for DL itself.

## 7. Proposed Lean 4 / Mathlib lemmas (NOT compiled; names of Mathlib lemmas are recollections and must be checked)

L1 (uniqueness of ECDLP answers modulo the order; exact statement).
For any additive group G (instantiate with WeierstrassCurve.Affine.Point over a field, which
Mathlib gives an AddCommGroup structure), P Q : G, k m : N with k * P = Q:
  m * P = Q  iff  m = k (mod addOrderOf P),   where addOrderOf P = 0 means infinite order.
Sketch:
  theorem ecdlp_unique_mod {G : Type*} [AddGroup G] (P Q : G) (k m : N) (hk : k * P = Q) :
      m * P = Q <-> m = k [MOD addOrderOf P] := by
    subst hk
    exact (nsmul_eq_nsmul_iff_modEq (x := P)).symm  -- or: Eq.comm then the additive form of pow_eq_pow_iff_modEq
In Lean-like source the product is `m • P`. Fallback proof: use `nsmul_eq_mod_addOrderOf`
and `Nat.ModEq` with `addOrderOf_dvd_iff_nsmul_eq_zero`.
Supporting evidence: 172 finite tests (section 2). Value: fixes output convention O1/O2/O3.
L1' corollary: if addOrderOf P = r then exactly one k in [0, r) solves, namely Nat.mod.
L2 (information bound on the answer): for any r L : N and f : Fin r -> (Fin L -> Bool)
injective, r <= 2^L; hence any encoding of all possible answers k < r uses at least Nat.clog 2 r
bits. Sketch: Fintype.card_le_of_injective and Fintype.card_fun, card_bool.
L3 (stretch; counting version of C2): number of SLPs of length L over an abstract group is at
most prod_{i=1..L} 4 i^2; formalize SLP as List (Fin-valued index pairs and signs) and bound the
cardinality of the image of the evaluation map; conclude some element of a cyclic group of order r
with 4^L (L!)^2 < r is not computed. This is more work; start with L1, L2.
