## Model / cover construction and checks
* E: y^2 = f(x) = x^3+ax+b over F_p, p = largest prime < 2^bits, random (a,b) until #E = r prime (brute force).
  C: y^2 = F(w) = f(w^2+c), degree 6 monic, c = smallest c >= 1 with f(c) != 0 and gcd(r, #E') = 1 (c = 1 every
  time). pi(w,y) = (w^2+c, y); C -> E has degree 2 and is branched exactly over the two points with x = c.
* **No degree-5 (imaginary) model exists, so the suggested "move a rational root to infinity" step is impossible.**
  Reason: the six Weierstrass points of C lie over E[2]\{O} (the hyperelliptic involution induces [-1] on E), so
  a rational Weierstrass point would give a rational 2-torsion point on E, impossible when #E = r is an odd
  prime (concretely F(w) = 0 forces f(w^2+c) = 0, and f has no root in F_p). Translating/twisting the cover
  does not help: any double cover branched at 2 points is isomorphic to a twist of this one by the translation
  taking the branch pair to {P, -P}. Instead the degree-6 "real" model is used: it has two rational points
  infty+ and infty- (leading coefficient 1 is a square) with pi^{-1}(O) = infty+ + infty- = K (canonical class).
* Representation: a class in J_C(F_p) is written D - K with D an effective degree-2 divisor, Mumford pair
  (u monic of degree 2, v of degree <= 1, u | F - v^2); identity = None. Group law: Cantor composition (with
  the usual gcd d = gcd(u1,u2,v1+v2)) then ONE reduction step u' = (F - v^2)/u, v' = -v mod u'. This computes
  D1 + D2 - K because div(y - v) = D + D' - 3K, so D - K ~ iota(D'). deg d = 2 gives identity; deg d = 1 needs
  no reduction. Classes whose D contains a point at infinity (probability O(1/p), 0.3-3% of random triples at
  p=2^8, <0.2% at 2^14) raise `Degenerate` and are skipped, so the Jacobian arithmetic is only "generic" there.
  pi^*(Q) = [div(w^2-(x_Q-c), y_Q)] - K, pi^*(O) = identity.
* Files: `hyper2.py` (arithmetic), `icj.py` (curves, counting, checks, index calculus), `aggregate.py`.

## Index-calculus implementation
Unknowns mod r (r || #J, so m*(-) followed by J[r] = Z/r is a homomorphism phi): x_w = phi(g(P)),
g(P) = [P - infty+], one unknown per hyperelliptic orbit {(w,y),(w,-y)} (g(iota P) = -g(P) - N, N = [infty+ - infty-]),
n = phi(N), and k with pi^*Q = k pi^*P (phi(pi^*P) := 1). Factor base = all ~p/2 orbits = ~p rational points
(degree-1 primes up to iota). Degree-2 reduced divisor with u splitting over F_p gives a relation
(prob ~1/2 observed: 2 Cantor ops per relation).
* Variant A (as in the task: alpha pi^*P + beta pi^*Q). Computing the sum in J is the same as taking the fibre
  of Q' = alpha P + beta Q, so the Mumford form of every sample is just the fibre of a point of E.
* Variant B (Gaudry-style): Z = pi^*(alpha P + beta Q) + (P_a + P_b - K) with P_a, P_b random factor-base
  points; one Cantor add per trial; (alpha, beta) advanced by an additive walk in E (EC adds counted).
  Collect orbits+20 relations, sparse Markowitz-style elimination mod r with dense numpy core, retry with +10%
  relations if k is not determined (all LA attempts counted; here always 1 attempt). k is accepted only if two
  different free-variable assignments give the same k.
* Variant Bhalf: B with a random half of the orbits as factor base (relation requires all roots in it).
* Not implemented: Theriault/GTTD large-prime and double-large-prime variants (analytic below).
Counted cost = Cantor adds (relations; setup is EC only) + EC adds (walk and secret setup) + LA coefficient mults.

## End-to-end DL verification
Per curve: secret k drawn uniformly in [1, r-1], Q = kP in E, `dlog_bsgs(E,P,Q,r)` returns k, then Variants A
and B return k_ic. Result: k_ic = k = BSGS value on 12 of 12 curves for both A and B (3 curves at each of
2^8, 2^10, 2^12, 2^14), and for B additionally [k_ic] pi^*P == pi^*Q in J_C verified by Cantor arithmetic on
the correct runs (`verify_k_piP_eq_piQ` true). Rank of the relation system in B: full up to 0-22 columns
(deficiency 0-22 among ~p/2 active unknowns), always with k and n determined and no inconsistency.

### Important finding: Variant A (pullback only) does NOT do index calculus
Every sample alpha pi^*P + beta pi^*Q is exactly pi^*(Q') for Q' = alpha P + beta Q in E, whose Mumford form is
the fibre u = w^2 - (x(Q') - c); its roots are the two points (+-w0, y) over Q'. Hence relations for distinct
x(Q') involve disjoint pairs of orbits {w0, -w0} (HYP-ad5bc0e3 part D, confirmed numerically): with one relation
per distinct x(Q') (`dedup`), the rank equals the number of relations (~#orbits/2) against ~#orbits+2 unknowns and
k is NOT determined in any of the 12 curves (`dedup_k_determined` = 0 at every size; deficiency ~50% of the
unknowns). The raw A run did recover k, but only because the walk revisits the same point of E with different
(alpha, beta): alpha + beta k = alpha' + beta' k gives k directly. That is a birthday collision in E and needs no
cover; the first collision occurred after median 17, 21, 70, 90 trials at 2^8..2^14, consistent with
~0.9*sqrt(r) (x-collisions include Q' = -Q''), the same order as rho on E. For the pre-registered "total counted
cost" the A figure is the 3*orbits sample count above (30.2e6 at 2^14, far above 0.5*sqrt(p) = 64). The
first-collision diagnostic (not a pre-registered metric, 3 curves per size, noisy) is 90 trials at 2^14 vs
0.5*sqrt(p) = 64, i.e. above it, with log-log slope ~0.4 from 4 noisy medians but theoretical slope 0.5; it is
birthday search in E, not evidence about covers.

## Verdict
Pre-registered rule: falsified iff a variant that recovered k on all curves has median total counted cost
< 0.5*sqrt(p) at the largest size AND fitted exponent < 0.5. Largest size 2^14: B total = 3.85e9 (exponent 2.52),
Cantor-only = 16,410 (exponent 0.97); A total = 3.0e7 (exponent 1.59). All far above 0.5*sqrt(p) = 64 and
exponents far above 0.5. **HYP-ad5bc0e3 SURVIVES on the tested domain** (genus-2 double cover, prime-field E with prime
order, p <= 2^14, degree-1 factor base, one curve family, pure-Python Cantor with generic-case-only arithmetic).
The measured relation-collection cost is ~p Cantor ops with no sub-sqrt(p) behaviour, and the linear algebra is
worse. Analytic (not run): with factor base fraction f the relation phase costs ~p/f Cantor ops (observed factor
2 for f = 1/2) and sparse LA ~ (f p/2)^2 mults, balanced at f ~ p^(-1/3) giving ~p^(4/3) for plain Gaudry; GTTD
(Diem/Gaudry-Thomé-Thériault-Diem) quotes ~q^(2-2/g) = q for g = 2 and Theriault's large-prime variants
q^(2-2/(2g+1)) type exponents (recollection from the hypothesis record, not re-verified here), still >= 1.
No variant came near sqrt(p). Variant A's failure is a clean negative result for the "pull back and reduce"
idea: it yields relations with disjoint supports.

## Limitations
* Toy sizes (p <= 2^14), 3 curves per size (1 for the F_{p^2} check at 2^14), one cover family (w^2 = x - c);
  2^16 not run. Medians over 3 values; exponents from 4 points are descriptive, not asymptotic claims.
* Degenerate classes (D with a point at infinity) are skipped, not handled; group-law tests cover generic classes only.
* LA counted for a hybrid sparse/dense solver written for this test, not an optimal one; an ideal sparse
  (Wiedemann) solver would still cost ~ (p/2)*nnz ~ p^2 mults, and the Cantor-only count (~p) is
  already two orders above sqrt(p). Cantor ops are counted as one unit each though each costs tens of field mults.
* Not tested: other covers (higher genus/degree), non-prime-order E, large-prime/double-large-prime variants,
  any factor base other than degree-1 points of C. The experiment says nothing about whether a better
  algorithm exists; it shows only that this natural one is >= p at these sizes.
* The development runs before freezing code are not in the result set (see Deviations).
* Self-reported model identity only; no independent review of this run yet (REVIEW.md integration review pending).
