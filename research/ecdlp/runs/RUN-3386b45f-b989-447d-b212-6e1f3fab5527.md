## 2. Model
**Computation tree T over F (one input).** Registers v_0 = u; constants of F are free operands. Node types:
(arith) new register := a o b, o in {+,-,*,/}, one child; (test) "is register v zero?", two children; (leaf) output register.
Along a root-to-leaf path the t-th arithmetic node creates v_t. Cost: L(T) = max number of arithmetic nodes on a path;
depth >= L; the number of test nodes is NOT bounded in Theorem 1. A *test on a register that was already tested* or on a constant is
redundant. Division: T is *total on X_N={x_1..x_N}*, i.e. no executed division has divisor value 0 (the convention x/0:=0 is covered:
it is a test plus a constant register; degrees below are unaffected).
**Formal pairs.** v_0=(X,1), constant c=(c,1); (a,b)+(c,d)=(ad+cb,bd); (a,b)(c,d)=(ac,bd); (a,b)/(c,d)=(ad,bc).
**Fact F1 (verified, RationalSLP `degLe_getD`, `eval_agreement`).** Both num and den of v_t have degree <= 2^t, and on any
input u0 whose execution is defined, den(u0) != 0 and value = num(u0)/den(u0). Tests create no registers, so
**degrees do not grow with the number of tests**: along a path degree <= 2^L, not 2^{L+D}. (The execution path only selects *which* formal
pairs are used; the pairs themselves depend on the path's arithmetic nodes only.)

## 3. Theorems

### Lemma A (partial agreement for linear target, consecutive triples; extends RationalSLP)
Hypotheses as in RationalSLP.degree_bound_rational_short_weierstrass but with G subset [1,N] instead of [1,N]: A,B in F[X], deg <= d,
B(x_k) != 0 and A(x_k)=k B(x_k) for k in G. Let C(G) = #{k in [2,N-1] : k-1,k,k+1 in G}. Then **C(G) <= 3d.**
*Proof.* If C(G)=0 trivial. Else some n0 in [2,N] has n0-1,n0 in G. Reduce A,B by g=gcd (g(x_k)!=0 on G because B(x_k)!=0), so A,B coprime
with the same hypotheses and deg <= d. Nrat (deg <= 3d, `natDegree_Nrat_le`) satisfies, for 2<=k<=r-2, the identity `key` (verified, RationalSLP).
(i) Nrat vanishes at x_k for every centre k (`eval_Nrat` with A=kB at k-1,k,k+1: expression is 0 by ring). (ii) Nrat != 0: suppose Nrat=0. The proof of `prop` in
`degree_bound_rational_coprime` starts from agreement at the pair (N-1,N) and propagates A=kB, B!=0 up to k=r-1; it only uses agreement at *some* adjacent
pair (n0-1,n0), so it propagates from n0 verbatim, and the same wrap-around contradiction (x_{r-1}=x_1, x_{r-2}=x_2 => 2=0) follows. (iii) distinct x_k, so
C(G) <= #roots <= 3d. QED. (Lean: generalise the `base` case of `prop` from N to n0; the rest of the file is reused.)

### Theorem 1 (equality tests are nearly free)  — main result
Let T be a computation tree as in section 2, total on X_N, L = max arithmetic nodes per path, with output k on every x_k (k in [1,N]). **No bound on the
number of tests/depth.** Then N <= 9*2^L - 1, i.e. L >= log2(N+1) - log2 9. (Same for division-free trees; N<=3d+2+3m below.)
*Proof.* Generic path pi_0: from the root follow arithmetic nodes; at a test node on register with formal pair (n,e) go to the zero-child iff n is the zero polynomial,
else to the nonzero child. pi_0 has <= L arithmetic nodes, its registers are formal pairs of F1. Let Bad = {k : execution of x_k leaves pi_0}.
*Claim 1: Bad is contained in the union of the root sets of the numerators n_w != 0 of registers tested on pi_0.* Take the first test w on pi_0 where k deviates.
If generic = nonzero branch (n_w != 0) and k goes zero: value 0 = n_w(x_k)/e_w(x_k) with e_w(x_k) != 0 (F1), so n_w(x_k)=0. If generic = zero branch (n_w = 0 as polynomial)
and k goes nonzero: value = 0/e_w(x_k) = 0, contradiction. (Prior to deviation k followed pi_0, so F1 applies to the shared prefix; totality ensures every
k reaches a leaf.)
*Claim 2: |Bad| <= 2^{L+1}-1.* Distinct registers on pi_0 are u, v_1..v_L (and constants, whose numerators are nonzero constants or zero: no roots). A nonzero numerator of v_t has <= 2^t roots,
x_k are distinct, so |Bad| <= sum_{t=0}^L 2^t. Repeated tests of one register add nothing, hence the depth does not matter.
Set G = [1,N] \ Bad. On G the generic leaf outputs the register (A,B) of pi_0 with deg <= 2^L, B(x_k)!=0 and A(x_k)=k B(x_k). By Lemma A, #centres <= 3*2^L. Each bad
element removes <= 3 centres of [2,N-1], so #centres >= N-2-3|Bad|. Hence N <= 3*2^L + 2 + 3(2^{L+1}-1) = 9*2^L - 1. QED.
*Consequence.* A branching program whose only branching is "register = 0?" needs L >= log2(N+1) - 3.17 arithmetic nodes on some path, whatever its depth D. The structure answers question 1(b): leaf sets
are not arbitrary dense sets; all nodes but <= 2^{L+1}-1 follow ONE leaf, so consecutive triples exist and no Behrend/Kelley-Meka issue arises.

### Theorem P (pair / first-difference partial agreement for the linear target, arbitrary subset A)  — proof attempt
Hypotheses: char F != 2, A subset [1,N], 2N<r, f,h in F[X] deg <= d, h(x_k)!=0 and f(x_k)=k h(x_k) for k in A, and j in [1,N-1] with 2j != 0 in F. Then
**#{k in A : k+j in A, k != j} <= 4d** (so <= 4d+1 counting k=j).
Remark: the earlier belief that first differences are not usable (F(x_{k+j}) - F(x_k)=j is not invariant under k+j <-> k-j) is repaired by taking the **norm**:
set phi(z,u) = f(z)h(u) - f(u)h(z) - j h(z)h(u) = sum_i c_i(u) z^i (deg c_i <= d) and q(Z)=D Z^2 - S Z + T with D=(u-x_j)^2, S, T the Interp numerators for centre offset x_j
(the quadratic whose roots are x(Q+jP), x(Q-jP)). M(u) := sum_i c_i^2 D^{d-i}T^i + sum_{i<l} c_i c_l D^{d-l}T^i sigma_{l-i}(u), sigma_0=2, sigma_1=S, sigma_{m+1}=S sigma_m - T D sigma_{m-1}
(so M = D^d phi(z1)phi(z2), z1,z2 the roots of q).
*Degree:* each summand has degree <= 2d + 2d (c's contribute 2d, cleared symmetric part <= 2d as in `natDegree_W`); deg M <= 4d. (Checked numerically C1.)
*Vanishing:* for k in A, k+j in A, k != j (so x_k != x_j and D(x_k) != 0, k != -j mod r since 2N<r): the roots of q(.,x_k) are x_{k+j}, x_{k-j}; phi(x_{k+j},x_k) = ((k+j)-k-j) h h = 0, so M(x_k) = 0.
*Nonvanishing (key step):* Suppose M = 0. q is irreducible over F(u): its discriminant is D^2 (z1-z2)^2 = 16 y_j^2 (u^3+au+b), y_j != 0 (r odd prime), and u^3+au+b is squarefree of odd degree, hence not a square times a constant. So K = F(u)[Z]/(q) is a field and
M/D^d is the norm of phi(Z,u) in K/F(u); norm 0 => phi(Z,u)=0 in K => q | phi in F(u)[Z] => phi(z1,u)=phi(z2,u)=0. Identify (over F-bar, generic point Q of E) z1=x(Q+P_j), z2=x(Q-P_j), P_j=jP, and Phi := f(x)/h(x),
an even function on E: Phi(Q+P_j)=Phi(Q)+j and Phi(Q-P_j)=Phi(Q)+j. Substituting Q -> Q+P_j in the second gives Phi(Q)=Phi(Q+P_j)+j, so 2j=0: contradiction. Hence M != 0 and the roots x_k (distinct) number <= 4d. QED (paper proof; the F-bar / function-field step is the part needing review).

### Corollary P1 (arbitrary leaf sets; any branching whatsoever)
Assume N < p (so 2j!=0 for 1<=j<N). If [1,N] is partitioned in <= 2^D classes (classes defined by ARBITRARY predicates of the input — comparisons, bit extraction, Legendre symbols, ...) and on each class a straight line program of <= L ops
computes k, then **N <= 40 * 2^{2D+L}**, i.e. L >= log2 N - 2D - 5.33.
*Proof.* For a class A, sum_{j=1}^{N-1} #{k : k,k+j in A} = C(|A|,2), so some j has >= |A|(|A|-1)/(2(N-1)) pairs; by Theorem P (d <= 2^L) that is <= 4d+1. So |A| <= 1+sqrt(2(N-1)(4*2^L+1)).
Sum over <= 2^D classes; if N >= 2^{D+1}, (N/2^{D+1})^2 <= 2N(4d+1) so N <= 2*4^{D+1}(4d+1) <= 40*4^D 2^L (4d+1 <= 5*2^L); otherwise N < 2^{D+1} <= 40 4^D 2^L. QED.
So any algorithm using D unrestricted bits followed by short field programs needs 2D + L >= log2 N - 5.33. It does **not** forbid D ~ log N tests with L ~ log N operations, so it is no barrier against bit-extraction algorithms (and, being generic in the predicate, it cannot be).
Pigeonhole (1b) therefore needs no 3-AP counting: pairs suffice because of the norm trick, and pair counts always exist by averaging over j.

### Corollary P2 (mixed model)
Tree with D' arbitrary tests per path plus any number of equality tests, L arithmetic nodes per path: delete non-generic children of equality tests to get T' with <=2^{D'} root-leaf paths; for each path Claim 1-2 gives <= 2^{L+1}-1 exits.
Remaining nodes form <= 2^{D'} classes with SLPs: N <= 2^{D'}(2^{L+1}-1) + 40*2^{2D'+L}  (proof attempt; the exit nodes on a shared prefix are only over-counted).

## 4. Obstructions / what is NOT covered
- Comparisons, bit/digit extraction of field elements (identify F_p with {0..p-1}), floor, parity, quadratic-residuosity tests: not algebraic over F. They are only covered by Corollary P1 at the price 2D, which is vacuous for D>=log2 N/2.
- Bound is loose: degree 2^L is a worst case for L ops (adding a constant already costs an op); true degrees for programs with free constants are likely smaller; no matching upper bound is known or claimed.
- Theorem 1 constant 9 (or 8 via first differences: N-1-2m <= 4d+1) is not optimised; the bound N<=3d+2 for a single SLP is no longer tight here because of the 3|Bad| loss.
- Only one input x(Q); multi-input (x and y, or both Q and a table) models, and non-prime-order/ p | r subtleties, are untouched. Randomised trees (probability) are not covered. N<2r/… we need 2N<r, i.e. only half the group.
- Division-by-zero convention x/0=0 handled by remark only (test + constant register), not proved separately.
- Equality tests on F_p only; tests on integers (e.g. lifted k mod something) outside model. Bit complexity is not addressed.
- Not formalized; not independently reviewed (no Opus reviewer in this run).
