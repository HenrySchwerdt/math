## Mathematical analysis
Write xs k = x(kP), D = (u-x0)^2, S = numS/D, T = numT/D (roots z1 = xs(k+1), z2 = xs(k-1) of Z^2 - S Z + T).
The k^2 case used N = D^d (g(z1)+g(z2) - 2g(u) - 2). For k the second difference is 0, giving
N0 := D^d (g(z1)+g(z2) - 2 g(u)) = (sum_i g_i D^(d-i) q_i) - D^d * 2g  (cleared, polynomial in u).

(a) N0 is NOT identically zero for nonconstant g, and no leading-term cancellation occurs. The worry in the task
("S ~ 2u, T ~ u^2, both roots ~ u") is a misreading of the degrees: 
deg numS <= 2 and deg numT <= 2 over D of degree 2, so S -> 2 x0, T -> x0^2 as u -> infinity and z1, z2 -> x0
(Q -> O gives Q +- P -> +-P, same x). Cleared: the first sum has degree <= 2d (Interp.natDegree_N_le), whereas
D^d * 2g is monic-D^d times 2g, degree exactly 2d + d = 3d (needs 2 != 0, d >= 1). Hence deg N0 = 3d exactly, leading
coefficient -2 lc(g). This is the same argument as for k^2: the constant "+2" there was never what made N nonzero; the
-2g(u) term does. So the "geometric" route (tau_P-invariance, char | r issues) is unnecessary: the polynomial degree
comparison is enough, with no char 3 hypothesis. Cleared roots: N0(xs k) = 0 for 2 <= k <= m-1 (m-2 distinct roots by x-injectivity), so
m - 2 <= 3d, i.e. m <= 3 deg g + 2, and with m = (r-1)/2: r <= 6 deg g + 5 (identical to k^2). Constant g impossible for m >= 2 since
1 != 2 in every field (no char assumption). Note: in char p with p | k-differences the hypotheses simply
identify k mod p; the proof never inverts anything, so no obstruction.
(b) Strongest bound proved by this machinery: N <= 3 deg g + 2. It is far from tight (Lagrange interpolant has deg g = N-1 in all
tested cases); closing that gap would need a different idea (e.g. using more than the one second-difference relation, or
higher-order differences with other multiples jP) -- not attempted.
