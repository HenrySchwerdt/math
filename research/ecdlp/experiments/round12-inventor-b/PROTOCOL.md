# Round 12 / inventor B protocol (RUN-58dee679, ECDLP-43) — pre-registered BEFORE any registered run

Owner: algorithm-inventor (claude-sonnet-5-5, self-reported). Python 3 prototypes, toy sizes only.
Nothing here is an asymptotic claim; sizes span only ~16 bits of r. Exploratory debugging runs (r <= 2^30, <= 12 instances,
used to fix the step-table quality, DP threshold and the volcano ascent) are EXCLUDED from results; their only effect is
that all tunable parameters below are frozen.

## Common machinery (frozen)
Reference "rho" and candidate walks are the SAME code (`ecinv.rho`): distinguished-point (DP) r-adding walk, m=256 steps
(table built from 3 full-size random seeds u P + v Q and random sums of earlier entries), start tables of 200 points, trail start =
sum of 3 table points, DP iff x & (2^d-1) = 0 with d = round(log2(0.25*sqrt(r/|G|)+1)), trail cap 20*2^d steps,
cycle ring 8 with deterministic escape (double the smallest cycle point) when |G|>1, total budget 60*sqrt(r)+5000 group operations
(an instance that exhausts it is a FAILURE, counted at budget value = censoring that can only favour the method).
Cost metric = counted group operations (affine add or double, 1 each) INCLUDING table construction, seeds, trail starts and escapes;
final verification (one scalar mult) not charged. Field operations are not separately counted; per group op the cost is
1 inversion + 3 mults in every method (canonicalisation adds <= 5 mults).
Same instances, same seed s for the instance (k) and the walk RNG across all methods. Instances N = 30 per size
(k uniform in [1,r-1], P random of exact prime order r, Q = kP). Each recovered k is checked Q == kP and against toyec.dlog_bsgs.

## T1 (candidate B1: automorphism-orbit rho = walk on the quotient E(F_p)/Aut)
Families: j=0 (y^2=x^3+b, p = 1 mod 3, |Aut|=6) and j=1728 (y^2=x^3+bx, p = 1 mod 4, |Aut|=4). For each family and
target bit-length of p in {22,26,30,34,38}: a prime p, a twist and b with #E = c*r, r prime, c <= 16 (generator seed 1000+bits(+1 for j1728)).
Methods: none (plain rho, G={1}), neg (G={+-1}), aut (full Aut). Metric M(r) = mean ops over the 30 instances per size.
Fit log2 M = alpha + beta log2 r (OLS over the 5 sizes); 95% CI by bootstrap over instances within size (2000 resamples, seed 7).
Pooled ratio rho/cand = geometric mean over sizes of M_none/M_aut, bootstrap CI as above.
DECISION RULE (fixed now):
 - ASYMPTOTIC-IMPROVEMENT evidence iff upper 95% CI of (beta_cand - beta_none) < -0.03 (and no censoring > 10%).
 - CONSTANT-FACTOR ADVANTAGE iff not the above AND the lower 95% CI bound of the pooled ratio is > 1.15.
 - NO ADVANTAGE otherwise; WORSE iff the upper CI bound of the pooled ratio < 0.87.
 Theory prediction (not a rule): beta = 0.5 for all methods; ratio <= sqrt(|G|) (2.45 / 2.0) before cycle losses.

## T2 (candidate B2: 2-isogeny volcano ascent to a j=0 curve, then B1)
Instances: prime p = s^2 + 3*4^(a-1), s odd, (s-1)/2 odd, #E = p+1-2s = 4r, r prime. Instance curve E = FLOOR of the 2-isogeny
volcano containing the j=0 curve (D = -3*4^a): generated by a random non-backtracking 2-isogeny descent of a steps from a
j=0 curve y^2=x^3+b with #E=4r and 3 rational 2-torsion points; the attacker receives only (E,P,Q). a in {10,12,14,16,18}
(bits(r) ~ 2a), generator seed 2000+a, 30 instances per a (descent path, P, k vary; one prime per a).
Attacker: Algorithm B2 (ascend by the neighbour with the longest random dead-end walk, carry P,Q through Velu maps until A=0),
then `ecinv.rho` with G = Aut(j=0), pull k back, verify on E.
Cost: ops_B2 = rho_aut ops + 2*(ascent steps) + W * (isogeny evaluations), W = 10 (assumption: one isogeny evaluation =
cubic root-finding ~ 15 log2 p field mults ~ 10 affine adds); both W=0 and W=10 reported.
Comparator: plain rho on E (same seeds), and neg rho on E.
Metrics: (a) iso evaluations and ascent steps vs a (log-log slope vs a and vs log2 r); (b) total cost vs r exponent as in T1.
DECISION RULE: same as T1 comparing B2 total (W=10) with plain rho on E. Additionally: ascent is "polylog" iff the 95% CI of the
log-log slope of iso evaluations vs log2 r is < 3.

## T3 (applicability of B2 over ALL curves: probability a random E/F_p is F_p-isogenous to a j=0 curve)
For primes p = 1 mod 3 near 2^10,2^11,...,2^16 (first prime >= 2^e that is 1 mod 3): 4000 uniform random (A,B) with nonzero
discriminant, trace computed exactly by numpy Legendre sum (Tate: isogenous over F_p iff equal trace). Fraction with trace in
the six j=0 traces. Fit log2 fraction vs log2 p; bootstrap CI (2000, seed 7). Prediction (Hurwitz class number counts): exponent -1/2.
Reading: exponent <= -0.35 => B2 applies to a vanishing fraction ~ p^(-1/2) of curves = a weak family, not universal.
