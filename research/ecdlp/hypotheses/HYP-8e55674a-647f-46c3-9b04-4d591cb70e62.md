# HYP-8e55674a-647f-46c3-9b04-4d591cb70e62 — Theorem P / Corollary P1 corrected

Theorem P (corrected): for an x-only rational function of degree d agreeing with k on A ⊆ [1, N], 2N < r, and j with (2j : F) != 0, the norm over the conjugates x(Q ± jP) is a nonzero polynomial of degree <= 4d vanishing at x_k whenever k, k + j ∈ A and k != j; nonvanishing follows from the Q -> −Q symmetry and evenness (no irreducibility, any r). Corollary P1 (corrected): additionally assuming N < char F, any partition of [1, N] into 2^D classes with a length-L field program per class gives N <= 40·2^{2D+L} (reviewer derivation gives constant 11).
