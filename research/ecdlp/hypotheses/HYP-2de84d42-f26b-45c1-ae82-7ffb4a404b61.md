# Universal classical ECDLP objective

Is there a universal uniform classical algorithm solving ECDLP over arbitrary elliptic curves over finite fields in worst-case O(n log n) bit operations, with n the total encoded input length?

This is aspirational and unproved. The precise input promise (including subgroup membership, order/generator information and output convention) and computational model are first-session obligations. Generic-group lower-bound statements must not be misapplied to every representation-specific algorithm. All scope and proof limits follow docs/LAB_MISSION.md.
