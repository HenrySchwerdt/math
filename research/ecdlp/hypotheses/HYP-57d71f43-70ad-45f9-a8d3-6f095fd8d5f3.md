# HYP-57d71f43-70ad-45f9-a8d3-6f095fd8d5f3 — Trivial coefficient bound for SLP certificates (N3)

## Exact statement
In any addition/subtraction straight-line program a_0 = P, a_i = ±a_j ± a_l (j,l < i), every a_i equals n_i P for an integer n_i with |n_i| <= 2^i. Hence if the order r of P exceeds 2^{L+1}+1, some Q in <P> is not an output of any SLP of length <= L; this gives L >= log2(r-1) - 1, strictly stronger than the counting bound log2 r / (2 log2 log2 r) of HYP-650069e0.
