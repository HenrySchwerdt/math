# HYP-49fb2746-152e-4907-b54b-9ba124cfd75e — Frobenius-equivariance obstruction for transfers

## Exact statement
Let r be prime, V an F_r-vector space with additive map F: V -> V, x0 in V with F(x0)=x0, M an F_r-module, c in F_r, and f: V -> M additive with f(F v) = c f(v) for all v. Then (1-c) f(x0) = 0, so f(x0) = 0 unless c = 1. Proposed application: F = q^j-power Frobenius on E[r], target mu_r with scalar c = q^j mod r, so nonzero equivariant transfers of a rational point require r | q^j - 1; for additive target c=1 but F_r-linear maps to F_p need r=p. Claimed to unify MOV/FR and the anomalous attack.
