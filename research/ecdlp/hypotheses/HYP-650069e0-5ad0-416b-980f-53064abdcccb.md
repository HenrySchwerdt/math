# HYP-650069e0-5ad0-416b-980f-53064abdcccb — Straight-line group-operation certificates need about log r / (2 log log r) operations

## Exact statement
Let G=<P> have order r. A straight-line program of length L is a_0=P, a_i = e1 a_j + e2 a_l with j,l < i and e1,e2 in {+1,-1}. At most 4^L (L!)^2 elements are outputs of such programs, so if 4^L (L!)^2 < r some Q in G has no SLP of length <= L. Consequently, if each group operation costs at least c*b bit operations (b = field bit length), verifying a worst-case instance by any SLP costs Omega(b^2/log b) bit operations, which is omega(n log n).
