# HYP-42f91290-d245-4bcf-a1e2-34daf4beeaab — Theorem C

## Statement
Theorem C (x-only interpolation of k): Let W be short Weierstrass over a field F with 2 != 0, P a point with addOrderOf P = r, and 2N < r. If g in F[X] satisfies g(x(kP)) = k for 1 <= k <= N, then N <= 3 deg g + 2 (so r <= 6 deg g + 5 for N = (r-1)/2). Proof: the cleared second-difference polynomial N0(u) has degree exactly 3 deg g (leading coefficient -2 lc(g)), vanishes at x(kP) for 2 <= k <= N-1.
