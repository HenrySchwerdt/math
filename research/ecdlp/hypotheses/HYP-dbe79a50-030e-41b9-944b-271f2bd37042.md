# HYP-dbe79a50-030e-41b9-944b-271f2bd37042 — Decision-tree barrier

Theorem DT (algebraic decision trees with equality tests): over a field F with 2 != 0, W short Weierstrass, P of order r, 2N < r. Any algebraic computation tree with single input u = x(Q), arithmetic nodes +,−,×,÷ (divisions defined where executed) and branching only on "register = 0?", in which every root-to-leaf path has at most L arithmetic nodes, and which outputs k at u = x(kP) for all 1 <= k <= N, satisfies N <= 9·2^L − 1 regardless of depth. Proof: along the generic path every register has degree <= 2^t; nodes deviating from it lie in the root sets of tested numerators (<= 2^{L+1} − 1 nodes); the generic leaf function agrees with k on a co-small set, which has many consecutive triples; Lemma A (a rational function agreeing with k on G has <= 3d centres k with k−1, k, k+1 in G) via the RationalSLP orbit-propagation argument. Theorem P: norm over conjugates x(Q ± jP) gives degree <= 4d polynomials vanishing at x_k when k, k+j in A (needs 2j != 0): first differences are usable; Corollary P1: any partition into 2^D classes with length-L programs gives N <= 40·2^{2D+L}.
