# HYP-5a550ab6-75ad-4e6b-a08c-af2a066c69c7 — Interpolation and algebraic-SLP lower bounds for the EC discrete-log map (Theorems A, A')

## Exact statement
Theorem A: Let E/F_p (short Weierstrass), P of order r with r != p, 2 <= N <= r-1. If a rational function f on E satisfies f(kP) = k mod p for 1 <= k <= N, then f has pole order (divisor degree) >= (N-1)/2; if f is a polynomial in X, Y then its total degree is >= (N-1)/6. Proof: h(Q) = f(Q+P) - f(Q) - 1 vanishes at kP, 1<=k<=N-1; h != 0 since otherwise iterating r times gives r = 0 in F_p; pole order of h <= 2 * pole order of f. Theorem A': any straight-line program over F_q using +, -, *, / on the coordinates of Q and constants that computes k mod p for all Q = kP, 1<=k<=N, has length >= log2((N-1)/12); charging >= c log q bit operations per field operation gives Omega(n^2) bit cost in this algebraic model (no comparisons/bit extraction).
