# HYP-5da6025e-c665-473f-a06a-3f02a267fe8c — Partial-agreement lower bounds

## Exact statement
Partial-agreement lower bounds (proof attempt). Let E/F_p, P of prime order r, N < min(p, r), A ⊆ {1..N} with |A| = m, and f a rational function on E regular at kP (k ∈ A) with f(kP) = k mod p for k ∈ A. (1) For every 1 <= j <= N-1: deg f >= T_j/2 where T_j = #{k : k, k+j ∈ A} (h_j = f∘τ_{jP} − f − j vanishes at those kP; h_j ≢ 0 since otherwise the pole set is jP-invariant, orbits of size r). (1b) Since Σ_j T_j = C(m,2): deg f >= m(m−1)/(4(N−1)) ≈ δ²N/4 for every δ = m/N. (1a) deg f >= ((2δ−1)N − 1)/2 for δ > 1/2. (1d) polynomial total degree >= deg f / 3. (2) x-only g with g(x(kP)) = k² on A: deg g >= S_j/3 with S_j = # 3-term progressions in A of difference j; gives deg g >= ((3δ−2)N − 2)/3 for δ > 2/3. N < p is necessary (counterexample p=5, r=7, f ≡ 1 on {1,6}).
