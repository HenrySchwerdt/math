# HYP-92a9b4d9-827b-45fc-b881-1e7cf3b3443b — Algebraic SLP lower bound for x-only DL computation (corollary of Theorem C)

## Statement
Corollary of Theorem C (algebraic SLP barrier, x-only, division-free): Let W be short Weierstrass over a field F with 2 != 0, P of order r, 2N < r. Any straight-line program over F of length L using +, −, × and constants, with the single input u = x(Q), whose output equals k (in F) at u = x(kP) for all 1 <= k <= N, satisfies L >= log2((N − 2)/3). Consequence (cost model): if each field operation costs >= c·log p bit operations, such programs need Omega(n^2) bit operations for N ~ r/2 ~ p/2, so the O(n log n) target is impossible in this restricted algebraic model.
