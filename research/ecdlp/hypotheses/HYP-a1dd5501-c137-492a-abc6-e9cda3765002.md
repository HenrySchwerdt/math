# HYP-a1dd5501-c137-492a-abc6-e9cda3765002 — Partial-agreement bounds (corrected)

## Statement
Partial-agreement bounds (corrected after blind review ECDLP-23). E/F_p short Weierstrass, P of prime order r, A ⊆ {1..N}, |A| = m. (1) If N <= min(p, r) and f is a rational function regular at kP (k in A) with f(kP) = k mod p on A, then for every j: deg f >= T_j/2 (T_j = #{k : k, k+j in A}) — via the dichotomy: h_j = f∘τ_{jP} − f − j ≢ 0, or else f has poles, deg f >= r (and p = r). Consequences (1b) deg f >= m(m−1)/(4(N−1)); (1a) deg f >= ((2δ−1)N−1)/2 for δ > 1/2; (1d) polynomial total degree >= deg f/3. (2) If additionally N <= (r−1)/2 (so ±kP, 1 <= k <= N, are distinct), and g in F_p[X] with g(x(kP)) = k^2 on A, then deg g >= S_j/3 (S_j = # of k with k−j, k, k+j in A) and deg g >= ((3δ−2)N−2)/3 for δ > 2/3.
