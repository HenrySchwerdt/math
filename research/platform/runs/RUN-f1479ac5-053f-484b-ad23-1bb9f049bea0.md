# Task-board implementation

Implements the latest user steering. Steps displayed on the board come from timestamped run metadata, recorded command evidence and reviews; open tasks are not given invented milestones.

Implemented persisted ECDLP-1/FACTOR-1/LAB keys, status columns, project/search
filters and deep-linked native task dialogs. Timeline entries are backed by
recorded run starts/completions, command evidence and review artifact metadata.
Review artifact creation is explicitly distinguished from decision time.

Independent review found and prompted fixes for malformed command argv/timestamps,
review timestamp interpretation and preservation of VitePress history state.
Twenty-two regression tests and a VitePress production build passed. Local
browser verification opened ECDLP-1 directly from its URL, showed exact criteria
and recorded command/run history, and returned to the ECDLP board on close.
Preview's cached asset list required restarting the preview server after rebuilding;
no site bug or successful browser check is claimed for those failed attempts.
